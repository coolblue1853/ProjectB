## 1. 원칙 (모션 연구와 같다)
1. **먼저 조사 → 규칙 문서 → 파일럿 1종 → 사용자 합불 → 대량 생산.** 규칙 없이 대량 생성하지 않는다.
2. **PixelLab 은 파일럿·핵심만.** 변형(색 바꾸기)·반복 타일·크기 변형은 생성 0(팔레트 스왑·코드)으로 한다.
3. 판정은 **Claude 판정을 먼저 로그에 적고** 사용자 판정과 비교한다(`MotionJudgeLog.md` 와 같은 표 형식, 영역별 로그 `Docs/Playtest/MobJudgeLog.md`·`BgJudgeLog.md`).
4. 실패하면 **왜 실패했는지** 같은 문서에 적는다(사용자 지시).
5. 평일 사용자 부재 시 Claude 가 스스로 판단하는 기준 = 아래 §2 합격 기준 + §3 예산 상한. 기준 밖(그림체 변경·새 세계관)은 `Docs/OpenQuestions.md` 에 쌓고 계속한다.

## 2. 영역별 합격 기준 (초안, 파일럿 뒤 사용자와 확정)
**몬스터** — ① 주인공과 같은 그림체(검정 외곽선·2~3단 평면 음영·밝은 눈, `ArtStyle.md` §0 "자연에 먹힌 몸 + 한 점 발광") ② 실루엣만 봐도 종 구분 ③ 크기 일정(프레임 간 ±2px) ④ 대기·이동·피격·죽음 프레임이 같은 몸 ⑤ 공격 예비-타격-회복이 읽힘 ⑥ 이펙트가 그림에 안 섞임(지우기) ⑦ 초반 몹은 작고 소박(`early-game-modest`). 합격 = 6점 이상 + ①④.
**배경** — ① 던전 슬래셔식 레이어 3~4겹(원경·중경·근경·바닥) ② 색감 일관(층계별 팔레트) ③ 타일 가로 반복 이음새 없음 ④ 캐릭터가 묻히지 않음(대비) ⑤ 어둡지만 유아틱하지 않음(`abyss-mood-not-childish`).
**방어구 레이어** — ① 맨몸 프레임과 같은 캔버스·프레임·피벗 ② 교체 시 맨몸 비침 없음(마스크) ③ 모든 모션(대기·걷기·달리기·점프·3타·올려베기·회전·활)에서 어긋남 없음 ④ 세트 색 변형은 팔레트 스왑으로 해결.
**NPC** — 현재 그림체와 어울림만 확인(생성 0 우선).

## 4. 순서 (급한 것 = 생성 많이 먹는 것)
1. 몬스터 규칙 조사: 던전 슬래셔 `clips_index.csv` 의 monster 526클립(176묶음)·boss 288, 스컬 enemy 라이브러리 → 크기·프레임 수·속도·공격 읽기 법을 `Game/MobRules.md` 에 정리.
2. 몬스터 파일럿(사용자가 가져온 레퍼런스: 돌 골렘 2017/2022·얼음 나무 정령·숲 거인) 1종 → 합불.
3. 배경 규칙 조사: 던전 슬래셔 배경 텍스처(`tex/BackGround_*`·`Back_*`)와 `BackgroundRefPlan.md` 묶음 → `Game/BgRules.md` + 1층계 근처 숲 1장 파일럿.
4. 방어구 레이어 규격에 새 모션 3종(올려베기·회전·활) 추가 후 1층계 첫 세트 1개 파일럿.
5. 파일럿 3종 합격 → 평일 위임 가능(대량 생산은 §3 상한 안에서 Claude 판단).

## 5. 평일 위임 규칙
- 큐 항목 하나 = 종 1개 또는 장비 1개. 한 번에 생성 40 이하, 결과는 로그 표 한 줄 + GIF/시트 파일 경로.
- 합격 기준 6점 이상이면 다음 종으로 계속, 5점 이하는 원인을 로그에 적고 같은 종을 1번만 재시도, 그래도 아니면 `OpenQuestions` 에 쌓고 다음 종.
- 주간 사용량 한도(Claude)가 낮을 때(10% 미만)는 생성·확인 위주로 하고 Unity 통합·커밋은 사용자 복귀 후.
