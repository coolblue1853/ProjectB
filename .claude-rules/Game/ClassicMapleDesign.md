# 클래식 메이플 진행 구조 (게임 디자인 방향, 2026-10-31 사용자 확정)

> 사용자(10-31): "레벨링 디자인은 옛날 메이플, 클래식 메이플(메이플랜드 초반 1.0~2.0). 퀘스트가 있고 사냥 위주, 너무 윗지역에 가면 죽고, 몸박(부딪히면 데미지), 물약 많이 들고 다니고… 게임 진행·구조는 클래식 메이플, 다른 요소(파밍·세트·제작)는 전에 말한 게임들처럼. 공격·스킬은 덜 답답하게 — 스킬은 캐릭터가 올리는 게 아니라 장비에 들어 있다. 클래식 메이플 → 최종 지역에서는 현재 메이플 정도의 유연함. 스킬 트리 없음(나중에 특정 무기 밀어주는 건 나올지도)."

## 0. 한 줄

**진행·구조 = 클래식 메이플**(레벨·EXP·퀘스트·사냥터·몸박·물약·사망 페널티), **전투 방식 = 장비**(무기 스킬·세트·계보 — 디아·던파·몬헌), **조작 유연함은 층계를 오를수록 열린다**(1층계 클래식 감 → 7층계 현대 메이플 감).

세 역할을 분리한다:
- **레벨** = 어디로 갈 것인가(적정 사냥터·위험 지역).
- **장비·계보 스킬** = 어떻게 싸울 것인가(전투력의 70~80%).
- **퀘스트** = 왜 그 지역에 가야 하는가(동선·새 맵 소개).

| 조작 유연함 | 처음부터 전부 | **층계별로 개방**(§6) |

## 2. 조사 요약 — 클래식 메이플(빅뱅 이전, 메이플랜드 계열) (GPT 웹 조사 10-31)

- 필요 EXP: Lv1 15 · Lv10 1,144 · Lv20 13,477 · Lv30 63,800 · Lv50 567,772 · Lv70 1,650,340. 초반은 짧고 중반부터 한 레벨에 오래 머물게 한다(그동안 장비 파밍).
- 레벨 차 피해 감소(2026 클래식 역분석): Δ=몹Lv−내Lv, Δ<10이면 D/(1+0.005Δ²), Δ≥10이면 D/(1+0.05Δ) → +5 89%, +10 67%, +20 50%. 명중은 별도.
- 퀘스트: 수집·처치·배달·연계·전직. 퀘스트 EXP는 그 레벨 필요 EXP의 수 %(제인 퀘스트 Lv25 EXP 2,500 = 7.9%) — 사냥을 대체하지 않고 **새 맵으로 끌고 가는 역할**. 보상은 EXP + 아이템(주문서).
- 맵: 마을 주변에서 바깥으로 위험도 증가, 발판 여러 층 + 로프·사다리, 좌우 포털 + 숨은 포털, 메인 동선 옆에 고위험 분기. 리젠 약 7~7.5초, 맵당 최대 40마리.
- 생존: 빨간 포션 HP 50 / 50메소, 주황 150 / 160, 하얀 300 / 320, 귀환 주문서 400. 사망 시 EXP 손실(클래식 월드 최대 10%).

## 3. 우리 게임 수치 (시작값, GPT 제안 채택)

### 3.1 레벨

| 항목 | 값 |
|---|---|
| 레벨 | 1~70 |
| 자동 성장(레벨당) | HP +8, 공격 +0.5, 방어 +0.5 |
| 시작 | HP 200, 공격 10, 방어 5 → Lv70 HP 752, 공격 44.5, 방어 39.5 |
| 장비 요구 레벨 | 가급적 없음(층계·재료·보스 드롭으로 통제) |
| EXP 곡선 | 원작 표를 그대로 쓰지 않는다. 목표 시간에서 역산: 초반 1레벨 5~10분, 중반 20~35분, 후반 40~60분 |
| 세이브 | ES3 `level` 필드가 이미 있다(사용 안 됨) → 그대로 쓰고 `exp` 추가 |

## 5. 기존 설계와의 관계

- 장비·세트·계보(LineageGear·WeaponTypes)·강화(ProgressionDesign·FloorCoreContent §4)·미니게임은 그대로. 단 **전투력의 70~80%는 장비**라는 기준으로 레벨 성장치를 작게 둔다.
- 상승 부하(TowerWorld §7)는 유지 — 레벨 차 감소와 함께 "너무 윗지역에 가면 죽는" 두 번째 벽.
- 1~4층계 본무대(FloorCoreContent)는 그대로.

## 7. 구현 순서(안)

1. 레벨·EXP 코어(몹 EXP·레벨 컬럼, 레벨업 자동 성장, HUD, 세이브 `level`·`exp`) + 사망 EXP −5%.
2. 몸박(접촉 피해·넉백·무적) + 레벨 차 피해 감소.
3. 물약 경제(물약 3종·쿨다운·가격) + 귀환 주문서.
4. 1층계 몹 레벨·EXP 배치(구역 T → Lv1~15) + EXP 곡선 역산(처치 속도 실측).
5. NPC 퀘스트(연계·지역 메인) — 1층계부터.
6. 리젠·맵 동선 점검.
