# 클래식 메이플 진행 구조 (게임 디자인 방향, 2026-10-31 사용자 확정)

> 사용자(10-31): "레벨링 디자인은 옛날 메이플, 클래식 메이플(메이플랜드 초반 1.0~2.0). 퀘스트가 있고 사냥 위주, 너무 윗지역에 가면 죽고, 몸박(부딪히면 데미지), 물약 많이 들고 다니고… 게임 진행·구조는 클래식 메이플, 다른 요소(파밍·세트·제작)는 전에 말한 게임들처럼. 공격·스킬은 덜 답답하게 — 스킬은 캐릭터가 올리는 게 아니라 장비에 들어 있다. 클래식 메이플 → 최종 지역에서는 현재 메이플 정도의 유연함. 스킬 트리 없음(나중에 특정 무기 밀어주는 건 나올지도)."

## 0. 한 줄

**진행·구조 = 클래식 메이플**(레벨·EXP·퀘스트·사냥터·몸박·물약·사망 페널티), **전투 방식 = 장비**(무기 스킬·세트·계보 — 디아·던파·몬헌), **조작 유연함은 층계를 오를수록 열린다**(1층계 클래식 감 → 7층계 현대 메이플 감).

세 역할을 분리한다:
- **레벨** = 어디로 갈 것인가(적정 사냥터·위험 지역).
- **장비·계보 스킬** = 어떻게 싸울 것인가(전투력의 70~80%).
- **퀘스트** = 왜 그 지역에 가야 하는가(동선·새 맵 소개).

- 필요 EXP: Lv1 15 · Lv10 1,144 · Lv20 13,477 · Lv30 63,800 · Lv50 567,772 · Lv70 1,650,340. 초반은 짧고 중반부터 한 레벨에 오래 머물게 한다(그동안 장비 파밍).
- 레벨 차 피해 감소(2026 클래식 역분석): Δ=몹Lv−내Lv, Δ<10이면 D/(1+0.005Δ²), Δ≥10이면 D/(1+0.05Δ) → +5 89%, +10 67%, +20 50%. 명중은 별도.
- 퀘스트: 수집·처치·배달·연계·전직. 퀘스트 EXP는 그 레벨 필요 EXP의 수 %(제인 퀘스트 Lv25 EXP 2,500 = 7.9%) — 사냥을 대체하지 않고 **새 맵으로 끌고 가는 역할**. 보상은 EXP + 아이템(주문서).
- 맵: 마을 주변에서 바깥으로 위험도 증가, 발판 여러 층 + 로프·사다리, 좌우 포털 + 숨은 포털, 메인 동선 옆에 고위험 분기. 리젠 약 7~7.5초, 맵당 최대 40마리.
- 생존: 빨간 포션 HP 50 / 50메소, 주황 150 / 160, 하얀 300 / 320, 귀환 주문서 400. 사망 시 EXP 손실(클래식 월드 최대 10%).

## 6. 조작 유연함 개방 — Q-446 1단계 (2026-10-31)

이번 작업 지시의 초반 잠금을 우선해 이전 "이미 있는 이동을 빼지 않는다" 가정을 대체한다. **기본 모션·점프 힘·대시 물리·칼 3타·스미어 v7은 보존, 실행 조건만 제한한다.** 최고 도달 층계 기준으로 내려와도 개방 유지.

| 시점 | 열리는 이동 | 제한·수치 |
|---|---|---|
| 1층계 시작 | 걷기·달리기·단일 점프·하향 점프·로프 | 2단 점프·Z 대시·활공 잠금. 공중 반대 입력은 제동(수평 0)까지만, 같은 방향 재입력 가능. 제자리 점프는 처음 공중 입력 방향을 기준으로 삼음 |
| 브로치 공명 1단계(Q604 완료 보고) | 지상 Z 대시 | 씬 실측 dashSpeed15×스케일1.5=22.5u/s·0.2초·쿨0.4초·스태미나5·무적 유지. 공중 대시는 잠금 |
| 2층계 첫 진입(그 이상 포함) | 2단 점프·공중 방향 전환·활공·지상 대시 | 실행 상한2회(씬 maxJumps=5 직렬화 값 보존, 정책에서2로 제한)·씬 점프 힘10 유지. 활공 홀드0.2초·12초·수평85%·낙하−1.3 유지. 층계 진입은 브로치 미완료에도 지상 대시 보장 |
| 3층계 첫 진입 | 공중 Z 대시 | 기존 대시 물리·비용 유지 |
| 4~7층계 | 이번 단계 추가 없음 | 벽 점프·신규 캔슬·이동 시전·텔레포트·스킬 칸 확장은 후속 |

- 공격·장비 스킬 돌진(`SkillDash`)·기존 캔슬·공중 공격·공격 시작 방향·버퍼0.1초·코요테0.08초·공격 이동 배율은 개방 조건으로 막지 않는다. 스킬 슬롯도 제한하지 않는다("공격은 덜 답답하게").
- 독립 리뷰 보완(10-31): 지상 대시는 발밑 접지 판정만 사용한다. 로프·코요테는 점프 허용 기준이며 지상 대시 근거로 쓰지 않는다. 공중 로프에서 대시하려면 3층계 공중 대시 개방이 필요하다.
- `MovementUnlocks`가 진행·저장·이벤트를 소유, `MovementUnlockRules`가 순수 판정. 기존 `maxJumps` 직렬화 필드는 보존.
- 새 ES3 키만 추가: `movement.highestFloor`(1~7), `movement.broochStage`(0~1). 기존 `glide.unlocked`는 읽기 전용 이관(true면 최소 2층계). Q604 완료 기록 로드 시 브로치 1단계 복원. 진행 변경 즉시 저장, 반복 개방은 false·알림 없음.
- 시작 맵: 활성 맵 중 플레이어와 y가 가장 가까운 `MapInfo.floor`. 이후 `Portal.MapChanged`의 층계. 맵 이름 문자열에 의존하지 않음.
- 화면 알림: 기존 `BossBanner` 부제 한 줄(40px, 제목 비움)(픽셀 폰트 대응 영문) `Movement unlocked: Ground Dash`, `Double Jump / Air Turn / Glide`, `Air Dash`. 여러 개방은 한 줄로 합침.
- 에디터 전용 메뉴 `Tools/ProjectB/Movement/Unlock All (Play Mode)` 전체 개방 토글. 세이브 기록 없음·플레이 종료 시 해제·빌드에서는 false. 끄면 진행 기준 복귀, 점프 잔여량은 다음 착지 갱신.
