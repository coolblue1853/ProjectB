# 스컬(Skul: The Hero Slayer) 전투 레퍼런스

10-27 사용자: "전투 움직임(공격 모션)·이펙트는 '스컬'을 보고 맞춰 달라. 캐릭터 형태는 우리 것." 이 문서는 스컬의 전투 표현 문법과 우리 기본 공격의 차이, 적용 계획을 적는다.

## 0. 조사 상태

- **기술 자료:** 개발사 SouthPAW의 Unity 사례 연구가 있다. PPU 32, 32×32 타일, Pixel Perfect 카메라를 쓴다. 이펙트 스프라이트는 피벗이 가운데이고, 둘레를 빈칸으로 둔다. 적을 때리면 갑옷·무기 조각("parts")이 실제 물리로 떨어져 나간다. 조각은 무게와 회전력을 따로 갖고, 회전은 각도마다 스프라이트를 따로 그렸다. 출처는 [Unity 사례 연구](https://unity.com/resources/skul-the-hero-slayer-case-study)와 [PhoneticLight 전재](https://www.phoneticlight.com/2021/01/21/2d-pixel-perfect-for-a-crisp-conquest-in-skul-the-hero-slayer/)다.
- **리틀 본 기본 공격:** 땅에서는 머리 위에서 내려치기 → 역방향 휘두르기 2타를 반복하고, 공중에서는 아래로 내려친다([Skul 위키](https://skul.fandom.com/wiki/Skul)).
- **영상 프레임 분석은 미완:** 내장 브라우저로 YouTube 4K 플레이 영상을 프레임 단위로 보려 했지만 막혔다.
  - 게임 카메라가 멀어 캐릭터가 화면에서 20px 안팎이다.
  - 중간 광고가 끼어들었다.
  - 스프라이트 시트 사이트(Spriters Resource)는 봇 확인 페이지에서 멈췄다.
  - 정밀 수치(프레임 수·히트스톱 길이)는 영상을 내려받아 프레임으로 뽑아야 잴 수 있다. 사용자 허락이 필요하다.
- 아래 1절은 공개 플레이에서 널리 알려진 스컬의 표현 특징을 정리한 것이다(관찰 일반론). 수치는 추정이니 영상 분석 뒤 고친다.

## 1. 스컬 전투 표현 문법(추정치 포함)

| 항목 | 스컬 | 비고 |
|---|---|---|
| 평타 리듬 | 2타 반복, 한 타 약 0.25~0.3초, 빠른 선딜(1~2프레임) → 즉시 판정 | 입력 버퍼로 끊김 없이 이어짐 |
| 공격 중 이동 | 걷기를 거의 막지 않음, 타마다 앞으로 짧게 미끄러짐(수 px) | 방향 전환은 타 사이에 가능 |
| 베기 이펙트 | 큰 초승달 잔상 1장(무기보다 훨씬 큼) + 2~3프레임 걸쳐 가늘어지며 사라짐, 흰색 중심 + 무기/스컬 고유색 테두리 | 무기 그림보다 이펙트가 타격의 "모양"을 결정 |
| 피격 반응 | 적 흰색 번쩍 1~2프레임, 짧은 경직(히트스톱 약 0.05~0.08초), 뒤로 밀림 + 작은 튕김 | 큰 적은 밀림 작음 |
| 타격 스파크 | 맞은 지점에 작은 방사형(별·선) 스파크, 2~4프레임 | 치명타는 더 크고 색이 다름 |
| 조각 파편 | 갑옷·방패·뼈 조각이 떨어져 회전하며 튐(물리) | 연출의 큰 비중 |
| 숫자 | 작은 도트 숫자가 위로 튀었다가 사라짐, 치명타는 색·크기 다름 | |
| 카메라 | 평타는 흔들림 거의 없음, 스킬·강타·보스 패턴에만 짧게 | 과한 흔들림 없음 |
| 공중 평타 | 내려치기 1종, 공중에서 약간 떠 있음(낙하 감속) | |

## 2. 우리 기본 공격과의 차이(10-27 기준)

- **이동:** 녹슨 검은 평타 중 60% 속도로 이동한다(d470df41). 스컬처럼 타마다 앞으로 미끄러지는 짧은 전진은 없다.
- **이펙트:** `M_PixelSlash` 궤적이 있지만, 스컬처럼 "큰 초승달 1장 + 가늘어지며 사라짐" 문법인지는 촬영해서 봐야 한다.
- **피격:** `HitFeedback` 평타 프로필이 플래시 0.06초, 대상 히트스톱 0.04초, 공격자 히트스톱 0.03초, 흔들림 Light다(GameFeelPlan.md). 스컬보다 짧고, 평타 흔들림은 스컬보다 세다.
- **파편:** 몹 처치·타격 때 조각이 튀는 연출은 없다(사망 셀만).
- 초반 장비·이펙트는 소박하게 유지한다(early-game-modest). 스컬 문법은 리듬·모양에 맞추고, 화려함은 유니크·레전더리 무기에만 둔다.

## 3. 적용 계획(우선순위)

1. 평타 타마다 짧은 전진(4~6 아트 px, 타격 프레임 직전 0.06초) — 리듬 체감이 가장 크다.
2. 히트스톱: 대상 0.04 → 0.06초, 공격자 0.03 → 0.04초. 평타 카메라 흔들림은 끄거나 아주 약하게.
3. 베기 이펙트: 무기 길이에 맞춘 큰 초승달 1프레임 + 2프레임 감쇠(흰 중심·무기색 테두리), 초반 무기는 무채색 소형.
4. 타격 스파크: 작은 방사형 4프레임(흰·연노랑), 치명타 전용 대형.
5. 피격 반응: 흰 번쩍 + 작은 튕김(소형 몹), 갑옷 몹은 조각 파편(후순위, 몹 리디자인 뒤).

각 항목은 Unity에서 0.04초 촬영으로 확인한 뒤 수치를 이 문서에 기록한다.

## 4. 영상 프레임 분석(10-27, 웨일 YouTube 프리미엄 1080p, 1/15초 격자)

주의: 스컬의 주인공은 **해골(스컬)** 이다. 빨간 머리 망토 검사 같은 '용사' 정형 캐릭터는 적(모험가)이라 분석에서 뺐다(10-27 사용자 확인).
방법: 영상 프레임을 캔버스에 1/15초 간격으로 잘라 붙인 격자를 한 장으로 보았다(내려받기 없음). 영상: "모든 유니크·레전더리 스컬 정리"(1wKkJtqM1FE, 베타 낮 맵, 적 소수라 잘 보임), 풀플레이(DGpOXS4CHRY), 일반 스컬 레전더리 각성 모음(mg5okMx-T6M, 후반 혼전이라 분석 부적합).

| 스컬 | 시점 | 본 것 |
|---|---|---|
| 리틀 본 | 풀플레이 1:40~1:47 | 대기: 몸 거의 정지, 뼈 몽둥이 비스듬히 위로. 대시: 몸이 낮게 누운 자세 + **검은 잔상 띠**가 뒤로 길게(4~5프레임) 남고 흰 먼지 한 덩이 |
| 닌자 | 28.0~29.3 | 평타 = **청록 초승달 베기**(두꺼운 가운데·가는 양끝, 캐릭터 키의 1.2~1.5배, 2프레임 정도 보였다 사라짐). 강타 = 대각선으로 길게 그은 **선 베기**(흰 선 1프레임 → 같은 자리 **검은 선 1프레임**) + 흰 원 고리 파열. 연타 타격점에 **검은 원(반전 임팩트) 1프레임** → 흰 원·방사선 |
| 다크 팔라딘(창기병) | 108.6~109.3 | 기본 = 긴 창 **수평 찌르기**(창을 3~4프레임 뻗은 채 유지), 몸 전진은 작다. 타격점 **작은 노란 별 스파크 + 십자 점**(2프레임) |
| 사무라이 | 244.0~245.3 | 발도 = **아주 가는 흰·청록 대각 선 1~2프레임** + 흰 연기 한 점. 폭발 스킬 = 빨강·노랑 불덩이 + **흰 충격파 고리** + 속도선. 사무라이(삿갓 해골)가 공중으로 뛰어올라 베고 내려옴, 잎·검은 조각 파편이 중력으로 흩어짐 |

공통 문법(관찰):
1. **베기 = 색 있는 초승달 1장**(스컬마다 고유색, 리틀 본은 흰색 계열), 2~3프레임(약 0.1초) 안에 사라진다. 무기 그림보다 이펙트가 크다.
2. **임팩트 프레임:** 큰 타격은 1프레임 **검은 실루엣(원·선)** → 다음 프레임 **흰 고리·방사선**. 반전 색 한 프레임이 "탁" 하는 맛을 만든다.
3. **작은 타격 스파크:** 노랑·흰 4갈래 별 + 작은 십자 점, 2프레임.
4. **숫자:** 작은 흰 숫자가 겹겹이 쌓임, 치명타는 빨강·분홍.
5. **파편:** 맞을 때마다 작은 조각(잎·어두운 파편·금화)이 포물선으로 튐.
6. **피격 반응:** 소형 적은 위로 띄워지거나 밀려나고 흰색 번쩍.
7. 카메라 흔들림은 평타에 거의 안 보이고 폭발·강타에서만.
캡처 원본은 `Docs/ArtCompare/Skul/` 에 메모만 둔다(영상 프레임 저장 안 함, 저작권).
