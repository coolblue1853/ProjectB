# 1~4층계 본무대 콘텐츠 (확정 2026-10-30)

> 사용자(10-30): "각 층계에 핵심이 되는 콘텐츠가 있으면 좋겠다, 다른 층계에서도 할 수 있더라도." / "1~4 정도까지 확정지어서 해보자. 4층계는 장비 강화 위주로 크게 열리는 느낌으로."
> 상위 배정표는 `TowerWorld.md` §20. 수치는 GPT 초안(v0.1)을 채택하고, 메인이 우리 구조에 맞게 고친 곳은 **[조정]**으로 표시했다.

## 0. 성장축

레벨이 없으므로 층계마다 다른 숙련으로 성장한다: 1층계 탐험(채집·추적) → 2층계 이동(활공) → 3층계 원정·대형 보스(원양 낚시) → 4층계 **장비 완성(강화 대개방)**. 1~3층계에서 모은 계보 장비를 4층계 대장간에서 완성하는 흐름이 장기 목표다.

| 층계 | 본무대 | 반복 플레이 | 장기 보상 |
|---|---|---|---|
| 1 외곽 숲 | 채집·흔적 추적 | 희귀 군락·정예 둥지 추적 | 계보 장비, 희귀 재료 |
| 2 언더 클라우드 | 풍향 활공 | 기류 코스 기록 | 활공 장신구, 기사·용 계보 |
| 3 인클루드 클라우드 | 원양 낚시 | 출항·어장·'주인' 낚시 | 주인 계보 무기 |
| 4 오버 클라우드 | 장비 강화 대개방 | 고급 강화·단조·각인·세트 승급 | 과거 장비의 최종 육성 |

## 1. 1층계 — 채집·흔적 추적 본무대 확장

입문판(MiniGames.md ③~⑥)은 그대로 두고 아래 3개를 더한다.

| 추가 | 규칙 | 보상 |
|---|---|---|
| ① 희귀 군락 | 맵마다 2~3곳. 채집 완벽 3연속이면 숨은 자원 발견 30% | 희귀 재료 1~2, U 재료 5% |
| ② 정예 둥지 추적 | 흔적 3개 연결 → 둥지 발견(40~60초). 기존 흔적 추적의 상위판 | 정예 확정 출현(기존 정예 보상 그대로 — 강화석 1~2 + 드롭표 장비 1) |
| ③ 생태 도감 의뢰 | 몬스터별 흔적 3회 + 고유 재료 5 납품 | 층계 결정 3 + 계보 재료 2 |

- 플레이 목표: 5분 = 채집 3~5·흔적 1 / 15분 = 희귀 군락 1·정예 추적 1 / 30분 = 정예 추적 2~3·도감 의뢰 1.
- [조정] 도감 의뢰는 기존 도감 창(B, `BestiaryWindow`)에 탭으로 붙인다.

## 2. 2층계 — 풍향 활공

| 항목 | 값 |
|---|---|
| 시작 | 공중에서 점프 키 0.2초 홀드(떼면 일반 낙하) |
| 낙하 | 기본 −5.0 u/s, 활공 −1.3 u/s |
| 수평 | 지상 이동속도 85%, 순풍·역풍 ±1.5 u/s |
| 기류 | 상승(약) +1.8, 상승(강) +3.5, 하강 −3.0 u/s. 기류 이탈 시 수직속도 0.4초 감쇠 |
| 지속 | 최대 12초, 상승 기류 안에서 초당 3초 회복(상한 12), 착지 시 초기화 |
| 상승 부하 | 저항 부족 시 지속 −10~20%(진입은 막지 않음) |

| 코스 | 길이·시간 | 기믹 | 기본 보상 |
|---|---|---|---|
| 초급 부유석 회랑 | 150m / 40~70초 | 상승 기류 3 | 층계 결정 2 |
| 중급 무너진 성벽 | 250m / 70~110초 | 순풍·역풍·가시 | 결정 3 + 기사 재료 2 |
| 상급 용의 상승로 | 400m / 100~160초 | 움직이는 기류·용의 돌풍 | 결정 5 + 용 비늘 1 |

- 평가: C 완주 ×1 / B 기준 시간 안 ×1.2 / A 85% 안·추락 0 ×1.5 / S 70% 안·추락 0·바람 문장 전부 ×2(내림). S 첫 달성 = 활공 장신구 U 도면 1회.
- 추락 = 직전 체크포인트 재시작, 평가 한 단계 하락.
- [조정] "하루 첫 완주 100%·이후 50%"는 실시간 날짜 대신 **게임 내 하루(낮/밤 1주기)** 로 센다. 활공은 2층계 진입 후 어디서나 쓸 수 있는 이동 능력으로 해금(1층계에서도 사용 가능 = 입문판 없음).

## 3. 3층계 — 구름바다 원양 낚시

흐름: 항구 → 보급 구매 → 어장 선택 → 출항 → 낚시·선상 사건 → 귀항 → 정산.

| 항목 | 값 |
|---|---|
| 출항 | 300G + 보급품 1(개당 200G, 최대 3) |
| 원정 | 8분(실제 플레이), 어획 기회 6회. 보급 1개 추가 = +4분·+3회 |
| 선상 사건 | 원정당 1~2회(습격·난파선 탐색·기상 이변) |
| 중도 귀항 | 획득물·미사용 보급 100% 보존 |
| 선박 파손 | 획득물 70% 보존, 강제 귀항 |

| 어장 | 특징 | 일반/희귀/주인 | 대표 희귀 |
|---|---|---|---|
| 백운 산호초 | 입문, 잔잔 | 75/22/3% | 구름비늘 송어 R(상승 저항 요리) |
| 천둥 해류 | 빠른 물살·번개 | 65/29/6% | 뇌광 장어 U(번개 계보 무기) |
| 심연 구름구멍 | 최고 난도 | 55/35/10% | 심연 유영어 U(고급 요리·세트 재료) |

'주인' 낚시 — 입문 낚시 장력 규칙의 확장:

| 요소 | 일반 | 주인 |
|---|---|---|
| 시간 | 20~50초 | 90~150초 |
| 물고기 체력 | 100 | 300(70%·30%에서 페이즈 전환) |
| 안전 장력 | 35~70 | 1페이즈 30~75 / 2페이즈 40~70 / 3페이즈 45~65 |
| 홀드 / 해제 | +28 / −22 per s | +26 / −24 per s |
| 안전 구간 체력 감소 | 5/s | 4/s, 취약(8~12초마다 2초) 중 ×2 |
| 끊김 | 한계 초과 | 위험 누적 2초 |

- 페이즈 2 돌진(장력 +15, 경고 0.8초), 페이즈 3 광폭(돌진 +20, 안전 구간 축소, 취약 1.5초).
- 완벽 포획 = 위험 누적 1초 이하·끊김 없음 → 주인 재료 +1, 희귀 장비 +5%p.
- 보상: 주인 재료 3~5 + 결정 3~5, 첫 포획 = 그 주인 계보 무기 도면(주인의 물살·번개·흡입 패턴을 무기 스킬로 복사 — 계보 규칙), 3종 모두 = 구름배 장식 + U 낚싯대 도면.
- [조정] 입문 낚시의 실제 장력 수치(시작 40, 누름 +18, 뗌 −24)와 다르다 — 주인 낚시는 따로 `FishingRules` 프로필로 둔다.

## 4. 4층계 — 장비 강화 대개방 (본무대, 가장 큰 축)

오버 클라우드 대장간 도시에서 강화 체계가 **구역을 진행할 때마다 하나씩** 크게 열린다.

| 구역 | 개방 | 첫 목표 |
|---|---|---|
| ① 잿빛 관문 | 고급 강화 +11~+12 | 고장 난 승강기 복구 |
| ② 제련 수로 | 정밀 단조, +13 | 제련 설비 재가동 |
| ③ 대장간 도시 | 재련, +14 | 장인 의뢰 3개 |
| ④ 기계 성소 | 각인·소켓, +15 | 기계 수호자 격파 |
| ⑤ 용광로 심장 | 세트 승급 I·II | 심장 보스 격파 |

### 4.1 고급 강화 +11~+15

기존 +0~+10(`EnhanceRules`, ProgressionDesign §3)은 그대로. 값은 기존 ES3 `upgrade` 정수에 그대로 저장한다.

| 목표 | +11 | +12 | +13 | +14 | +15 |
|---|---|---|---|---|---|
| 기본 성공률 | 65% | 50% | 35% | 25% | 15% |
| 층계 결정 | 5 | 6 | 7 | 8 | 8 |
| 골드 | 1,000 | 1,500 | 2,500 | 4,000 | 6,000 |
| 실패 | 단계 유지, 재료 소모 | | | | |

- 보너스: 무기 단계당 +4%, +15 달성 시 추가 +10%(무기 +15 = 총 +90%, +10 = +60%). 방어구 단계당 +5%(+15 = +75%).
- 천장 보조: +11 이상에서 연속 실패마다 다음 성공률 +2%p(최대 +10%p), 성공하면 초기화. ES3 `forge.pity`.
- 최종 성공률 상한 90%.

### 4.2 정밀 단조(망치 타이밍 3회)

채굴 타이밍 규칙을 재사용. 고급 강화 때 기본으로 수행한다(+10 이하는 기존 즉시 강화).

| 판정 | 오차 | 점수 |
|---|---|---|
| 완벽 | ±6% | 3 |
| 훌륭 | ±14% | 2 |
| 좋음 | ±25% | 1 |
| 빗나감 | 그 밖 | 0 |

| 3타 합 | 0~2 | 3~4 | 5~6 | 7~8 | 9 |
|---|---|---|---|---|---|
| 성공률 보너스 | +0 | +4%p | +8%p | +10%p | +12%p + 실패 시 결정 50% 반환(올림) |

- 단조를 못 해도 성장은 가능하고, 잘하면 자원이 덜 든다. 1회 6~9초.
- 기대 비용(3타 완벽 가정): +10 → +15 평균 결정 약 74·골드 약 41,000.

### 4.3 각인·소켓

| 등급 | 소켓 | 개방 비용 |
|---|---|---|
| C | 0 | — |
| R / U | 1 | 결정 3 + 1,000G / 결정 5 + 2,000G |
| L | 2 | 결정 8 + 4,000G |

| 룬 | 효과 | 재료(+공통 500G) |
|---|---|---|
| 화염 | 화염 피해 +6% | 화염 코어 2 |
| 수호 | 방어 +5% | 화염 코어 1 + 결정 2 |
| 생존 | 최대 HP +6% | 화염 코어 1 + 결정 2 |
| 상승 | 상승 부하 저항 +4 | 화염 코어 2 |
| 계보 | 그 몹 계보 스킬 피해 +8% | 계보 재료 3 + 화염 코어 2 |

- 장착·교체 무료, 기존 룬 보존 추출 = 500G + 결정 1. 추출 없이 덮어쓰면 기존 룬 소멸.

### 4.4 세트 승급 — 과거 계보 장비의 재탄생

| 대상(부위당) | 비용 | 결과 |
|---|---|---|
| 1층계 계보 세트 | 계보 재료 8 + 화염 코어 3 + 2,000G | 보정 I |
| 2층계 계보 세트 | 계보 재료 6 + 화염 코어 3 + 2,000G | 보정 I |
| 3층계 계보 세트 | 계보 재료 4 + 화염 코어 3 + 2,000G | 보정 I |
| 보정 I → II | 결정 8 + 화염 코어 6 + 5,000G(⑤ 보스 처치 후) | 보정 II |

| | 보정 I | 보정 II |
|---|---|---|
| 기본 공격·방어·HP | +20% | +35% |
| 상승 부하 저항 | +2 | +4 |
| 계보 스킬 피해 | +5% | +10% |

- 이름·등급·강화 단계·세트 ID·고유 스킬·룬은 그대로 이어진다. 승급 보정을 기본 스탯에 먼저 곱하고 강화 보너스를 계산한다.
- 낮은 층계 장비일수록 계보 재료를 더 요구 → 옛 구역 재방문 이유.
- 목표: 보정 II 장비의 기본 스탯은 같은 등급 4층계 장비의 90~95%. 대신 계보 스킬·세트 시너지가 선택 이유.

### 4.5 재련(옵션 재굴림) — [조정] 보류

- GPT 안: R/U/L·+5 이상 장비의 보조 옵션 1~3개 재굴림(800G + 결정 2 + 재련 가루 1, 잠금 1개당 결정 +2·가루 +1, 결과 거절 가능, 세트·계보·고유 스킬은 못 바꿈).
- **지금 장비에는 랜덤 보조 옵션 체계가 없다.** 옵션 체계(드롭 시 굴림·툴팁·세이브)를 먼저 만들어야 하므로 4층계 ③ 개방은 "재련 = 옵션 체계 도입 후"로 미룬다. 그 전까지 ③ 대장간 도시는 +14 + 장인 의뢰만 연다.

### 4.6 재화 균형

- 새 재료는 **화염 코어**(4층계 기계몹·보스)와 **재련 가루**(R 이상 분해·장인 의뢰) 2개만. 나머지는 층계 결정·계보 재료·골드.
- 30분 수급 목표: 결정 12~20 / 골드 5,000~9,000 / 화염 코어 4~7 / 재련 가루 3~5.
- 소모 비중 목표: 강화·단조 45% / 재련 20% / 각인 15% / 세트 승급 20%.

### 4.7 세이브(추가만, 기존 필드 이름 변경 없음)

| 키 | 타입 | 범위 |
|---|---|---|
| 아이템 `forgeGrade` | int 0~2 | 장비 인스턴스(세트 승급 단계) |
| 아이템 `socketRunes` / `openedSockets` | string[] / int | 장비 인스턴스 |
| 아이템 `reforgeOptions` | 옵션 배열 | 장비 인스턴스(재련 도입 때) |
| `forge.unlock` | int 비트 | 공용(구역별 개방) |
| `forge.pity` | int | 공용(천장 보조) |

- 없으면 기본값 0·빈 배열.

### 구현 (10-30, 4층계 고급 강화 +11~+15·정밀 단조)
- 코드 `Assets/Script/Item/`: `AdvancedEnhanceRules`(순수 표·천장·단조 점수·상한 90%) · `ForgeState`(ES3 공용 `forge.unlock` 비트 1/2/4/8·`forge.pity`, 공용 파일 `SaveFile.es3`) · `ForgeSession`(3타 판, 채집 `GatherRules` 커서 재사용) · `ForgeHammerView`(패널). `EnhanceService.TryEnhance(..., forgeScore)`·`EnhanceWindow` 가 연결. +10 이하 경로·수치·`enhanceFailStreak` 는 그대로.
- 게이트: 비트 없으면 +10 이 상한(지금과 동일 "최대 강화 완료"). 목표 11·12=비트1, 13=2, 14=4, 15=8. 4층계 구역 개방 때 `ForgeState.Unlock(bit)` 호출만 하면 된다(맵 미구현).
- 보너스: 무기 단계당 +4%·+15 추가 +10%(+15 = +90%), 방어구 단계당 +5%(+15 = +95%, 임시 가정 — 표의 "+75%" 는 +11~+15 구간 증가분으로 해석).
- 정밀 단조: 강화 창에서 +10 이상 장비 선택 → 공격 키 3타(타당 3초 제한, 시간 초과=빗나감) → 끝나면 재료·골드 소모 후 굴림. ESC 는 소모 전까지 손실 없음. 9점 실패 시 결정 절반(올림) 반환.
- 검증: EditMode 257/257(`AdvancedEnhanceRulesTests` 신규, +0~+10 회귀 포함). 플레이 `Tools/probes/forge_run.cs`: 비트 없음 CanTry=MaxLevel → 비트1 → 3타 완벽 9점, 실패(Rng 고정) 성공률 77%·결정 5 소모 3 반환(33→31)·골드 −1000·pity 1, 단조 0 실패 pity 2·환급 0, 성공 lv 10→11·pity 0·무기 배율 1.64. 스크린샷 `Logs/playtest/forge_panel.png`.

## 5. 구현 순서

4층계·3층계 맵은 아직 없다. 맵이 없어도 만들 수 있는 **시스템을 먼저** 만들고, 해금은 `forge.unlock` 같은 플래그로 막아 둔다(디버그 프로브로 열어 검증).

| 순서 | 항목 | 재사용 | 비고 |
|---|---|---|---|
| 1 | 2층계 풍향 활공(이동 능력 + 기류 구역 컴포넌트) | 플레이어 공중 이동 | 2층계 맵(무너진 성벽)에 초급 코스 1개 |
| 2 | 4층계 고급 강화 +11~+15 + 정밀 단조 | `EnhanceRules`, 채굴 타이밍 | 기존 대장장이 강화 창 확장, `forge.unlock` 으로 잠금 |
| 3 | 1층계 정예 둥지 추적 | 흔적 추적·정예 승격 | 입문 추적의 상위판 |
