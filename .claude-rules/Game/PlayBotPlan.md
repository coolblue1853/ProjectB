# 자동 플레이 봇 계획 (11-15)

목표: 사용자 플레이 기록으로 학습한 **사람처럼 노는 봇**을 만든다. 봇은 가상 키보드·패드로 진짜 입력만 넣는다. 치트·순간이동·위치 직접 변경·내부 함수 직접 호출은 금지한다.
봇의 쓰임: 사람 대신 플레이테스트를 해서 막힘·오류·밸런스 이상을 보고한다. 같은 일을 할 때마다 Claude 토큰을 아끼는 것이 목적이다.
예산: 이번 주는 이 일만 한다(상한 100%, 11-15 기준 43%에서 시작). 단계마다 끝나면 `get_usage` 기록.
구현 형식·로그 표는 `PlayBotDesign.md`(R1 산출물)에 둔다. 이 문서는 단계 계획이다.

## 원칙
- **많이 기록하고, 적게 읽는다.** 원본 jsonl 은 디스크에만 둔다. Claude 는 요약 md·그래프 PNG 만 읽는다.
- **학습 가능한 형태:** 고정 틱마다 "그때 본 것(관측) + 그때 누르고 있던 키(행동)"가 한 행에 같이 있어야 한다. 이벤트만으로는 모방 학습이 안 된다.
- **기록은 플레이테스트 보고서도 겸한다.** 사람 기록 하나로 봇 학습 자료와 UX 문제 목록을 같이 얻는다.
- **봇도 같은 형식으로 기록한다**(src=bot). 사람과 봇을 같은 요약기로 비교한다.

## 기록기 단계

### R1 기본 (진행 중)
입력 이벤트, 10Hz 상태, GameLog 미러, 경고·예외·막힘, `Tools/playrec_summary.py`.

### R2 학습용 확장 (사용자 플레이 전에 끝내는 것이 목표)
1. **고정 틱 학습 행 `k:"tk"` 20Hz:** 누르고 있는 액션 비트마스크(이동 축 포함) + 관측 벡터. 이벤트 입력은 R1 그대로 둔다.
2. **지형 격자:** 플레이어 주변 가로 24 × 세로 14칸(1칸 = 1유닛)을 발판·벽·로프·사다리·빈칸·위험으로 표시한다. 바뀔 때만 기록하고 해시로 줄인다. 발판 끝까지의 거리, 아래 낙하 높이도 넣는다.
3. **적 상세:** 가까운 적 6마리. 종·위치·속도·HP%·상태(대기·추적·공격 예고·공격 중·피격·사망)·공격 판정 활성 여부·플레이어와의 거리. 투사체는 위치·속도.
4. **공격 예고 → 반응:** 적 공격 예고가 시작된 시각, 플레이어가 피했는지·맞았는지, 그 사이 입력(점프·대시·후퇴·무시)을 기록한다. 회피 습관 학습용.
5. **전투 결과:** 준 피해의 치명타·넉백·콤보 단계, 스킬 쿨다운 상태, 버프 목록, 무적 시간.
6. **UI 의사결정:** 열린 창, 포커스된 버튼·슬롯 경로, 메뉴 이동 입력. 결정 이벤트로 산 것·판 것·장착한 것과 그 전후 스탯, 스킬 투자, 퀵슬롯 배치, 버린 것을 남긴다. 상점 화면에서 무엇을 보고 무엇을 골랐는지도 남긴다.
7. **진행 맥락:** 활성 퀘스트·목표 진행도, 가방 칸 여유, 포션 수량, 다음 레벨까지 EXP%, 현재 장비 요약, 낮/밤.
8. **사람 신호:** 연타(같은 키 0.15초 안에 3번 이상), 제자리 왕복, 창 열었다 바로 닫기, 일시정지, 3초 넘는 무입력. 막힘·혼란·지루함 후보로 쓴다.
9. **북마크 F8:** "여기 이상해" 키를 누르면 그 순간의 상태 전체와 스크린샷을 남긴다(`Logs/playrec/<세션>/mark_NN.png`). 패드는 Select+R3. 다른 키와 충돌하는지 `InputAudit.md` 로 확인한다.
10. **플레이 영상(11-15 사용자: 주기 스샷 대신 영상):** 게임 화면을 640×360·15fps 로 줄인 RenderTexture 를 `AsyncGPUReadback` 으로 읽어 ffmpeg(winget 설치본, PATH 에 있음) 표준입력으로 보내 H.264 mp4 로 굽는다(crf 30 안팎, 30분 ≈ 100MB 이하 목표). 창 캡처가 아니라 게임 내부 캡처라 창이 가려져도 된다. 영상 시작 시각과 1초마다 프레임 번호를 jsonl 에 `k:"vf"` 로 남겨 로그 시각 ↔ 영상 시각을 맞춘다. 분석 때는 이벤트 시각의 프레임만 ffmpeg 로 뽑아 본다(영상 통째로 보지 않는다). ffmpeg 가 없거나 실패하면 녹화만 끄고 기록은 계속한다. F8 북마크는 영상과 별개로 원본 해상도 PNG 를 남긴다.
11. **성능:** 프레임 시간, 50ms 넘는 끊김, GC 할당 급증.
12. **세션 메타:** 시작 레벨·맵·장비, 빌드 해시(git), 해상도, 입력 장치.

### R3 분석 도구
1. **요약기 확장:** 세그먼트 자동 분류(사냥·줍기·이동·마을 업무·메뉴·휴식·막힘). 세그먼트별 시간과 전환 순서를 낸다.
2. **사람 버릇 모델 추출 `Tools/playrec_fit.py`:** 반응 시간, 키 누름 시간, 공격 간격, 회피 반응, 목표 선택 규칙(가장 가까운 적인지, HP 낮은 적인지, 드롭 먼저인지), 포션 쓰는 HP%, 귀환 조건(가방·포션)을 분포·임계값으로 뽑아 `Assets/Resources/Bot/human_profile.json` 으로 낸다.
3. **타임라인 그래프:** matplotlib 이 있으면 세션 하나를 PNG 1장으로(위치·HP·입력·이벤트). Claude 는 이 그림만 본다.
4. **입력 재생 봇 B0:** 기록된 입력을 가상 장치로 같은 시각에 다시 넣는다. 가상 입력 경로가 진짜 입력과 똑같이 동작하는지 검증하는 단계다(게임이 결정론적이 아니므로 결과는 달라도 된다).

## 사용자 플레이
- R2 가 끝나면 플레이한다. R2 전에 플레이해야 하면 R1 기록도 쓸 수 있다.
- 30분을 한 번보다는 **10~15분씩 2~3번**이 낫다(시작 상태가 다양해진다). 사냥만 하지 말고 마을 업무(상점·장비·퀘스트)도 섞는다.
- 이상한 곳에서는 F8 을 누른다. 말 없이 평소처럼 하는 것이 가장 좋다.

## 봇 단계
### B1 몸: 가상 입력 + 인지
`InputSystem.AddDevice` 로 가상 Keyboard/Gamepad 를 만들어 `QueueStateEvent` 로 키를 누른다. 사람 버릇 모델로 지연·누름 시간·흔들림을 넣는다.
인지는 기록기의 관측 코드를 그대로 재사용한다(같은 관측 = 같은 학습 자료). 실행 스위치는 `PlayBot.Run(minutes, goal)` 이고, 프로브·메뉴에서 켠다.

### B2 손발: 동작
- **11-15 구현(`PlayBotDesign.md` 11절):** 반응 1.24초 합격, 막힘 15(B1 27), 맵 이동 1. 남은 것: 계단 모서리 고착(게임 쪽 TechDebt), 포션 실사용·Lv3 세이브 미검증.
- **이동:** 맵 발판·로프·포털로 이동 그래프를 만든다. 이동 그래프는 맵 데이터로 미리 굽고, 런타임에는 읽기만 한다. 점프·하향점프·로프 타기를 진짜 입력으로 한다.
- **전투:** 목표 선택 → 간격 맞추기 → 평타·스킬 → 공격 예고 회피. 규칙과 임계값은 사람 버릇 모델에서 가져온다.
- **기타:** 줍기, 포션.
- **실패 처리:** 3초 진척이 없으면 다른 길로 가고, 그래도 안 되면 막힘으로 보고한다.

### B3 머리: 목표
퀘스트 따라가기, 가방·포션 상태에 따른 귀환·판매·구매, 더 좋은 장비 장착, 맵 이동 순서. 사람 세그먼트 전환 순서를 참고한다.
메뉴는 진짜 메뉴 입력(방향키·확인)으로 조작한다.
- **11-16 B3 축소판 구현(`PlayBotDesign.md` 12절):** 귀환 판단·귀환 주문서/포털 이동·마을 장착·상점 판매(J 일괄 + 메뉴 칸 판매)·H 충전 구매. 15분 실행: 왕복 1, 판매 11, 구매 97, 장착 2, 사망 0. 퀘스트 따라가기는 후속.
- **11-16 B3 보완·B4 자동 보고(`PlayBotDesign.md` 13절):** 메뉴 직접 구매(HP 물약만, 골드 25~35%)·단계 시간 제한 진척 갱신·닿지 않는 드롭 무시·귀환 주문서 실사용 확인. 30분 합격 실행(Lv3·마을 시작): 처치 479(15.7/분)·왕복 3·판매 19·구매 96·장착 2·중단 0·사망 1. `bot_run.sh` 끝에 `_report.md` 자동 생성(`Tools/playrec_report.py`).
- **11-16 B3 퀘스트 따라가기(`PlayBotDesign.md` 15절):** 처치 퀘스트 목표 몹 맵·몹 우선, 완료 가능 퀘스트는 NPC 앞에서 진짜 입력(↑·선택지·Select)으로 보고. 20분(Lv3): 처치 408·퀘스트 완료 1(Q106)·막힘 11·사망 0. 수락 경로·맵 이동 경로는 미검증, 계단 막힘 미해결.

### B4 학습·검증
- **비교:** 사람과 봇 기록을 같은 요약기로 대조한다(반응 시간·공격 간격·세그먼트 비율·처치/분). 차이가 큰 항목부터 고친다.
- **모방 실험:** 미세 판단(언제 점프·회피·공격)에 kNN 또는 결정 트리를 사람 tk 행으로 학습한다. 표로 내보내 C# 에서 조회하고, 규칙과 비교해 나은 쪽을 쓴다.
- **자동 밸런싱(11-15 사용자):** 봇 실행 결과를 `Tools/playrec_balance.py` 로 몹·맵·낮밤별 처치 시간·피해·EXP·드롭/분 표로 만들어 기준선과 비교한다. 수정안을 CSV 에 반영한 뒤 봇을 다시 돌려 지표가 목표 범위에 드는지 확인한다. 이 반복은 사람 개입 없이 돈다. CSV 반영은 규칙상 커밋 전에 요약을 남긴다.
- **자동 플레이테스트 보고:** `Tools/bot_run.sh <분>` 한 번으로 봇 실행 → 요약 md(막힘·예외·사망·밸런스 지표·F8 대신 봇이 남긴 이상 지점 캡처)를 만든다. 이후 플레이테스트는 이 명령 하나와 md 읽기로 끝낸다. **11-16 구현 완료**(`<세션>_report.md`, 사람 기준 대비 ▲▼ 표시).

### B5 무인 플레이테스트 (11-16 사용자: 이번 주 목표, 사용자 플레이테스트 없이 돌아가게)
하루 12% 상한 안에서 아래 순서로 진행한다. 각 항목은 builder 1개, 끝나면 `bot_run.sh` 보고서로 확인한다.
1. **진행 봇:** 1층계를 마을부터 층계 끝까지 진행한다. 퀘스트 수락 경로, 맵 이동 순서, 레벨업 뒤 스킬 투자, 장비 교체가 대상이다. 합격 기준: 신규 세이브로 60분 무인 실행 시 Lv·퀘스트 진척이 사람 기록 곡선의 0.5~2배. **(11-17 무효 주의: PREP_LEVEL 이 장비를 초기화하지 않아 봇 수치·곡선 무효, `Docs/Handoff/bot_fresh_start_1118.md`) (11-17 진척: 길찾기 층 충돌 수정(Travel 이 퀘스트·귀환 중 쉼), 퀘스트 3종 완료 확인, 60분 곡선 비교는 미실시)** **(11-17 B5 추가: 곡선 비교 스크립트 `Tools/playrec_curve.py`·파괴물 제외·월드 밖 드롭 무시·급격 피해 물약 완료. 단 90분 런 결과는 전부 무효 — `PREP_LEVEL` 이 장비를 초기화하지 않아 Lv1 봇이 후반 장비 착용. 다음: `PREP_FRESH=1` 구현 후 재측정, 18절)**
2. **장시간 안정성:** 60~120분 무인 실행에서 중단·UI 갇힘·예외가 0이어야 한다. 갇히면 스스로 창을 닫고 복구하며, 복구 횟수는 보고서에 낸다. **(11-17 진척: 90분 런 처치 948·퀘스트 3/3 완료·Lv9·사망 3·예외 0·UI 복구 1·귀환 중단 1(360초로 완화, 재실행 필요) — `PlayBotDesign.md` 17절)**
3. **이상 탐지 보고서:** 막힘·예외·사망·UI 갇힘·성능 끊김마다 위치와 캡처를 남긴다. 기존 보고서와 비교해 회귀(▲)를 표시한다.
4. **UI 기능 순회:** 창고·제작·요리·강화·빠른 이동 등 장르 기본 기능을 한 번씩 써 보고 실패를 보고한다.
5. **자동 밸런스 반복:** 수치 수정 → 봇 재실행 → 지표 비교를 사람 개입 없이 돌린다. CSV 반영은 사용자 확인 뒤에만 한다.
6. **남은 막힘:** 몹 되돌림, y=14 정지, NoPath 막힘(`PlayBotDesign.md` 15.7·15.8).

## 합격 기준
- 봇이 1층계 마을에서 시작해 30분 동안 사람 개입 없이 사냥·귀환·판매·퀘스트 진행을 한다. 치트·순간이동은 0회다.
- 사람 대비 주요 지표가 2배 안에 들어온다. 막힘은 보고서에 위치·스크린샷과 함께 나온다.
- 이 실행의 Claude 비용은 요약 md 를 읽는 것뿐이다.
