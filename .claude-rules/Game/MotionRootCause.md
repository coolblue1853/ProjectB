## 2. 과정의 문제(내 작업 방식)

- **생성 결과를 보고 고치는 순서가 거꾸로였다.** 키를 뽑고 → 사이를 뽑고 → 문제가 보이면 다시 뽑았다. 생성은 매번 새 그림이라 앞에서 맞춘 것(손·비율·위치)이 다시 흔들리고, 크레딧이 많이 들었다.
- **판정을 접촉 시트(정지 그림)로 했다.** 게임에서 움직이는 모습(앞뒤 이동·리듬·이어짐)을 수치로 재지 않았다. 위 1·2·3·6은 숫자로 재면 바로 보였을 문제다.
- 성공 기준(§7.1)에 "몸이 공격 방향으로 나아간다", "장비가 프레임마다 같은 모양", "콤보 연결", "완급"이 빠져 있었다.

## 4. 성공 기준 추가(§7.1에 더할 것)

10. 공격 중 몸 중심(머리 x)은 공격 방향으로만 움직인다(뒤로 3px 넘게 빠지면 불합격, 피격 제외).
11. 장비 레이어(투구) 픽셀 수가 대기 대비 ±5% 안.
12. 프레임 시간에 완급이 있다(준비 ≥ 타격 × 2).
13. 콤보는 앞 타의 끝 자세에서 다음 타가 시작한다(대기로 돌아가지 않음).
14. 판정은 게임 영상 + 위 수치 자동 검사로 한다(접촉 시트만으로 통과시키지 않는다).

## 5. PixelLab 도구 재조사(10-27, search_help + 도구 설명)
- 잔량: 914/2,000 생성(11-25 리셋).
- **animate_with_skeleton_v3**: 그림 한 장 + 프레임마다 COCO-18 관절 좌표(직접 작성)를 주면 그 자세대로 그린다. 4~14프레임 = 3생성(지금 방식: 키 3장 15 + 구간 3~4개 = 약 20생성). 모든 프레임을 같은 원본 한 장에서 그려 비율·얼굴이 덜 흔들리고, **자세(다리 폭·몸 기울기·손 위치)를 우리가 숫자로 정한다** → 1번(뒤로 물러남)·8번(튀는 사이 프레임)·손 전환을 설계 단계에서 막을 수 있다. 첫 프레임 관절(first_frame_keypoints)도 직접 적어야 한다(자동 추정 API 는 토큰 필요, MCP 없음). 첫 프레임은 내부에서 다시 그려 픽셀 동일은 보장 안 됨.
- 칼은 생성 그림에 넣지 말고 지금처럼 게임에서 따로 붙이는 게 가장 안정적(공식 답변도 같음) → 초안은 **맨손**으로 생성하면 칼 지우기·재채색·손 오독 문제가 통째로 사라진다.
- 장비(투구)는 PixelLab 결과가 레이어로 안 나와 프레임 전이 시 출렁임이 남는다 → 투구는 대기 투구 한 장을 머리 위치·기울기로 옮겨 붙이는 쪽(생성 0)이 맞다.
- **pixelart_workbench 는 무료**: inspect·edit(정밀 재채색)·repair(잡티 정리)·lint(외톨이 픽셀) — 재채색에 쓰던 edit_image_pro_flash(5생성/장)를 대체.

## 7. v3 피드백과 다음 작업(10-27, 사용 한도로 여기서 멈춤)
사용자 규칙: ① 신체 부위가 잘리거나 커지거나 작아지면 안 됨(비슷한 자세면 같은 크기) ② 칼 든 손 위치가 튀면 안 됨 ③ 투구 빼고 기본 복장 ④ 머리카락이 이상해지면 안 됨. "GPT 와 더 이야기하고, 안 되면 PixelLab 도 써도 됨."
GPT 2차 토론(`Docs/ArtCompare/Motion/cel/basic_sword/gpt_round2.md`) 요지: 손은 칼 직선에서 역산하지 말고 준비·타격·마무리 셀의 **쥐는 중심을 수동 확정**, 공용 주먹 2종으로 통일, 손 위치와 칼 각도를 같은 키에서 지정, 다음 걸림은 1→2타 사이 몸 높이 변화·올려베기 중 몸 그림 교체감.
측정한 사실:
- 손 좌표(칼날 시작점)가 실제 주먹보다 6~8px 앞(찌르기 1~4: 기록 46,39 / 실제 주먹 약 38,40) → 칼이 손에서 떨어져 보이고 손이 움직이는 것처럼 보인다.
- 주먹 레이어 픽셀 수: 대기·걷기 41~48, 공격 0~12 → 칼에 손이 덮여 손이 작아지거나 사라진다.
- 찌르기 런지 프레임(5·6)은 머리카락 덩어리가 대기보다 커 보인다(초안 차이).
다음 순서(생성 0 우선):
1. `Tools/probes/rig_combo_video.cs` 의 `__BARE__` 를 1로 바꿔 맨몸 촬영(투구 제외), 기본 표시도 장비 끔.
2. 공격 셀별 주먹 중심을 격자 이미지(`grid_<클립>.png` 방식: 셀 확대 + 4px 격자)로 직접 읽어 `HAND_KEYS` 표로 고정 → 칼 피벗을 주먹 중심에.
3. 주먹 레이어를 대기 주먹 한 장(공용 주먹)으로 찍어 크기 통일.
4. 자동 검사 스크립트: 프레임마다 머리 폭·머리카락 면적·주먹 면적·몸통 면적을 대기와 비교(±5% 넘으면 표시) → 넘는 프레임은 빼거나 머리 영역을 대기 머리로 교체(머리 앵커 합성, 생성 0).
5. 그래도 안 되는 프레임만 PixelLab(모션당 30생성 이하).
