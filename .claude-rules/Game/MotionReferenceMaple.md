# 비슷한 환경 레퍼런스 — 메이플스토리 몸 동작 체계 (10-29 사용자: "비슷한 환경에서 동작이 잘 어울리는 레퍼런스")

자료: Nexon Open API 공지(2025-01-16, 캐릭터 이미지 action 파라미터 목록) + maplestory.io 커뮤니티 렌더러로 받은 34동작 전 프레임(`C:\Users\user\MapleRef\act`, 시트 `sheet_actions.png`, 받기 `fetch.py`). **참고 전용, 저장소 밖, 커밋 금지**(스컬·림버스와 같은 규칙).

## 왜 메이플인가
- 2~2.5등신 측면 캐릭터 + 무기는 손에 붙는 별도 그림 + 장비는 부위 레이어 — 우리 구조(셀 몸 + 손 앵커 무기 + 던파식 레이어)와 가장 같다.
- 수백 개 직업이 **몸 동작 34개를 공유**하고 스킬 차이는 이펙트로 낸다(사용자 방향 "이펙트로 대부분 돌아간다"와 같음).

## 34동작 (프레임 수)
- 이동·상태: stand1/2(3), walk1/2(4), alert(3), jump(1), prone(1), proneStab(2), fly(2), sit(1), ladder(2), rope(2), heal(3), dead(1)
- 한손(O): swingO1·O2·O3(각 3), swingOF(4, 마무리) / stabO1·O2(2), stabOF(3)
- 양손(T): swingT1·T2·T3(3), swingTF(4) / stabT1·T2(3), stabTF(4)
- 폴암(P): swingP1·P2(3), swingPF(4)
- 원거리: shoot1(3, 활), shoot2(5, 석궁·총), shootF(3)
- → **같은 휘두르기도 무기 쥠(한손·양손·폴암)마다 변형**이 있고, 각 변형은 3프레임이다.

## 우리 실패(10-29 사용자: 기본·칼 3타 외 대부분 불합격)와 비교
| 항목 | 메이플 | 우리 새 동작(10-29 생성분) |
|---|---|---|
| 프레임 수 | 공격 2~4장 | 9~13장(보간) |
| 자세 크기 | 키 포즈가 극단적(무기 끝이 머리 위 → 앞 아래로 몸 밖까지) | 머리 이동 2~13px, 몸 거의 그대로 — 졸라맨 설계가 작았다(생성기는 키를 평균 1.06배로 정확히 따름, 측정) |
| 실루엣 주인공 | **무기**(몸은 기울기 조금, 무기 궤적이 크다) | 몸·팔 위주, 무기 각도는 키 칼 각도 → 대검이 머리 뒤로 수평 눕는 프레임 |
| 무기 쥠 변형 | 한손·양손·폴암 별도 | 무기 상관없이 한 셀 |
| 로프·사다리 | 뒷모습 2장, 몸 크기 같음 | 예전 셀(크기 다름) |
- 기본 칼 3타가 통과한 이유도 같다: 7프레임 안팎, 준비·타격 자세를 크게, 칼 각도를 그림에서 읽음.

## 다시 만드는 규칙(제안)
1. 동작마다 **키 포즈 3~4장**(준비 → 타격 → 끝/회복) + 유지 시간으로 완급. 보간 프레임을 늘리지 않는다(림버스 관찰과 같음).
2. 키 포즈는 **무기 끝 위치부터** 정한다: 준비 = 무기 끝이 머리 위·뒤, 타격 = 앞 아래 몸 밖. 몸은 그 무기를 들 수 있게 따라온다.
3. 무기 쥠별 변형(한손 O·양손 T·폴암 P·찌르기·사격)을 39개 안에서 나눈다 — 메이플 34개와 대응표를 만들어 빈 곳만 우리 것(던지기·시전·잡기 등)으로.
4. 레퍼런스 3칸 비교: 메이플 프레임 · 스컬/림버스 · 우리 졸라맨 → 생성(3~4프레임은 PixelLab 2~3회).
5. 로프·사다리는 뒷모습 규격(몸 크기 동일)으로 다시.
