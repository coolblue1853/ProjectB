# 주인공 마스터 모션 목록(던파식 고정 개수)

10-27 사용자: "옷이 바뀌어도, 무기를 바꿔도 되어야 하니 던파 방식으로 간다. 모캐릭터 모션이 일정 개수를 넘으면 안 된다. 모션이 10개인 상태에서 11개째가 생기면 지금까지 만든 방어구마다 하나씩 다 추가해야 한다. 그러니 모션을 먼저 전부 만들고, 그 뒤에 방어구를 쌓는다. 그러려면 스컬 모션을 가능한 한 많은 머리(직업)로 확인해야 한다."

근거 자료는 `SkulReference.md`다. 스컬 머리 목록은 나무위키 스컬 문서를 전부 읽어 정리했다(§1). 영상 프레임 분석은 4절에 있다.

## 1. 스컬 머리(직업)별 공격 형태 → 모션 계열

| 계열 | 스컬 예 | 평타 / 공중 | 대표 스킬 모션 |
|---|---|---|---|
| 한손 둔기·검 | 리틀 본, 해골 검병→근위대장, 노예→반신, 사무라이 | 2~3타(내려치기 → 역방향 휘두르기 → 찌르기), 공중 내려치기 | 3연 찌르기, 돌진 찌르기, 백스텝 후 베기, 회전 베기, 발도(선 베기) |

| 대검·둔중 | 전사, 미노타우로스, 엔트, 묘지기, 바이킹 | 느린 평타·모아 치기, 공중 내려찍기 | 올려베기, 점프 내려찍기, 강타, 돌진 찌르기, 지면 충격파 |
| 단검·속도 | 좀도둑→무법자, 닌자 | 빠른 연타, 공중 연타 | 뒤로 구르기, 뒤로 순간이동 베기, 연속 베기 |
| 발톱·맨손 | 웨어울프, 진(3타 주먹), 구울(갈고리) | 빠른 할퀴기·주먹 3타 | 도약 할퀴기, 물어뜯기 돌진, 거대 주먹 |
| 지팡이 | 손오공(석원숭이) | 연타·찌르기 | 회전, 내려찍기, 분신 |

| 원거리 활·총 | 사냥꾼, 미라(권총) | 연사·차징 | 부채꼴 연사, 관통, 화살비, 뒤로 빠지며 쏘기 |
| 투척 | 광대(단검), 연금술사(플라스크), 리틀 본(머리) | 던지기 연사, 공중 던지기 | 폭탄·병 던지기, 흩뿌리기 |
| 소환·변신 | 칼레온 신병(병사 소환), 폭탄병, 라이더 | 본체 모션 최소 | 소환 손짓, 돌진 탈것 |

## 2. 공통 모션으로 묶기

스컬은 머리마다 몸 전체를 새로 그린다. 우리는 던파식이라 몸 모션 하나를 여러 무기가 나눠 쓴다. 무기는 손 소켓에 붙고 칼날 각도는 셀에서 읽는다(PixelRig). 그래서 **무기가 달라도 손·몸 궤적이 같은 동작은 한 모션으로 묶는다.** 무기 고유의 느낌은 이펙트·속도·무기 그림이 낸다.

## 3. 마스터 모션 목록(고정 31개)

- 31개를 다 만든 뒤에 방어구를 입힌다. 방어구 한 벌 비용은 31모션 × 약 7프레임 ≈ 220프레임이다. 전이 1회가 15프레임까지라 약 15회, 즉 약 150 gen이 든다. 지금 철 세트는 이동 12 + 공격 7만 입혔다.
- 새 모션은 지금 셀 파이프라인을 그대로 쓴다. 칼을 쥔 기준 그림에서 PixMiniMax 측면 생성 → `build_cel` 칼 지우기·각도 읽기 → 장비 전이.
- 앞으로 무기·스킬을 더할 때는 **이 31개 안에서 고른다.** 새 모션이 꼭 필요하면 먼저 이 표를 고치고 사용자에게 확인받는다.
