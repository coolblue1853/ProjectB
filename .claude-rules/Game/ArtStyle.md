- 생성물은 모두 아래 **고정 규격**으로 만든다. 몹마다 바꾸는 것은 형태·포인트 색 하나뿐.
  1. **밀도·크기**(2026-10-25 개정): 16도트/유닛. 캐릭터 32×32, 일반 몹 32~48px, 정예 48~64px, 보스 64~96px(초대형 128). 생성 해상도를 섞지 않는다(작게 만든 걸 키우거나 큰 걸 줄여 섞지 않음).

  4. **팔레트**: 공용 마스터 팔레트(저채도 이끼 초록·돌 회색·청회색·탁한 갈색 + 발광 포인트 청록·호박·연보라)에서 몹당 16색 이하. 포인트 색은 1~2개, 눈·핵·룬 같은 **점**에만.

  6. **PixelLab 파라미터 고정**: 위 "PixelLab 경로"의 값(`create_image_pixflux`, `view=side`, `direction=east`, `outline=selective outline`)을 모든 몹·캐릭터에 그대로 쓰고, 프롬프트 끝에 같은 스타일 꼬리말을 붙인다: `"dark fantasy pixel art, muted desaturated palette, single glowing accent, selective outline, top-left light, no anti-aliasing"`.
  7. **스타일 앵커**: 첫 결과물 중 사용자가 고른 1장(예: 숲 늑대)을 앵커로 삼아, 이후 생성은 앵커와 나란히 비교 시트(`Docs/ArtCompare/`)를 만들어 도트 크기·외곽선·명암이 같은지 확인한 뒤 채택한다. 어긋나면 `polish_mob_sheets.py`로 팔레트·잡점을 맞춘다.
