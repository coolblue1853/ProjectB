## 1. 방향

- **인디 액션풍 저해상도 도트**: 굵고 또렷한 픽셀, 엄격한 격자, 안티앨리어싱·블러 없음.
- **해상도**: 인간형 캐릭터 키 약 48~64px(논리 px). 일반 몹 40~64px, 보스 96~128px. 게임 내 24 PPU 기준과 맞춘다.
- **팔레트**: 바탕은 채도를 낮춘 차분한 색 3단 명암, 포인트 색 1~2개만 선명하게(마력 청록, 호박빛 눈, 주황 금속 등). 몹마다 대표 포인트 색을 정해 계보 무기 이펙트 색과 맞춘다(TowerWorld 12절).
- **외곽선**: 검은 테두리를 두르지 않는다. 어두운 색 면이나 부분 외곽선으로 실루엣을 분리한다.
- **실루엣·동세**: 비율은 날렵하게, 망토·꼬리·물결처럼 흐르는 형태로 동세를 크게 잡는다. 정지 포즈도 무게중심이 살아 있게 그린다.
- **배경·타일**: 전경은 대비를 또렷하게, 원경은 채도·명도를 낮춰 공기원근을 준다. 바닥에 반사(물·광택 바닥)를 쓰면 분위기가 산다(레퍼런스 2종 공통).

## 2. 제작 파이프라인

1. 핀터레스트에서 레퍼런스 수집(로그인 없이 핀 페이지·`i.pinimg.com` 원본 열람). 레퍼런스는 영감용이며 그대로 베끼지 않는다.
2. 생성: **PixelLab MCP**(연결되면 우선, 애니메이션 시트까지) 또는 ChatGPT 이미지(앱 내장 브라우저, 로그인됨). 프롬프트에 위 1절 조건과 "flat magenta #FF00FF 배경, 같은 디자인 6포즈 한 줄"을 넣는다.
3. 정리: 배경 키 제거 → 실제 픽셀 크기 추정 후 최근접 축소로 격자 복원 → 팔레트 감축(색 16 이하) → 프레임 정렬(발 위치 맞춤) → MonsterBuilder 규격 시트(Idle/Run/Attack1/Take Hit/Death).
4. 검증: 게임 스크린샷에서 플레이어·배경과 같이 봤을 때 픽셀 크기·밝기가 어울리는지 확인.

### PixelLab 경로 (2026-10-19, 숲 늑대에 첫 적용)

- 기본 포즈: `create_image_pixflux` 64×64, `view=side`, `direction=east`, `outline=selective outline`, 투명 배경. 후보 2~3장을 뽑아 `Docs/ArtCompare/`에 비교 시트로 남기고 고른다.
- 애니메이션: 고른 이미지 URL로 `animate_image`(짝수 프레임, 64px 8프레임까지 1생성). 결과 0번은 입력 프레임 그대로다. 디자인이 유지되는 프레임만 골라 쓴다(고개가 카메라로 도는 프레임은 버림).
- 시트: `Tools/pixelfx/assemble_pixellab_sheet.py <out> <dy> <프레임...>` — 모든 프레임에 같은 dy를 줘 발끝을 y=61에 맞춘다. Death는 프레임 알파 255→216 페이드(기존 시트 규약).
- 마무리: `polish_mob_sheets.py`(아래) → `Tools/probes/reskin_mobs.cs`로 재슬라이스·프리팹 재빌드.
- trial 플랜은 동시 작업 1개다. 병렬 호출하면 rate limit 오류가 난다.

### 도트 폴리싱 `Tools/pixelfx/polish_mob_sheets.py`

- 몹 단위로 모든 애니메이션에 같은 16색 팔레트를 쓴다. 씨앗은 멀리 떨어진 색부터 뽑는 k-means라 눈·불꽃 같은 포인트 색이 묻히지 않는다.
- 외톨이 점 노이즈는 가까운 색일 때만 이웃 다수 색으로 바꾼다. 3픽셀 이하 부스러기는 지운다. 입자·끊긴 다리가 디자인인 몹(Wisp, SwampMosquito)은 `--keep-bits`를 준다.
- 알파는 프레임 최대값 기준으로 정리한다(Death 페이드 유지). Idle에 반투명이 있는 몹(모기 날개)만 170 단계를 남긴다.
- 2026-10-19 GPT 외형 19종에 적용: 52~164색 → 16색. 요정·모기는 원본 형태가 부서져 있어 필터로는 한계가 있다(재생성 후보).

### 평면 아이콘 음영 `Tools/pixelfx/shade_flat_icons.py` (2026-10-19)

- 아이템 아이콘은 32×32 도트를 8배 키운 256 PNG다(`Assets/Resources/Item/`). 32px로 줄여 처리하고 다시 8배로 저장한다.
- 좌상단 광원, 색조 이동 5단(외곽선·그림자·기본·밝음·하이라이트, 어두운 쪽은 푸른 보라, 밝은 쪽은 노랑). 검은 테두리는 쓰지 않는다. 보석·핵(`gem`)은 반짝임 점을 찍는다.
- 적용: 1~4색 평면 실루엣 재료 17종 + 너무 어두운 신발 13종(색조 유지, 명도 0.46 이상). 실루엣 자체가 어색했던 7종(둥근·작은·고대 뼈, 고블린 송곳니, 죽음의 인장, 심연 핵, 불길한 검은 액체)은 `Tools/pixelfx/gen_abyss_relic_icons.py`로 다시 그렸다(상아+라벤더 그림자, 청록·라벤더 생물발광 포인트).

### 픽셀 밀도 통일 `PixelLook` (2026-10-19)

- 감사(`ppu_paths` 프로브 + 블록 크기 계산): 배경·마을·NPC는 유닛당 도트 14~21, 몹·소품 24, 덤불·뒷나무 텍스처 143(고해상도), AnyPortrait 주인공은 메시 회전·확대로 흐릿했다. 예전 서드파티 `PixelPerfectCamera`는 꺼져 있었고 ProCamera2D 픽셀 퍼펙트는 카메라 위치만 맞췄다.
- 조치: `Assets/Script/Cam/PixelLook.cs`가 런타임에 메인 카메라에 URP Pixel Perfect Camera를 붙인다(24 PPU, 480×270, Upscale Render Texture). 4K에서 정확히 8배라 화면 전체가 같은 도트 격자로 그려진다. 씬 파일은 바꾸지 않는다. ProCamera2DPixelPerfect는 끈다.
- 보스 연출 줌아웃(`BossIntro`)은 기준 해상도를 640×360(6배)으로 바꿔 처리한다. ProCamera2D.Zoom은 Pixel Perfect가 직교 크기를 잠가 먹히지 않는다.
- 월드 공간 데미지 숫자는 24px 격자에서 뭉개지므로 PixelLook 활성 시 최소 2.2배(치명타 2.8배)로 키운다(`HitFeedback.SpawnNumber`).
- 끄려면 `PixelLook.Enabled = false`.
