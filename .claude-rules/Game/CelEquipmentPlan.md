# 셀 애니메이션 × 장비 외형 계획 (10-26 초안)

기본 이동·점프를 셀(프레임별 그림, PixelLab PixMiniMax 초안 + 정리)로 가기로 함(Q-423, PixelRigDesign 3.6~3.7). 문제: 방어구·무기 조합마다 셀을 다시 찍으면 경우의 수가 폭발(5종 × 5부위면 5^5).
사용자 방향(10-26): **던파식 부위 레이어** — 몸 셀 위에 부위별 장비 셀을 같은 프레임 수·타이밍으로 덮어 교체. "동작이 다듬어지면 이거 위주로 고민", 그다음 몹·무기 애니·이펙트 고도화.

## 조사 요약 (출처는 조사 원문 그대로)

| 방식 | 사례 | 장점 | 단점 / 우리 적합도 |
|---|---|---|---|
| 페이퍼돌(부위 레이어를 몸과 같은 프레임 격자로) | Mana Seed(64칸·최대 20레이어), 던파 아바타(부위별 IMG, 커뮤니티 분석) | 조합 = 합(5×5) | 장비마다 모든 프레임을 그려야 함 → AI 생성 비용·정리 노동 큼 |
| 앵커 + 정지 부위 | 메이플(몸 스프라이트의 neck·navel·hand 맵 포인트 + zmap) | 투구·무기는 1장씩 | 프레임 수가 적은 게임에 맞음, 몸 실루엣이 바뀌는 갑옷엔 약함 |
| 무기 손 앵커 | Terraria HoldoutOrigin + 오프셋·회전 | 무기 수십 종 저비용 | 무기별 쥠점 조정 필요 |
| 팔레트 스왑 | Fell Seal(아틀라스 100→8), unity-pixel-palettemap | 세트 색 변형 생성 0 | 형태는 못 바꿈 |
| 3D→도트 렌더 | Dead Cells | 애니 재사용 | 3D 리깅 전제, AI 셀과 다른 길 |

PixelLab 기능(문서·MCP 답변, 일부 불일치): transfer_outfit(참조 1장의 의상을 2~15프레임에 입힘, 동작 유지, 64px 1회 10~20 gen — 실제 잔액으로 확인 필요), Edit animation Pro(텍스트로 2~16프레임 일괄 수정, 10 gen, 플러그인 전용), animate_with_skeleton_v3(키포인트 재사용, 2~4 gen), PixMiniMax(64px 4~8프레임 1 gen). 레이어 분리 공식 기능 없음 — 원본 몸 프레임에 입힌 결과와 원본의 픽셀 차이로 장비 레이어 추출(무기는 어려움).

일관성 팁: 장비는 항상 원본 몸 프레임에 입힌다(연쇄 편집 금지), 캔버스·피벗·프레임 순서 고정, 몸 드리프트 검사(bbox·무게중심), 고정 팔레트 강제 매핑(`build_cel.py` 가 이미 함), 시드 고정.

## 추천 구조 (조사 결론 + 사용자 방향 결합, 미확정)

- **A안(기본)**: 몸 셀 1벌 + 투구 = 프레임별 머리 앵커에 정지 1장(2등신이라 머리가 외형의 절반) + 무기 = 프레임별 손 앵커(`cel.json` hand/handB) + 무기군별 쥠 3~4종 + 갑옷 = 실루엣 2~3단계(천·가죽·판금)만 셀, 세트별 차이는 팔레트 스왑. 생성 ≈ 실루엣 3 × 12 ≈ 36 gen.
- **B안(대표 세트만)**: 던파식 부위 레이어 — 세트마다 transfer_outfit 으로 28프레임 입힌 뒤 원본과 차이로 레이어 추출·정리. 세트 10개 ≈ 300~600 gen, 품질 최고·노동 큼.
- **C안**: 스켈레톤 재사용 재생성 — 외형마다 몸 전체를 다시 그려 흔들림 위험, 정예·보스 세트 소수에만.

다음 단계(동작 완성 후): 부위 레이어 규격(레이어 순서·앵커 이름·캔버스) 확정 → transfer_outfit 실제 비용 1회 확인 → 갑옷 1세트로 차이 추출 시험.

## 실험 1 — 던파식 레이어 추출 (10-26, 사용자 부재 중)

`Docs/ArtCompare/Motion/equip/`: 측면 대기 셀에 철 투구·흉갑을 입힌 기준 그림(edit_image_pro_flash, 5 gen) → transfer_outfit 으로 걷기 8프레임(10 gen, 15프레임까지 같은 값 — 잔액으로 확인) → `python Tools/pixelfx/extract_layer.py Assets/Art/Player/PixelRig/Cel "Walk_{}" <장비 폴더> 8 <출력>`.
- 전이는 8프레임 모두 자세·동작을 그대로 지키며 장비를 입혔다.
- 레이어 = 장비 프레임에서 맨몸과 색이 다른 픽셀, 8px 미만 덩어리는 잡티로 버림(전이가 다리·팔·스카프를 미세하게 다시 그림).
- **지울 마스크 필요**: 프레임당 54~60px 은 맨몸엔 있고 장비 프레임엔 없는 픽셀(투구 밖으로 삐져나오는 더벅머리) — 겹치기만으로는 못 지운다(던파의 "머리 숨김"과 같은 문제). `<i>_erase.png` 로 함께 저장하고 합성 때 맨몸에서 지우면 장비 프레임과 거의 같다(남은 차이 28~44px 은 전이가 몸을 다시 그린 부분, 몸은 맨몸 그대로가 의도).
- 런타임 합성 방안: 장비가 바뀔 때만 CPU 로 (맨몸 − 지울 마스크 + 레이어들) 프레임을 한 번 합성해 캐시(던파식), 매 프레임 비용 0.
- 비용: 장비 1개를 셀 동작 전체(현재 43프레임)에 입히면 전이 3회 × 10 + 기준 5 ≈ **35 gen**. 슬롯 5 × 종류 5 = 25개면 ≈ 875 gen(월 2000 안). 머리·몸이 같이 바뀌는 세트를 한 번에 입히면 줄어든다.

## 확정: 던파식 부위 레이어 (10-26 사용자 결정, Q-425)

**규격**
- 맨몸 = 셀 클립 프레임(`Assets/Art/Player/PixelRig/Cel/<클립>_<k>.png`, 64×64, 피벗 = 리그 원점). 모든 레이어는 같은 캔버스·같은 프레임 번호.
- 장비 1개 = `Assets/Art/Player/PixelRig/Equip/<장비 id>/<클립>_<k>.png`(덮어쓰기, RGBA) + `<클립>_<k>_erase.png`(맨몸에서 지울 마스크, L). 없는 프레임은 레이어 없음으로 본다.
- 슬롯 그리는 순서(아래 → 위): 맨몸 → 하의·신발 → 갑옷(상의) → 장갑 → 투구. 마스크는 레이어보다 먼저 맨몸(과 아래 레이어)에서 지운다.
- 무기는 레이어가 아니라 프레임별 손 앵커(`cel.json` hand/handB)로 붙인다(무기군별 쥠은 무기 애니 단계에서).
- 제작: 측면 대기 셀에 장비를 입힌 기준 그림(edit_image_pro_flash) → transfer_outfit 을 클립 묶음(최대 15프레임)으로 → `extract_layer.py` 로 레이어·마스크. 장비 1개 ≈ 35 gen.
- 런타임: 장비가 바뀔 때만 프레임마다 (맨몸 − 마스크들 + 레이어들)을 CPU 로 한 번 합성해 스프라이트 캐시 — 그리는 비용은 맨몸 셀과 같다.

## 구현 1 (10-26)

- 셀 동작 전체 43프레임에 철 투구·흉갑(`iron_set`, 슬롯 body) — 전이 4회(걷기 8 + 14 + 13 + 8프레임) 40 gen + 기준 그림 5 gen. `python Tools/pixelfx/build_equip.py iron_set body` → `Assets/Art/Player/PixelRig/Equip/iron_set/`.
- 빌더 `BuildEquipLayers` → `Resources/PixelRig/Equip/<id>.asset`(`CelEquipLayer`: 프레임별 레이어·마스크, 읽기 가능 텍스처). 막 쓴 PNG 는 먼저 `ImportAsset` 해야 한다(안 하면 텍스처가 전부 비었다). 맨몸 셀 텍스처도 읽기 가능.
- 런타임 `PixelRig.SetEquipmentLayers(layers)` → `CelComposer`(슬롯 순서로 마스크 지우고 덮어쓰기) → 클립별 합성 스프라이트 캐시, 43프레임 합성 5ms. 시험 프로브 `Tools/probes/apply_cel_equip.cs`, 촬영 `EQUIP=iron_set bash Tools/compare_moves.sh <태그>`. 영상 `Docs/ArtCompare/Motion/cmp_v6_cel_plain_vs_iron.mp4`.
- 남은 일: 인벤토리 장착과 연결(아이템 → 레이어 id 표, ItemSheet 컬럼 추가 시 ItemSpec 갱신), 슬롯별 분리(투구만·갑옷만), 공격 동작 셀화 뒤 같은 레이어 확장.

## 구현 2 (10-26) — 부위 분리·인벤토리 연결

- 부위 분리(생성 0): `python Tools/pixelfx/split_equip.py iron_set iron_helm iron_plate` — 프레임마다 맨몸 스카프 윗줄 위 = 투구(+지울 마스크 전부), 아래 = 갑옷. 맨몸·투구만·흉갑만·둘 다 4조합 모두 깨끗(조합 시트 확인). 세트를 한 번에 전이한 뒤 나누면 장비 2개 값으로 1번 비용.
- 연결: `CelEquipSync`(PixelRigInstaller 가 리그에 붙임) — 장비 칸(모자 2·갑옷 5·장갑 6·바지 8·신발 9)을 0.5초마다 보고 아이템 이름이 바뀔 때만 `Resources/CelEquipMap.csv`(아이템 이름,레이어 id) 로 레이어 합성. 인벤토리 코드는 손대지 않음. 임시 대응 Q-426: Cap → iron_helm, Armor·HighArmor → iron_plate.
- 검증: 낮 인게임에서 장비 칸에 Cap 장착 → 걷기에 철 투구. 갑옷 칸은 프로브 장착이 칸에 들어가지 않아 미검증(합성은 조합 시트로 확인).
