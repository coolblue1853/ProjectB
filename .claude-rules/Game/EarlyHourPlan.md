## 7. 검증 방법 (처음부터 플레이)

1. **세이브 초기화**(새 슬롯, Lv1/EXP0/가방0). 낮 고정 유지. 첫 장비 RustedSword 확인.
2. 사용자 직접 플레이(권장) + 봇 보조(좌표 이동·전투 가속 금지 구간은 정상 시간 측정에서 제외, `ClassicMapleDesign` §20 규칙). 기록 항목: 시각(분:초), 레벨, 골드, 가방 칸, 이벤트.
3. 체크리스트(시각은 §3 표 대비 ±3분 이내면 통과):
   - 첫 레벨업 ≤ 3분. Lv3 ≤ 15분. Lv4 ≤ 20분. Lv5 ≤ 30분.
   - LeafAdae 수령(Q102 보고) → 장착 → 특수 효과 툴팁/발동 확인 → Adae Lv2 에서 스킬 2 해금 토스트.
   - Q106 보상 RatCap 수령, 쥐 두목 정예 처치 1회.
   - Q107 1부위 구매·착용이 골드 부족 없이 가능(골드 로그).
   - Q203 첫 요리 → Q110 마을 요리대 x3(수량 팝업·가방 부족 처리).
   - Q109 강화 +1 성공 로그. Q206 제작 성공 로그.
   - Q201 보고 이동 시간(왕복 제거 후 ≤1.5분).

4. 이탈 위험 표시 규칙: 같은 몹 종류 연속 5분 초과(M), 변화 이벤트 없는 10분 초과(막힘), 가방 15/15, 골드 부족으로 진행 정지, 포털 길 못 찾음.
