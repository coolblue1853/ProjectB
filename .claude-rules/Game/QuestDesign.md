# 퀘스트 콘텐츠 설계 (REWORK-6, 11-11)

틀(데이터 모델·창·HUD)은 `Game/QuestSystemDesign.md`. 이 문서는 **내용**: 유형 정의, 대사 단계, 층계별 줄기, 재분류표. 클래식 메이플은 **구조·형식만** 차용한다. 대사·고유명사·문장은 베끼지 않고 TO THE BEYOND(`TowerWorld.md`)로 새로 쓴다.

## 1. 메이플 퀘스트 조사 (mapledb.kr, WebFetch 11-11)

사이트: 정보 메뉴 `quest.php`(전체 778건 집계, ID 1000~6000대 군집). 목록은 아이콘+제목뿐이고 상세는 `search.php?q=<id>&t=quest` 로 열린다. 표본 4건 확인(전수 아님).

### 1-1. 한 건의 구성 (사이트 필드)
| 영역 | 필드 | 우리 대응 |
|---|---|---|
| 순서 | 이전 퀘스트 / 다음 퀘스트 링크 | `requires`(선행 1개). 다음은 역참조로 계산 |
| 정보 | 반복 여부(1회성 등) | `repeat` |
| 정보 | 시작 최소·최대 레벨 | `minLevel`(최대는 두지 않음) |
| 정보 | 시작 필요 메소 | 도입 안 함 |
| 정보 | 시작 NPC / 종료 NPC | `giver` / `reportTo` |
| 정보 | 시작 가능 직업 | 도입 안 함(직업 무관) |
| 요구 | 몬스터 처치 수 또는 아이템 전달(수량) | `objective·target·count` |
| 보상 | 경험치·메소·인기도·아이템 | `exp·gold·rewardItem·stones·artifact`(인기도 없음) |
| 대사 | (게임 내) 시작 → 수락/거절 → 진행 중 → 완료 | §3 형식 |

### 1-3. 종류 분포·사슬·레벨 구간 (확인된 범위의 결론)
- **종류:** 대화·전달 심부름(입문) / 아이템 납품 / 몬스터 처치 / 일회성 고보상 수집. 반복형은 표본에서 확인 못 했다(전부 1회성).
- **사슬 길이:** 2~4건 사슬이 기본(앞/다음 링크가 모든 퀘스트에 붙는다). 한 NPC가 시작·종료를 같이 맡는 경우가 많고, 심부름은 NPC 사이를 오간다.
- **레벨 구간:** 입문(1~)부터 50대 이상까지 최소 레벨만 있고 최대는 대부분 없음. 경험치는 레벨이 오를수록 커진다(표본 300 → 1200).
- **한계:** 대사 문장·진행 조건 세부·종류별 건수 통계는 사이트가 공개하지 않거나 이번에 열람하지 못했다. 분포는 **임시 가정**(`Docs/OpenQuestions.md` Q-QD1).

### 1-4. 차용 결론
1. 한 건 = 시작 NPC·종료 NPC·최소 레벨·선행·요구·보상 6요소(이미 CSV 가 갖춤).
2. 사슬은 2~4건으로 끊고, 사슬 이름을 제목 접두("… I/II/III")로 드러낸다.
3. 대사는 4단계(수락·진행·완료 + 거절은 기본 문구).
4. 메소(골드)·경험치·아이템 보상 중 한두 가지만 주어 보상 성격을 구분한다(§2).

## 2. 유형 3종 정의 (`kind` 열)

| 유형 | `kind` | 역할 | 정의 | 판별 | 분량(층계당) |
|---|---|---|---|---|---|
| 메인 가이드 | `main` | 진행 안내·세계관 줄기 | 다음에 갈 곳·할 일을 알려 주는 **한 줄기**. 선행 사슬이 끊기지 않고 층계 졸업(문지기)으로 이어진다. 장로(`elder`)가 대부분의 시작·종료 NPC. 사냥·방문은 최소(1~2종 목표) | 이 줄기를 건너뛰면 다음 구역·층계 진입 방법을 모른다 | 5~8건 |
| 사이드 | `side` | 세계관 설명용 이야기 | 아버지·탑·브로치·구역 생태의 **뒷이야기**. 진행에 필수가 아니다. 2~4건 사슬, NPC 개성(말투 `TowerWorld §21`) 중심. 보상은 이야기 소품(칭호·아티팩트·소량) | 안 해도 진행되고, 하면 설정이 더해진다 | 2~3사슬(사슬당 2~4건) |
| 보상용 | `reward` | 사냥·수집·반복 | 장비·재료·EXP 를 얻는 **파밍 보조**. 수치가 목표(처치 N·수집 N·제작·강화·착용). 이야기 없음(대사는 짧은 사정 한 줄) | 목표가 숫자·아이템이다 | 제한 없음(구역당 3~6건) |

공통 규칙: 레벨 구간은 해당 구역 권장 레벨(`minLevel`). 보상용만 EXP 가 본문(메인은 EXP 보다 아이템·열쇠, 사이드는 소량). 메인 줄기는 `source=npc`, 푯말·게시판(`questboard`·`bountyboard`)은 항상 `reward`(예외 없음).

## 3. 대사 단계 형식 (퀘스트 1건당)

| 단계 | 열 | 길이 상한 | 내용 |
|---|---|---|---|
| 요약 | `description` | 40자 | 창 요약 한 줄. 사정·목표. 쉼표 없음 |
| 수락 | `offerLine` | 페이지 2줄 × 2페이지 이내(페이지 구분 `|`, 줄 `^`) | 시작 사정 → 부탁 → 어디서 무엇을. 수치는 목표 줄에 맡김 |
| 진행 | `progressLine` | 1페이지 2줄 | 아직 안 끝났을 때 격려·힌트 한 가지 |
| 완료 | `doneLine` | 1~2페이지 | 결과 확인 → 보상 → (메인·사이드만) 다음으로 이어지는 한 줄 |
| 거절 | 열 없음 | 기본 문구 | 시스템 기본("지금은 어렵겠나. 마음이 서면 다시 오게." 류, NPC 말투로 `NpcQuestVoice` 처리) |

- 말투는 NPC별(장로 하게체·루엔 짧은 반말·세나 존댓말·이브 관찰 반말·일사 보급 존댓말·브란 무뚝뚝한 반말·기록지기 간결 존댓말).
- 한 페이지 2줄 이내, 경이·불안은 흔적·관찰로만. 아버지·문지기 정체는 확정하지 않는다.
- 현재 구현: `QuestsFloor1.csv` 의 처음 60건은 대사 열이 비어 있고 `NpcQuestVoice` 코드가 대사를 담당한다. 이행분 11건(게시판 8·촌장 3)만 CSV 열에 대사가 있다. **이행 상태(11-11):** 로더·`NpcQuestVoice` 는 이미 CSV 열 우선·빈 열이면 코드 대사 폴백. 구조 검증용으로 Q204·Q301·Q403·Q502·Q601·Q604 6건을 새 대사로 CSV 에 올렸다(`QuestVoiceCsvTests`). 나머지는 빈 값=기존 코드 대사 유지(Q102 는 `QuestSystemTests` 가 빈 값으로 핀). 완료·진행 대사는 1페이지(`|` 금지), 수락만 2페이지. 남은 이행·Q 창 노출은 Q-QD2.

## 7. 1층계 대사 초안 (새로 씀, 최소 분량)

사이드 ㉠ 별 관측의 첫 건(이브 말투 = 관찰하는 반말). 열에 아직 넣지 않는 **초안**:
- 수락: `숲이 밤마다 조금씩 어두워져.^길가 별빛이 언제부터 줄었는지 보고 싶어.|왼쪽 끝 관측지까지 가 줘.^밟기만 하면 돼.`
- 진행: `아직이야? 관측지는 입구에서 왼쪽으로 조금 더 가.`
- 완료: `…빛이 이어져 있어. 누군가 일부러 놓은 길이야.^고마워. 다음엔 둥지 쪽을 같이 보자.`
