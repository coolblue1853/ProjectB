## 2. 합격 기준 (초안)
**타일(바닥·벽)** ① 도트 밀도가 주인공과 같다(타일 1칸 = 16 또는 32px, 캐릭터 몸 56px 대비) ② 가로·세로 이음새 없음(자동 타일 규칙 포함) ③ 윗면·옆면·모서리 구분이 읽힘 ④ 캐릭터·몹이 바닥에 묻히지 않음(바닥 명도 < 캐릭터) ⑤ 팔레트 층계마다 한 주조색+보조 1색.
**배경 레이어** ① 3~4겹(하늘·원경·중경·근경 소품) ② 거리 = 명도·채도(멀수록 옅고 외곽선 없음) ③ 가로 반복 이음새 없음 ④ 어둡지만 유아틱하지 않음 ⑤ 패럴랙스에서 전경·캐릭터와 겹쳐도 가독성 유지.
**맵 구성** ① 이동·사냥 동선이 `Floor1Completion.md` 흐름과 일치 ② 맵 폭 화면 8~9장(카메라 20×11.25u) ③ 포털·안전지대 위치가 `FloorTransition.md` 규칙과 일치.
합격 = 항목의 80% 이상 + 이음새·가독성(타일 ②④, 배경 ③⑤) 필수.

## 3. 방법 (몹 레시피 확장)
- **타일**: 몸 크기 비교용 시트를 먼저 만든다(주인공 + 1타일 + 예상 맵). 풍은 주인공 앵커(`style_image`)가 아니라 **타일은 DS 도트 타일(`City_Tile`·`Ground_178x70`)을 스타일 입력**으로(타일은 사람 흉내 위험이 없고 DS 도트 질감이 이미 도트 해상도). 생성은 `create_tiles_pro`/`create_sidescroller_tileset` 후보를 먼저 조사(가격·타일 규격·사이드뷰 지원)하고, 안 되면 Pro Flash 로 16x16 한 장씩 + 코드로 오토타일. ⚠ 도구 스키마·가격 조사 필요(1순위).
- **원경 띠(하늘·능선·침엽수)**: 절차 생성(`Tools/pixelfx/` 에 스크립트): 노이즈 높이 맵 → 윗면 요철 단색 면, 층계마다 시드·색. 생성 0.
- **중경·근경 소품(나무·바위·기둥)**: 몹 레시피 v2 와 같이 Pro Flash 64 캔버스 + 앵커, 소품 1종 5생성. 소품은 사람형 걱정이 없어 앵커 = 합격 몹(거북·유적 골렘 등) 중 풍이 맞는 것도 가능.
- **복사 금지**: DS 원본 이미지는 저장소·빌드에 넣지 않는다(스타일 입력용 업로드만). 구도는 참고, 모티프 복제 금지.
- 판정은 시트로: 주인공·몹과 한 화면에 합성한 목업 1장(`Docs/ArtCompare/Maps/`) → Claude 판정 먼저 로그(`Docs/Playtest/BgJudgeLog.md`) → 사용자 판정.

## 6. 스케일 실측 (프로브 `_tile_size.cs`·`_hero_size.cs`, 11-07) — 타일 크기 결정 근거
- 주인공 리그: 파츠 64px, **PPU 36** → 캔버스 1.78u, 몸 56px = 1.56u, 폭 28px = 0.78u. 카메라 ortho 5.87(화면 높이 11.7u).
- **숲형 타일: 스프라이트 256x256 PPU 256 = 1u**(일러스트 해상도, 도트 밀도가 주인공의 7배) → 주인공 풍과 가장 안 맞음. **절벽형 타일: 16x16 PPU 16 = 1u**(주인공의 0.44배, 거침).
- 결정: **새 타일은 32px, PPU 32~36** (주인공 PPU 36과 도트 크기 같음, 타일 1칸 ≈ 0.9~1u). 1u 격자를 유지하려면 PPU 32(주인공 대비 12% 차이)가 단순하고, 정확히 맞추려면 셀 크기 0.889. 실제 적용 때 Unity 에서 확정(미검증).
- 몹도 같은 PPU 36 기준으로 크기 환산: 일반 몹 폭 32~56px = 0.9~1.6u.
