# 무기 타입 확장 설계 (10-31, 사용자 "무기 증가 방향으로도 진행, 여러 무기 타입, 실제 도트는 안 찍어도")

근거: `WeaponReview.md` 0~1절(무기 18종 = `Weapon`+`Skill` 프리팹 값만 다름, 타입 enum 없음), `MotionSpec39.md` 2~3절(마스터 모션·무기군 타이밍), `LineageGear.md`·`Floor2Plan.md`(계보 무기 표), `TowerWorld.md` 12절(몹을 잡아 그 몹 무기, 스킬 = 몹 패턴 복사), `FloorCoreContent.md`.
목표: **무기 "계열"을 늘려 플레이 감각 차이를 만든다.** 아트는 기존 무기 스프라이트 색조·회전·간단 코드 도트 임시, 모션은 기존 마스터 모션 재사용. 초반 장비는 작고 소박하게, 화려함은 유니크·레전더리만. 한손 무기 = 화면 오른쪽 손.

## 1. 현재 계열 정리

| 계열 | 무기 | 정체성 | 겹침 문제 |
|---|---|---|---|
| 한손검 | RustedSword, PoisonSword | 3타 균형, 기본 | 무기 이름만 다르고 평타 판정 프리팹(Steb·VashDown·VashUp)이 같다 |
| 검방 | RustedSwordandShield | 느린 3타 + 홀드 방어 | 방패가 검 무기의 부속이라 방패 단독 플레이가 없다 |
| 대검 | SacreGreatSword | 2타 느린 광역(maxE 3), 홀드 차지 | 낫과 판정(GreatDown/Great Side·Up)이 같다 |
| 낫 | ScareSide, CliffBlade | 2타 광역 + 홀드 회전 | CliffBlade = ScareSide 복제. 대검과 감각 차이 작음 |
| 단검 | DoubleDagger, RatCheifDagger | 빠른 3타, 버프·연타 스킬 | 두 단검이 모두 같은 3타 |
| 너클 | Leather Knuckles | 2타 근접 + 전부 캔슬 스킬 | 정체성 뚜렷함 |
| 클로 | ScareClow | 2타 광역 + 대시 연타 | 대검·낫과 판정 프리팹 계열 공유 |
| 창 | Wood Spear | 1타 찌르기 + 돌진 | 콤보 없음, 찌르기 사거리 장점이 약함 |
| 아대 | LeafAdae | 유도 발사체 1타 | 지팡이와 평타가 둘 다 "발사체 1타 반복" |
| 지팡이 | LeafStaff, ScareStaff, CliffStaff, AbyssStaff | 이동정지 없는 발사체 | 4종 중 3종이 같은 DarkAttack 복제 |
| 활(부분) | Bandit Shortbow | `BowShot`+`StraightArrow` 평타 | 계열로 정식화되지 않음(몹 드롭 1종뿐) |
| 채찍(부분) | Frog Tongue Whip | Spear 기반 + 당기기 스킬 | 평타는 창과 동일, 채찍 감각 없음 |

핵심 진단: 차이가 **스킬**에만 있고 **평타·사거리·기믹**이 계열마다 거의 같다. 새 타입은 평타 구조와 기믹 1개로 구별한다.

## 2. 새 무기 타입 11개

공통 표기: 모션 ID는 `MotionSpec39.md` 코드. "판정" = 근접/발사체/차지/지면. 코드는 `Weapon`/`Skill` 기존 기능 + 타입 컴포넌트(4절) 최소 추가.

### 2.1 활 (Bow)
- 정체성: 거리 두고 쏘는 안정적 원거리. 이동 중 사격 불가, 방향 고정.
- 평타: 1타 반복(0.55s), 판정 = 발사체 `StraightArrow`, 사거리 길음. **기믹 = 차지 샷**: X 길게 누르면 최대 1초 충전, 놓으면 관통 +1·피해 ×1.6.
- 모션: A13(한 팔 겨눔, 통과 Bow 셀 참고). 충전 중에는 A13 예비 구간 유지(완급 0.6초 정지).
- 코드: `BowShot`(구현됨) + 차지 입력 처리 `ChargeShot` 신규(작게: 누른 시간 → 피해/관통 배율).
- 임시 아트: 기존 Bandit Shortbow 스프라이트 색조 변경(나무색 → 짙은 녹/회). 화살은 기존 `BanditArrow`.

### 2.2 석궁 (Crossbow)
- 정체성: 느리게 쏘고 한 방이 센 장전식. 활보다 정지 시간 길고 관통 우수.
- 평타: 1타(0.9s), 발사체 직선, **기믹 = 장전 3발**: 3발 쏘면 재장전 1.2초, 재장전 직후 첫 발 치명 확정.
- 모션: A13 (A21 양손 조준은 보류 중 → 임시로 A13 재사용, 무기 쥠만 양손 프로파일).
- 코드: `AmmoMagazine`(탄 수·재장전 타이머, 활 `ChargeShot`과 대체 관계) 신규.
- 임시 아트: 활 스프라이트를 90° 눕혀 가로 막대 + 작은 활 날개(코드 도트 8×16).

### 2.3 둔기 (Mace / Hammer)
- 정체성: 느리고 무거운 한손/양손 타격. 경직·방어 무시.
- 평타: 2타(0.65/0.9s), 근접 판정 작고 두꺼움(maxE 1, 넉백 큼). **기믹 = 충격**: 타격 시 몹 경직 +0.3s, 방어 20% 무시.
- 모션: A1(내려베기, 타이밍 프로파일 둔기 ×1.4), 2타는 A4(양손일 때)/A2. 도약 스킬 A16.
- 코드: 평타 판정 프리팹 복제 + `StaggerOnHit`(`DamageObject` 경직 값 확장, 이미 몹 경직 필드가 있으면 값만) 소규모.
- 임시 아트: 한손검 칼날 스프라이트 → 머리 부분을 직사각 블록으로 코드 도트 교체(PNG 6×6 합성), 색은 철/나무.

### 2.4 도끼 (Axe)
- 정체성: 한 방 찍는 중간 속도 근접. 거치적 방어 파괴.
- 평타: 2타(0.5/0.7s), 1타 베기·2타 내려찍기, maxE 2. **기믹 = 쪼개기**: 방어구 있는 몹(기사·방패·골렘) 대상 피해 +20%, 2타는 방패 막기 무시.
- 모션: A5b(한손 수평) → A1(내려베기). 양손 대도끼 A4.
- 코드: 몹 태그(`Armored`) 판정 + 피해 배율. 몹 프리팹에 태그 추가 필요(없으면 몹 이름 리스트로 시작).
- 임시 아트: 한손검 스프라이트 → 날 쪽 삼각형 코드 도트, 색조 갈색/녹슨 철.

### 2.5 채찍 (Whip)
- 정체성: 긴 리치, 가장자리 타격이 센 중거리. 이동 가능, 안전하지만 피해는 낮음.
- 평타: 2타(0.45/0.5s), 판정 = 좁고 긴 근접(`DamageObject` 박스 길이 ×2.2). **기믹 = 끝 판정**: 판정 박스 끝 30% 구간에 맞으면 피해 +40%, 근접하면 -20%.
- 모션: A5b(한손 수평), R10(당기기, 스킬). 타이밍 채찍 ×1.2.
- 코드: 타격 위치 기반 배율 `TipBonus`(충돌 지점 vs 박스 거리) 소규모. 기존 Frog Tongue Whip 평타를 이 타입으로 이전.
- 임시 아트: 기존 창 스프라이트를 가늘게 늘이고 휜 선(코드 도트 곡선 4px), 색 갈색 가죽.

### 2.6 사슬 철퇴 (Flail)
- 정체성: 휘두르다 놓기까지 시간이 걸리고 한 번 돌면 전방위. 타이밍 무기.
- 평타: 2타(0.6/0.9s), 1타 전방 호, 2타 **회전**(주변 360°, maxE 4). **기믹 = 원심력**: 2타 직전 1타를 맞췄으면 2타 판정 반경 ×1.4, 못 맞추면 평범.
- 모션: A5b → A10(회전 베기). 줄 그리기 N5는 후보라 임시 없음(무기 스프라이트만 회전).
- 코드: 이전 타 적중 여부 기억 `LastHit` 플래그 + 판정 크기 배율. 낫 판정 프리팹 복제.
- 임시 아트: 철퇴 머리(둥근 8×8 코드 도트) + 사슬(3px 점선) 3요소 분리 스프라이트.

### 2.7 쌍검 (Dual Blades)
- 정체성: 빠른 교차 연속, 좌우 번갈아. 단검보다 짧은 사거리지만 타수 많음.
- 평타: 4타(0.25/0.25/0.25/0.4s), 홀수 우측·짝수 좌측 판정, maxE 1. **기믹 = 교차 마무리**: 4타째 X자 판정(피해 ×1.5, 범위 ×1.2).
- 모션: A7(교차 베기), 1~3타는 A5b/A2 번갈아. 주손 = 오른쪽, 보조손은 왼쪽(손 전환 금지 규칙 유지).
- 코드: 평타 4타 허용(`maxComboCount` 프리팹 값만), 마지막 타 판정 배율 `FinisherBonus` 소규모(둔기·도끼와 공용).
- 임시 아트: 한손검 스프라이트 2개를 좌우 기울여 놓음, 색조 청/은.

### 2.8 태도 (Tachi, 발도)
- 정체성: 칼집에서 뽑는 단 한 번의 일섬. 평소엔 약, 납도 후 첫 타가 강력.
- 평타: 1타(0.55s) 중거리 수평 베기(maxE 3). **기믹 = 납도**: 공격 후 1.2초 입력 없으면 납도 → 다음 첫 타 피해 ×2·범위 ×1.3·히트스톱 강화. 연타하면 약한 3타 콤보만.
- 모션: A19(발도 일섬, 60/5/35) 납도 첫 타용, A3/A5b를 연타 구간 평타로 임시.
- 코드: 마지막 타 이후 경과 시간 추적 `SheathedBonus`(상태 플래그 + 이펙트 한 장) 소규모.
- 임시 아트: 한손검 스프라이트 → 길이 ×1.3·휜 선, 납도 상태 칼집 코드 도트 한 장. 색 은/검정.

### 2.9 마도서 (Tome)
- 정체성: 지팡이보다 다양한 "원소 전환" 근거리 마법. 서고·방벽 관련.
- 평타: 1타(0.6s) 발사체 `HomingOrb`(약 유도). **기믹 = 장 전환**: C키 또는 스킬 슬롯으로 "불/냉기/번개" 3장 전환, 평타 판정 색·부가효과(화상/둔화/연쇄)가 바뀐다. 전환 쿨 3초.
- 모션: A11(시전 한 팔), 전환은 R2(양손 들기) 임시.
- 코드: 현재 장 인덱스 + 평타 프리팹 3종 선택 `TomePage`. 둔화는 LineageGear 4절 3번 시스템 필요 → 1차는 화상·연쇄만.
- 임시 아트: 아이콘 = 책 코드 도트 10×12, 장별 색(빨/파/노).

### 2.10 투창 (Javelin)
- 정체성: 던지고 회수하는 중거리. 창보다 호쾌하지만 던진 뒤 빈손.
- 평타: 1타(0.7s) 던지기 발사체(직선 → 땅에 박힘). **기믹 = 회수**: 던진 창이 박힌 곳으로 걸어가 줍거나 스킬로 소환 회수. 박힌 창은 5초간 함정(밟은 몹에 피해).
- 모션: A12(던지기), 창 들고 있을 때 A3. 회수는 R6(웅크려 놓기)/R10(당기기) 임시.
- 코드: `StraightArrow` 변형(`ThrownSpear`: 도착 시 지면 고정 오브젝트 + 회수 로직). 중간 규모.
- 임시 아트: 기존 Wood Spear 스프라이트 그대로 던지기 회전 없이 직선.

### 2.11 건틀릿·방패 단독 (Bulwark)
- 정체성: 때리기보다 막고 밀기. 파티 아닌 솔로에서도 탱커 감각.
- 평타: 2타(0.5/0.7s) 밀치기(maxE 1, 넉백 큼, 피해 낮음). **기믹 = 반격**: 홀드 방어(A14) 중 피격 시 다음 평타 피해 ×1.8(3초). 방어 중 이동 불가.
- 모션: R8(방패 밀치기), A14(막기), A9(돌진).
- 코드: 이미 `Hold the Line`·Shell Guard가 있으므로 "피격 시 반격 버프" 토큰만 추가(`CounterBuff`). 검방에서 방패 평타를 분리.
- 임시 아트: 방패 스프라이트(Raider Buckler) 단독, 오른손에 쥠 표시.

## 4. 데이터 구조 제안 (최소)

- **ItemSheet 맨 뒤 컬럼 `WeaponType`**(문자열: Sword/Axe/Mace/Whip/Flail/Dual/Tachi/Bow/Crossbow/Tome/Javelin/Bulwark/…). 기존 18종은 빈칸 → 계열 이름으로 채우기(기본값 = 프리팹의 계열). `Game/ItemSpec.md` 표 갱신.
- `Weapon.cs`에 `enum WeaponKind`(직렬화 필드 `[SerializeField] WeaponKind _kind`)를 두고 ItemSheet와 일치 검사. 프리팹마다 설정.
- 타입별 기믹은 **`WeaponGimmick` 추상 컴포넌트**(`OnAttackStart`, `OnHit`, `OnSkill`)를 상속한 작은 클래스: `ChargeShot`, `AmmoMagazine`, `StaggerOnHit`, `TipBonus`, `SheathedBonus`, `TomePage`, `CounterBuff`, `FinisherBonus`. `Weapon.MeleeAttack`이 있으면 호출.
- 툴팁에 "무기 타입: 활" 표시, 기믹 한 줄 설명 문자열을 `Docs/CSV`(없으면 `ItemSheet` 설명)에 추가.
- 함정: 판정 프리팹은 공유되므로 **복제해서 수정**(LineageGear 0절). 콤보 4타(쌍검)는 `maxComboTime` 1초 안에 4번 눌러야 하므로 쌍검은 1.2초로 올린다(W-02 참고).

## 5. 구현 순서

### 5.1 1차 묶음 (새 코드가 적고 차이가 큼)
1. **활 정식화 + 차지 샷**: `BowShot` 이미 있음, `ChargeShot`만 추가. Hunter's Longbow 1종 신설.
2. **둔기 + 도끼**: 평타 판정 프리팹 복제 + `StaggerOnHit`/피해 배율. 1층계 몹(슬라임·악어) 기존 무기 이전 + 신규 2종.
3. **쌍검**: `maxComboCount` 4 + `FinisherBonus`. 모션 A7 이미 있음. Twin Fang 1종.
4. **채찍**: 기존 Frog Tongue Whip을 `TipBonus` 타입으로 이전 + Vine Lash.

### 5.2 2차 묶음
5. 태도(`SheathedBonus`), 건틀릿·방패 분리(`CounterBuff`).
6. 석궁(`AmmoMagazine`), 플레일(`LastHit`).
7. 마도서(`TomePage`), 투창(`ThrownSpear`).

### 5.3 검증 방법
- 에디터 플레이 모드: 무기 장착(디버그 지급 프로브 `Tools/probes/*.cs` 신규) → 허수아비 대상 평타 10회 → 콘솔 로그의 피해/판정/기믹 플래그 확인.
- 활: 1초 차지 → 화살 관통 2마리 확인. 둔기: 몹 경직 시간 로그. 쌍검: 4타 마지막 배율 로그. 채찍: 끝/근접 거리별 피해 2회 비교.
- 모든 새 무기는 `Weapon`+`Skill` 컴포넌트 값만으로 장착·발사되는지 먼저 확인(기믹 끄고).
- 결과 스크린샷/로그는 낮 시간대에 찍는다. 확인 못한 항목은 "미검증"으로 문서에 기록.

## 6. 임시 가정 (묻지 않음)

1. 아트는 코드 도트·색조 변경으로 임시, 정식 도트는 후속(PixelLab 후순위).
2. 쌍검의 보조손(왼손) 무기는 시각만(이펙트), 판정은 오른쪽 기준 좌우 번갈아.
3. 석궁은 모션 A21 보류 → A13 임시. 플레일 줄 그리기(N5)도 후속.
4. 태도 납도 1.2초는 초기값. 플레이 후 조정.
5. 3·4층계 몹 이름은 임시. 실제 몹은 층계 구현 시 재조정.
6. `WeaponType` 기본 문자열은 영문 키. 한글 표시는 I2에서.
7. 둔기 방어 무시 20%는 `DamageCalculator` 방어 항에 일시 반영(공식 문서 `CombatSpec.md` 후속 갱신).
8. 신규 몹(숲 사냥꾼·감시병·나무꾼·덩굴 요정 등)은 2차 이후 구현, 1차는 기존 몹 드롭 이전으로 시작.
