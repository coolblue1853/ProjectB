## 4. 레이어 구성·색감 관찰
- 레이어 4~5겹: 하늘(단색 그라디언트, 4px 폭 늘림) / 달·구름 파츠 / 원경 실루엣(가장 옅음) / 중경(기둥·바위·묘비, 약간 진함) / 근경 타일(가장 진함).
- **거리 = 명도·채도**: 멀수록 하늘색에 가깝게 옅고, 가까울수록 어둡고 대비가 큼. 원경은 외곽선 없이 한 색 면, 근경만 짙은 외곽선.
- 윗면만 요철인 실루엣 띠가 1024~2048 폭 + 64~155 높이로 매우 얇다 → 가로 반복, 저비용.
- 한 맵 = 한 주조색 + 보조 1색(달밤 = 자주+연분홍, 협곡 = 주황+갈색, 묘지 = 회보라). 보스·밤 맵일수록 단색 지배.
- 광원 파츠(달·별·빛무리)는 흰 글로우 원판 따로 → 가산 합성용.
- 맵 파츠가 아틀라스 하나에 섞여 있어 원본 레이어 순서는 불명. 스프라이트(`spr/atlas_B###_Map*`)에서 파츠 이름은 숫자뿐이라 구성 복원은 하지 않는다.

## 5. 우리 것으로 다시 만드는 방법 (복사 금지)
1. 구도·색 수치만 추출: 시트에서 주조색·보조색 3~5개를 스포이드로 뽑아 층계별 팔레트 표만 `ArtStyle.md` 기준에 맞춰 기록. 이미지는 쓰지 않는다.
2. 하늘 = 코드/셰이더 그라디언트(Sky_4x867 방식 아이디어, 에셋 불필요). 낮/밤은 `TimeChange` 톤과 연동.
3. 원경 띠 = 절차 생성(노이즈 높이 맵 → 윗면 요철 단색 면)으로 우리 해상도에 맞게 생성. 층계마다 시드·색만 변경.
4. 중경 소품은 PixelLab 으로 우리 그림체·도트 규격에 맞춰 신규 생성(참고 이미지는 `style_image` 로 비율·명암만, 모티프 복제 금지). 1회 시험 후 사용자 검토.
5. 근경 타일은 기존 Unity 타일셋 우선(`polish-existing-first`), 부족한 층계만 `City_Tile` 같은 도트 질감을 참고해 신규.
6. 각 단계 결과는 시트로 만들어 사용자 검토 후 적용. 적용 전 `MotionFxChecklist` 해당 없음(배경은 `ArtStyle.md` 만).
