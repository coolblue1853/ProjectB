# 컨텍스트 절약

- **필요한 범위만 읽는다.** 큰 파일은 `grep -n`으로 위치를 찾은 뒤 그 주변만 읽는다. 200줄 이하이거나 구조 파악이 목적일 때만 통으로 읽는다.
- **같은 파일을 다시 읽지 않는다.** 수정 직후 확인용으로 다시 읽지 않는다. 편집 도구가 실패하면 알려준다.
- **통으로 읽지 말 것:** `*.unity` / `*.prefab` YAML, 로그(`Logs/`, Editor.log), `packages-lock.json`, 서드파티 폴더(AnyPortrait, Behavior Designer, Plugins 등). 필요한 줄만 grep한다.
- **명령 출력은 잘라서 본다:** `| head`, `| tail`, 중복은 묶어서 센다.
- **넓은 탐색("어디 있지?")은 서브에이전트에 맡기고** 결론만 받는다.
- **결정은 바로 문서에 적는다.** 압축되면 대화 내용은 사라진다.
- **Unity 콘솔은 error만 먼저 본다.** warning은 개수만 센다(아틀라스 경고처럼 대량으로 나오는 경고가 있다).
