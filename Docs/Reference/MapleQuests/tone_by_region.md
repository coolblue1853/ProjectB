한글 본문(KMS) 통계. 원문은 캐시에만 있고 여기엔 **통계·키워드·구조 요약**만 있다(원문 인용 없음). 줄거리 요약은 구조 데이터(NPC·목표·보상)로 우리 말로 새로 쓴 것이다.
