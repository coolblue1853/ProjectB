## 분석 (표본: 한 사람 1회, 아래는 방향용 추정)

- **드롭률 체감 원인 = 정예**: 정예가 처치의 8%(53/663, 씬 `eliteChance` 0.04 의 2배. 원인 미확인: 정예가 오래 살아 처치로 더 잡히는 편향 추정). 정예 1마리 = 장비 1개 확정 + 강화석 1~2 + 골드 96(일반 7.2의 13배). 장비 드롭 줄의 약 75%, R 드롭 줄의 78%(125/161)가 정예 몫. 28분에 장비 약 70개, 강화석 88개, 장비는 `RatCap`·`LeafCap` 처럼 안 입고 파는 것이 다수.
- 일반 몹 확률 드롭은 처치당 0.40줄, 잡템 23%. 실측은 표시 확률의 0.8~1.8배(§1c 상위 8개 중 7개가 1 초과)로 오차 안쪽이나 한쪽으로 쏠림(드롭률 보너스 의심, 표본 부족). 골드 드롭률 21~54%는 규칙 40%와 일치.
- **밤이 더 쉬움**: SideRoad 밤은 낮보다 처치/분 1.7배, EXP/분 2.3배. 처치당 받은 피해만 1.36배(7.0→9.5). CSV 밤 몹 HP·공격은 낮 대비 0.7~1.16배로 차이 없음(§6). 사용자 "밤 몹이 더 세야 한다"와 일치.
- **DeepForest 밤 Ghost 파밍**: 3.7분에 267킬, 73킬/분·EXP 1327/분(SideRoad 낮의 8.3배). Ghost 슬롯 41개, Lv7 한 레벨 210킬 6:24. 레벨당 필요 처치가 설계(Lv6~8 약 260~270, `LevelDesignRef` §3)보다 낮은 구간이 생김.
- **몹 간 격차**: 같은 Lv3·EXP 10 에서 `RatChief` 3타(0.2s) 대 `StoneRabbit` 8타(7.5s, def 6). 저레벨 피격이 큼: Lv2~4 에서 RatChief 17~30, LeftMole 30 (CSV 접촉 19, 플레이어 HP 약 108 → 4~6방 사망, 사망 2회). 피격 시도의 53%(324/622)는 피격 후 무적이 막음.
- 메이플 비교(§5): Lv1~2 HP 20~24 는 메이플 8 의 2.5~3배(▲)이나 메랜 Lv1~2 범위 8~20 의 상단이라 유지 가능. EXP 비는 0.9~1.4 로 정상, 몹 `ForestSnail` HP 130 이 2.0배(경계).

## 기록·도구 한계 (R2 추가 제안)

- 낮/밤은 `cx.night`(1초 주기)로 가능해 PlayBotDesign 추가 불필요. 단 `ev kill` 에 몹 id·EXP·골드·정예 여부·맵·밤이 없어 로그 미러(EXP/드롭 줄) 파싱에 의존한다. 한글 로그는 기록 단계에서 깨져(U+FFFD) 영문 토큰만 쓴다. `ev kill` 필드 추가와 로그 UTF-8 정리를 R2.1 후보로 권한다.
- 처치 시간은 몹 인스턴스 id 가 없어 HP 연속성으로 이은 근사(풀피 시작 사슬만, 정예 제외).

## 총괄 결정 (11-15)
- **#1~#4 대신 코드 밤 배율:** 밤에 스폰되는 모든 몹에 HP ×1.4, 공격 ×1.3, EXP ×1.15 를 적용한다. 배율은 데이터로 둔다. 같은 행을 쓰는 낮 변종(RatThief·RatChief)이 같이 세지는 문제를 피하려는 것이다. 이렇게 하면 MonsterSheet 밤 몹 행은 고치지 않는다(이중 적용 방지).
- **그대로 적용:**
  - #5 Ghost count ×0.6
  - #6 StoneRabbit exp 10→14
  - #7 정예 장비 확정 100→40%
  - #9 PhantomScythe 2→1%
- **#8 보류:** 정예 비율이 설정값 0.04 의 2배(8%)로 나온 원인부터 찾는다(중복 판정 의심). 버그면 고치고 eliteChance 는 0.04 그대로 둔다.
  - **#8 결과(11-15 적용 후): 중복 판정 버그 아님. `eliteChance` 0.04 유지.** 코드 확인: 정예 굴림은 `EnemySpawner.CycleCheck` 스폰 1회당 1번(`AlwaysElite || Random.value < eliteChance`)이고, `PromoteElite` 는 `IsElite` 가드, 풀 반환 `OnDisable` 에서 `DemoteElite` 로 플래그를 지운다(재활성 때 재굴림·플래그 잔존 없음).
  - 로그 실측(두 세션 스폰 1061건, "슬롯 N 스폰" 대 "정예 승격"): 승격 68건 = 6.4%. 이 중 `RatChief_BD` 가 22건(스폰 106건, trait elite 라 `AlwaysElite`)이고 나머지는 46/955 = 4.8%로 0.04 와 표본 오차 안(±1.4%p)이다.
  - 8%(53/663)는 처치 기준 비율이다. 원인은 ① RatChief 의 항상 정예(승격의 32%) ② 일반 몹은 덜 잡힌 채 영역을 벗어나 사라질 수 있는 처치 대 스폰 분모 차이 ③ 퀘스트 추적 정예(`SpawnTracked`)·미니보스(`MiniBossSite`)가 이 굴림과 별개로 정예를 만든다는 점이다. 수정할 코드는 없다. R2.1 이후 `ev kill` 의 `el` 필드로 정예 처치를 직접 센다.
- **R2.1 적용:**
  - `ev kill` 에 몹 id·인스턴스 id·EXP·골드·정예·맵·밤 필드를 넣는다.
  - 한글 로그 U+FFFD 깨짐을 고친다.
