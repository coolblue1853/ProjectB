# 숲 토끼 리디자인 세대 기록 (10-26)

사용자: "아예 형태가 바뀌어도 되니 퀄리티업 — 캐릭터도 완전 바뀌었잖아, 예전에 몹 관련 세대별 핀터레스트 학습한 거" / "가장 기본몹인 토끼만". 기준: ArtStyle §0(자연에 먹힌 몸 + 한 점 발광, 사실적 질감 금지) + 초반 몹은 작고 순하게(early-game-modest).
방식(CharacterPixelRules §0 과 같음): 앵커 고정 → 컨셉만 바꿔 edit_image_pro_flash → 사용자 굿/배드 → 다음 세대.

- 앵커: 원본 토끼(38×32 → 64칸 13,24)를 주인공 Walk_3 그림체 레퍼런스로 다시 그림(`redraw.png`, 5회분)
- 1세대(각 5회분, seed 8401~8404): 1 이끼·버섯+청록 한 점 / 2 잔가지 뿔(재칼로프)+호박색 눈 / 3 마른 잎 귀+씨앗 꼬리 발광 / 4 숯빛 몸+뼈색 가면+옅은 파랑 눈 — `gen1/sheet.png`
- 대기·깡충·피격 셀 시험(앵커 기준, 3회분)은 디자인 확정 뒤 다시 뽑는다

## 2세대 (10-26) — 원본 편집 대신 새로 생성
- 사용자: 1세대 전부 탈락("기존 애 모습이 그대로 있으면 안 된다, 스킨 씌운 것 같다. 3번 느낌으로 아예 다르게").
- 방법: create_image_pro_flash 64×64, style_image = 주인공 셀 Walk_3(외곽선·음영·밀도만 복사, 팔레트는 자유). 시드 8501~8504, 20gen.
- 1 잿빛 재칼로프(이끼 감긴 가지뿔, 호박색 한 눈) / 2 뿌리 토끼(나무껍질 몸, 빈 얼굴에 청록 점) / 3 해골 가면 토끼(짐승 두개골 가면+부러진 뿔, 눈구멍 연초록 빛, 등에 풀) / 4 등불 꼬리 토끼(회청색 긴 귀, 꼬리 끝 씨앗 등불).
- 내 판정: 3이 가장 읽기 쉽고 "토끼+섬뜩" 균형이 좋다. 1·4는 다리가 길어 사슴처럼 커 보여 초반 몹으로는 강해 보인다(early-game-modest 위반 우려). 2는 실루엣이 덩어리져 토끼로 안 읽힌다.
- 크기: 전부 64칸을 거의 채운다. 게임 칸(38×32)에 맞추려면 약 0.55배로 줄이거나 작은 크기로 다시 뽑아야 한다 — 확정 후 축소본을 따로 만든다.

## 3세대 (10-26) — 2세대 3번(해골 가면 토끼)을 더 약해 보이게
- 사용자: "3번이 좋은데 좀 더 약해 보이면 좋겠다" + "배경·캐릭터·몹이 함께 있을 때 부자연스러우면 안 된다".
- 방법: gen2/3.png 를 edit_image_pro_flash(text)로 4안, 시드 8601~8604, 20gen. 몸 22~28칸으로 축소.
- 1 웅크린 어린 토끼(기운 가면) / 2 마른 새끼(가면이 흘러내림, 뿔 없음) / 3 통통한 아기(작은 가면, 뿔 싹 둘) / 4 낮게 엎드린 경계 자세(부러진 뿔).
- 판정 방법을 바꿈: 단독 시트 대신 실제 게임 캡처(mobs_ingame.png)에 주인공과 같은 도트 밀도(화면 1.9배)로 합성한 gen3/scene.png 로 본다. 패널의 사각 얼룩은 옛 토끼를 지운 자국(합성용)이다.
- 발견: 옛 토끼는 주인공보다 도트가 작게(밀도 약 1.25 vs 1.9) 그려져 섞여 보였다 — 새 몹은 주인공과 같은 밀도로 넣어야 한다(mob_write_frames 위치·프리팹 스케일 확인 필요).
- 내 판정: 3이 가장 약하고 자연스럽다. 갈색이 어두운 절벽 앞에서 약간 묻히지만 가면이 밝아 읽힌다. 2는 말처럼, 4는 실루엣이 흐트러진다.
