# 주인공 기준 8방향 (사용자 확정 11-06)
방향 모션을 만들 때 기준 그림은 이 폴더다. 새로 뽑지 않는다.
순서: ①정면 d1 → ②3/4앞(오른) d2 → ③측면(오른) d3 → ④3/4뒤(오른) d4 → ⑤뒷모습 d5 → ⑥3/4뒤(왼) d6 → ⑦측면(왼) d7 → ⑧3/4앞(왼) d8.
- 직접 생성은 5장(d1·d2·d3·d4·d5), 나머지 3장(d6·d7·d8)은 d4·d3·d2 좌우 반전.
- 랜턴은 뺐다(별도 스프라이트도 없음). 반전해도 소품이 반대편으로 넘어가지 않는다.
- 모션을 만들 때 첫 프레임·방향 스켈레톤은 이 그림에서 시작한다. 오른쪽 방향에서 만든 모션은 좌우 반전으로 왼쪽을 만든다.
- 확인용 뷰어: Tools/pixelfx/spin_viewer.py (Logs/motion_review/dir5_new/spin_viewer.html 생성).
