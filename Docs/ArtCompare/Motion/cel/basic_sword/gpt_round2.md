**손 안정화는 `기준점 재지정 → 공용 주먹 → 팔 연결 수정 → 칼 결합 → 타이밍` 순서가 좋습니다.** 지금은 손 좌표와 주먹 모양이 각각 흔들릴 수 있는 구조입니다.

### A. 원인과 검증

| 의심 원인 | 현재 구조에서 생기는 문제 | 생성 없이 검증 |
|---|---|---|
| **손잡이 끝 ≠ 쥐는 중심** | 칼 끝점 추정을 손 좌표로 쓰면, 손잡이 길이·각도 변화가 손 이동으로 섞임 | 모든 셀에 **주먹 중심·손목·칼 피벗**을 서로 다른 색으로 수동 표시. 기존 추정점과 비교 |
| 초안마다 다른 주먹 | 원본부터 손 크기·손목 두께·팔 길이가 다를 수 있음 | 주먹 중심을 맞춘 손 부분 확대본을 나란히 비교. 폭·높이·피부 픽셀 수 기록 |
| **반경 2px 추출** | 중심이 1px만 틀려도 손 일부가 잘리거나 팔·테두리가 들어옴. 방향에 따라서도 추출량 변화 | 원본 주먹과 추출 마스크를 겹쳐 표시. 누락 피부·잘린 외곽선 확인 |
| 이웃 보간·평균 | 실제 손의 가속이나 방향 전환을 지우고, 잘못된 추정값을 주변으로 퍼뜨림 | 수동 표시한 손목 궤적과 추정 궤적 비교. 특히 타격 전후 확인 |
| 칼과 손의 합성 기준 | 피벗 불일치·회전 후 반올림으로 손과 칼이 서로 미끄러져 보임 | 몸을 숨기고 **주먹+칼만** 재생. 손잡이가 주먹 안에서 움직이는지 확인 |

측정은 **화면 좌표와 어깨 기준 상대좌표를 함께** 보세요. 몸 전체의 이동과 손 자체의 튐을 구분할 수 있습니다.

### B. 추천 작업 순서

| 순서 | 작업 | 핵심 기준 |
|---|---|---|
| 1 | 투구를 숨기고 몸·팔·손·칼을 분리해서 확인 | 투구 아래 가려졌던 부분은 수동 픽셀 보완 필요 |
| 2 | 준비·타격·마무리 셀의 **손목과 쥐는 중심을 수동 확정** | 칼 직선에서 손 위치를 역산하지 않기 |
| 3 | 공용 주먹을 먼저 2종 제작 | 옆면·비스듬한 면으로 시작. 방향이 안 맞으면 추가 |
| 4 | 기존 주먹을 지우고 공용 주먹 배치, 손목 연결부 수정 | 공용 주먹만 덮으면 이중 외곽선·굵은 손목이 남을 수 있음 |
| 5 | 손 위치와 칼 각도를 같은 키프레임에서 지정 | 칼의 **쥐는 지점**을 주먹 기준점에 고정 |
| 6 | 중간 셀만 보간하고 픽셀 단위로 정리 | 타격 셀은 고정. 전체 궤적에 일괄 스무딩하지 않기 |
| 7 | 실제 프레임별 시간으로 재생 확인 | 현재 첨부의 균일한 1/15초 표시는 최종 타격감을 판단하기엔 제한적 |

**칼 회전 → 주먹을 위에 합성**은 유지해도 됩니다. 다만 회전·좌표 반올림을 따로 처리하지 말고, 같은 기준점과 최종 정수 좌표를 공유하세요.

### C. 첨부에서 다음으로 걸리는 부분

행마다 왼쪽부터 셀을 셌습니다. 투구를 제거한 모습은 없으므로, 아래는 현재 보이는 몸과 동작 기준입니다.

| 우선순위 | 보이는 구간 | 어색함과 수정 방향 |
|---|---|---|
| **1** | **1행 6→7→8→9셀** | 낮은 찌르기 자세에서 몸이 서고, 다시 깊게 숙여집니다. 칼보다 **몸의 높이 변화가 연결을 끊는 인상**입니다. 골반 높이와 상체 기울기를 먼저 연결하세요. |
| **2** | **1행 8→9셀 내려베기** | 칼이 머리 위에서 아래로 이동할 때 팔·상체의 중간 경로가 짧게 읽힙니다. 준비 셀의 어깨 회전과 타격 셀의 팔 방향을 명확히 하면 좋습니다. |
| **3** | **2행 2→3→4셀 올려베기** | 낮은 자세에서 얼굴·상체가 한꺼번에 바뀌어, 팔이 올라가는 동작보다 **몸 그림이 교체되는 느낌**이 납니다. 가슴 중심과 어깨 위치를 겹쳐 비교하세요. |
| **4** | **2행 5→6→7셀 이후** | 올려베기 뒤 손과 칼이 내려오며 빠르게 정면 대기로 정리됩니다. 마무리 자세를 조금 유지하고, 팔이 내려오는 회복을 분명히 하면 무게가 살아납니다. |

앞발을 고정했으니 다음 기준은 **골반→어깨→팔꿈치→손목의 연결**입니다. 손만 매끈하게 만들어도 이 연결이 흔들리면 팔 길이가 변하는 것처럼 보입니다.
