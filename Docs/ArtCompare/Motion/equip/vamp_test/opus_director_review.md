# Opus 감독 검수 (11-13, 지시서 `opus_director_brief.md`, REVIEW_BRIEF §5 기준, 흰 바탕 5배)

- **A sonnet (`opus_dir_sonnet/`) — 조건부 합격, 6세대(edit 5 + 모션 1, 재시도 0).** 루프·발 뜸·망토 물결·붉은 안감은 8프레임 내내 유지된다. 결함: 머리가 입력의 포니테일에서 옆으로 흘러내린 머리로 바뀜(단계 A) / 망토 아랫단 1px 잔털, 0~7번 (11~16,45~48), 왼쪽 끝 (1~3,26~40) / 7→0번 망토가 높고 두꺼움에서 낮고 얇음으로 바뀜 / 신발 발끝이 갈퀴처럼 갈라짐, 전 프레임 (18~24,52~58) / 위아래 흔들림 약 1px로 약함.
- **B opus (`opus_dir_opus/`) — 불합격, 7세대(edit 5 + 모션 2, 7001→7002 재시도는 원인 기록 있음, 낭비 아님).** 머리 묶음은 입력에 더 가깝고 위아래 흔들림 약 3px가 더 활공답다. 결함: 2~3번은 망토 바깥 검정만 보이고 붉은 안감이 가는 띠로 줄었다가 6~7번은 넓은 붉은 면이 돼 같은 옷으로 안 보임(§5-2 실패) / 0·7번 머리 꼭대기가 y=0에 닿음(잘림 위험) / 1~5번 팔 아래 망토 가닥이 늘어짐 (22~26,39~44) / 다리·발이 가시처럼 뾰족, 전 프레임 (23~25,54~60) / 3번 얼굴이 더 옆으로 돌아감.
- **비교:** 사용자가 쓸 수 있는 품질에 더 가까운 쪽은 A다. 옷의 일관성이 유지되고 남은 결함(잔털·발끝)은 0세대 픽셀 보정 범위다. B는 머리 보존·흔들림이 낫지만 안감 깜빡임은 재생성 없이는 못 고친다. 두 모델 모두 지시서 덕에 상한 20의 1/3만 썼다(이전 Sonnet 방식 29세대 대비).
