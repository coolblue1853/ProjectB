- 0세대 결론(Claude): **내용은 말로 재현되지만 그림체(굵은 도트·큰 머리·검정 외곽선)는 말만으로 안 잡힌다** → 생산은 모드 B(앵커 style_image) 유지. 시트 `g00_sheet.png`.
- **방식 변경(사용자, 같은 날)**: "세대별로 나한테도 허가 받아. 랜덤한 컨셉으로 캐릭터를 뽑아 봐, 잘된 거랑 못된 거 찍어 줄게. 너도 판단하고 나도 판단하고." → 1세대부터 **현재 생산 레시피(모드 B)로 랜덤 컨셉 캐릭터 4장**을 뽑아, Claude 판정(지표·시트) + 사용자 굿/배드를 합쳐 다음 세대 레시피를 고친다. 세대마다 계획·비용을 보여 주고 허가 후 생성.
