# 첫 1시간 테스트 체크리스트

2026-10-31 / 새 슬롯 기준. 아래 시간은 내일 진행 순서를 위한 배분이며 사람의 60분 완주 실측값은 아니다. 장비 드롭·밤 대기에 따라 늦어지면 현재 퀘스트와 레벨을 적고 다음 항목으로 건너뛰지 않는다.

## 알려진 문제·주의할 점

- 현재 기본값은 낮 고정이다. **첫 시작 후 에디터 메뉴 `Tools/ProjectB/Playtest/Enable Day-Night Cycle (Play Mode)`를 한 번 실행한다.** 실행하지 않으면 Q104는 자연 진행되지 않는다.
- Q104 허수아비는 밤 몬스터다. 낮이면 꽃두더지·토끼 사냥과 채집을 먼저 하고 밤에 돌아온다. 밤 대기를 진행 불가로 오인하지 않는다.
- 꽃두더지는 샛길 서쪽 고지대에 있다. 오른쪽 끝 연결 포털 → 서쪽 구역 → 로프 순서를 따른다. 낮 몬스터이므로 밤이면 낮을 기다린다.
- 일반 숲에서 늑대를 잡기 전에 Q201을 수락한다. 전용 수피 조각은 수락 중에만 떨어진다. 수집 보고 시 재료를 회수한다.
- 새 그림은 이번 작업에서 만들지 않았다. 기존 NPC 색조·퀘스트 아이콘 등 임시 그래픽 품질은 이번 검증 대상 밖이다.
- 프로브의 위치 이동·사망 처리 API·빠른 미니게임 입력은 기능 검증이다. 사람의 전투 난도·한 시간 물약 소비량·완주 시간은 별도로 기록해야 한다.

## 기본 조작

| 행동 | 기본 키 |
|---|---|
| 이동 / 달리기 | ←→ / Shift+←→ |
| 점프 / 발판 아래로 | C / ↓+C |
| 로프 잡기·오르내리기 | 로프에 닿아 ↑ 또는 ↓ / ↑↓, C로 이탈 |
| 평타 / 장비 스킬 | X / A·S·D·F |
| NPC·포털·채집·화로 | 가까이서 ↑ |
| 대화 진행·선택 | Enter 또는 Z, 선택지는 ↑↓ |
| 가방 / 퀘스트 | I / J |
| 물약·귀환 퀵슬롯 | 1~4. 가방에서 소비템을 골라 해당 숫자 또는 슬롯에 드래그해 등록 |
| 창 닫기·취소 | ESC. 대화는 끝까지 진행 |

1층계 시작은 단일 점프다. Z 대시·2단 점프·활공은 잠겨 있다. 장비 스킬은 사용할 수 있다. J 창의 설명과 우측 추적 목표를 확인한다.

## 내일 따라 할 순서

### 0~10분: 타이틀 → 마을 → 첫 의뢰·물약

- [ ] 타이틀에서 ←→로 EMPTY 슬롯 선택, Enter. 에디터에서는 다른 슬롯 선택 시 플레이가 정지하므로 다시 Play한다. 타이틀의 같은 슬롯에서 Enter로 시작한다.
- [ ] 오프닝을 Enter로 끝낸다. 방향키로 움직이고 잠깐 서 있다가 C 점프가 되는지 확인한다.
- [ ] 마을 오른쪽 장로에게 ↑ → Q101 ‘마지막 별의 방향’ 수락. 자동 보고 보상 EXP 700·100G, Lv2 확인.
- [ ] 장로 왼쪽 사냥꾼 루엔에게 Q102 수락. J에 꽃두더지 0/8 표시 확인.
- [ ] 마을 왼쪽 상인에서 소형 물약(25G) 3개 구매. 가방에서 1번 슬롯에 등록. 100→25G인지 확인.
- [ ] 시작 무기 ‘녹슨 검’이 자동 장착되어 X 공격이 되는지 확인. 장비를 얻으면 I에서 해당 장비 선택 후 Z로 교체하고 외형·스탯·공격을 확인한다.

### 10~25분: 샛길·꽃두더지·첫 보고

- [ ] 마을 오른쪽 포털에서 ↑ → 숲 샛길.
- [ ] 오른쪽으로 토끼 구역·화로·채집 구역을 지나간다. 나무·토끼에서 나무 1개와 토끼고기 2개를 남겨 둔다.
- [ ] 오른쪽의 ‘일반 숲’ 포털을 지나 더 오른쪽 연결 포털을 사용해 샛길 서쪽 구역으로 간다. 초반에는 2층계 포털에 가지 않는다.
- [ ] 서쪽 구역에서 오른쪽 경사와 로프를 따라 고지대 꽃두더지를 사냥한다. 로프는 ↑, 이탈 C. 단일 점프로 넘을 수 없는 곳·로프를 잡을 수 없는 곳은 위치를 기록한다.
- [ ] 8/8 달성 뒤 마을 루엔에게 보고. 사냥 중 HP가 줄면 1 물약 사용: 1개 감소·HP 회복·즉시 연속 사용 차단(공유 2초) 확인.
- [ ] 주운 장비 1개를 실제 장착하고 다시 공격한다. 골드는 바닥에서 자동으로 주워지고 HUD에 합산되는지 확인한다.
- [ ] 가방은 15칸이므로 마을 상인에게 일반 재료·불필요한 장비를 중간 판매한다. **수집품/보상을 받을 빈칸 3~5개**를 남긴다. 가방이 차면 머리 위 ?가 있어도 보고가 완료되지 않는다. 토끼고기2·약초1·나무1은 요리용으로 보존한다.

### 25~40분: 약초·밤 사냥·일반 숲 준비

- [ ] Q102 보고 뒤 세나에게 Q103, 루엔에게 Q104를 받는다. Lv3 이상이면 장로에게 Q201도 받는다.
- [ ] 샛길 입구 약초 또는 표본 덤불에서 GreenHurb 3개 수집. 덤불은 ↑ 시작 → 표시 구간에서 다시 ↑. 완료·취소 후 이동이 풀리는지 확인.
- [ ] 세나에게 Q103 보고: 3개 회수·1개 보상. 요리용 약초를 팔거나 소비하지 않는다.
- [ ] 밤이면 샛길 끝 허수아비 6마리 처치 → 루엔 Q104 보고. 낮이면 사냥·채집을 이어간 뒤 밤에 재방문.
- [ ] Lv4가 되면 루엔 Q202, Q103 완료 후 상인 Q203 수락. 상인이 퀘스트 대화를 먼저 띄우면 수락/보고를 마친 뒤 ↑로 상점을 연다.
- [ ] 소형 물약을 보충하고 여유가 되면 귀환 주문서 1개(120G) 구매·다른 퀵슬롯 등록.

### 40~55분: 일반 숲·늑대·첫 요리·관측지

- [ ] 샛길 오른쪽 일반 숲 포털에서 ↑. 높이 올라간 지면 위에서 진입되고 바닥 속에 끼이지 않는지 확인.
- [ ] 입구에서 왼쪽으로 늑대 사냥. Q201 수피 3개는 직접 줍고 Q202 늑대 8마리까지 진행. 수락 전에 잡은 몹은 소급하지 않는다.
- [ ] 마을 장로·루엔에게 각각 보고. Lv5가 되면 일반 숲 입구 이브에게 Q204 수락.
- [ ] 이브 왼쪽 금빛 별 관측지를 밟고 이브에게 돌아와 Q204 보고. 이 목표는 낮에도 된다. J에서 1/1·완료 후 목록 제거 확인.
- [ ] Q203 수락 상태에서 샛길 화로로 간다. 토끼고기 2+약초 1+나무 1 필요. ↑로 열고 ‘허브 토끼구이’ 선택 → X 시작 → 3번 표시 구간에서 X로 뒤집기. 성공 요리 획득·Q203 1/1 확인 후 상인에게 보고.

### 55~60분: 귀환·저장·재시작·로드

- [ ] 안전한 평지에서 귀환 주문서 퀵슬롯 사용, 2초 움직이지 않는다. 마을 도착·주문서 1개 소비·시전 바 닫힘 확인. 이동·피격으로 취소하면 소비되지 않아야 한다.
- [ ] ESC → QUIT GAME(종료 직전 저장)을 사용하거나 에디터 `Tools/ProjectB/Playtest/Save Progress (Play Mode)`로 저장하고 레벨·EXP·골드·아이템·장착·Q101~104/Q201~204 상태·퀵슬롯을 적는다.
- [ ] 일반 숲에 들어가 한 번 저장한 뒤 플레이 정지→재시작→같은 슬롯 진입. **일반 숲으로 복원**되는지 확인한다(샛길과 좌표가 같아도 구역이 바뀌면 안 됨).
- [ ] 기록한 진행과 비교하고 완료 의뢰 보상을 다시 받을 수 없는지 확인. 모든 창을 닫고 이동·공격·점프 확인.

## 체크할 수치

| 시점 | 적을 값 |
|---|---|
| 시작 / 15 / 30 / 45 / 60분 | Lv·EXP·골드·현재 맵·HP·사망 횟수 |
| 사냥 구간 | 일반몹 5마리 처치 시간·쓴 물약·획득 장비 수 |
| 의뢰 보고 | 완료 ID·보상·막힌 지점·대기 원인 |

목표는 Lv5 전후지만 이 8개 의뢰 보상만 합쳐도 6,822 EXP다. 전부 완료하면 사냥 보상을 더해 Lv6 전후가 될 수 있다. 목표 시간에 맞추려고 EXP를 주입하지 않는다.

## 디버그 단축·자동화

- 기존 ESC → RETURN TO VILLAGE는 무료 즉시 귀환이다. 귀환 주문서 경제/시전 검증 중에는 사용하지 않는다.
- 에디터 `Tools/ProjectB/Playtest/Save Progress (Play Mode)`로 수동 저장할 수 있고 ESC 종료도 같은 저장 경로를 호출한다.
- 에디터 `Tools/ProjectB/Playtest/Enable Day-Night Cycle (Play Mode)`로 세션 낮 고정을 해제한다. `Daytime for Screenshot (Play Mode)`는 다시 낮으로 고정한다. 기존 디버그 `0`은 순환이 켜진 상태에서 시간을 60초 앞당긴다.
- 에디터 `Tools/ProjectB/Movement/Unlock All (Play Mode)`는 전체 이동 개방 토글이다. **본 테스트에는 끈다.** 켜면 초반 동선 막힘을 숨긴다. 플레이 종료 시 해제되고 저장되지 않는다.
- `bash Tools/u.sh cs Tools/probes/set_day.cs`: 낮 전환. 밤 의뢰 확인 때는 자연 시간을 기다리거나 별도 밤 프로브 사용 사실을 기록한다.
- `bash Tools/u.sh call refresh_unity '{}'`, 오류 콘솔, `run_tests`는 플레이 정지 후 실행한다. 재컴파일 중 플레이 상태를 이어 쓰지 않는다.
- 일회성 `Tools/probes/firsthour_*.cs`는 기능 검사·좌표 이동·처치 API를 포함하므로 일반 사용자용 치트가 아니다. 커밋에서 제외한다.
