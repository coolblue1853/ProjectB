## 스크린샷 관찰 (창고 화면, 사용자 제공 11-08 — 코드 확인 전, 추정)
- 창고 하단 안내가 키 조합으로만 길게 나열(G/RT 같은 종류, T/SELECT 재료 전부, R/R3 정렬·꺼내기 모드, C/Y 수량): 마우스 버튼·툴팁으로 대체해야 일반적.
- 상단 BOX 1~5 탭이 큰 버튼, 아이템 칸 위에 가림 요소. 테두리·간격이 인벤과 다름.
- 화면 하단에 개발 치트 버튼(Heal·Unstuck·Day·Night·Day-Night Cycle·Fill Quests·Save·God Mode)이 보임: 릴리스에서는 숨김 처리 필요(개발용이면 에디터 전용).
- 창고가 열린 상태에서 인벤 칸이 화면에 보이지 않아 드래그 이동 대상이 불분명.
