## 육안 검토

- 총 `r3_*.png` **182장** 생성. 포털·몹·자원·점프·저장 비교 시트와 대표 원본을 열어 검토했다. 모든 원본182장을 개별 확대 검토했다는 의미는 아니다.
- 포털은 검정 화면 후 목적지에서 밝아졌다. 수백 칸의 가로 이동과 마을 높이 이동이 밝은 화면에 미끄러져 보이지 않았다. 내부 포털 양방향 도착과 일반 숲 입구 표시 정상.
- 반복 방문 배너 없음. 일반 숲 최초 배너는 표시됨.
- 샛길 자원은 지면에 보이고 평타·파괴 조각·드롭·재생성이 표시됐다. 나무 파괴 직후 크게 회전하는 나무 잔해는 기존 사망 연출이며 이번에 제작·수정하지 않았다.
- 딱정벌레는 지면에 표시됐고, 여우는 웅크림과 이동이 이어졌다. 두꺼비는 낮은 도약 및 구름을 확인했다. 다수 몹이 밀집해 주인공과 겹친 구간은 있으나 이번 표본에서 지속 끼임·잘림·방향 뒤집힘 문제는 확인하지 못했다.
- 저장 재시작은 타이틀 해제 후 다시 낮 캡처했고, 발이 지면에서 떠 있는 현상은 보이지 않았다.

## 제외한 초기 시도·문제 재현 기록

1. 첫 EditMode job `e905606f91524d7c94b21e0772602342` 도중 플레이를 요청해 테스트 러너가 중단됐다. 검사 순서 오류이며 게임 결함으로 세지 않았다. 정지→SampleScene 재로드→전체440개 완료 확인 후 플레이로 순서를 바로잡았다. `r3_tests.json`, `r3_console_mid.json`에 무효 시도 보존.
2. 첫 자원 측정은 광석 파괴 후 대기 중 플레이어가 사망해 마을로 돌아갔다. `r3_resource_initial.txt`의 리젠 타임아웃·나무 hp100 비활성은 통과 근거에서 제외했다. 주변 몹 스포너와 몸박을 격리한 뒤 평타부터 다시 측정했다. 최종 자원 PNG는 재검사 결과다.
3. 초기 새 몹 검사 일부도 다수 몹 동시 피격으로 관찰이 끊겼다. 이후 기능 검사 체력1,000,000·몸박 격리를 사용했다. 초기 hunt0 회차는 퀘스트 검증에서 제외했으며, 같은 로그의 후속5/6/6 사망 및 NPC Done으로 판정했다.
4. 초기 딱정벌레 촬영은 프로브로 서쪽에 이동한 뒤 카메라 경계를 적용하지 않아 대상이 화면 밖이었다. 프로브에 현재 맵 경계 적용을 추가해 다시 촬영했다. 게임 포털의 경계 오류로 해석하지 않았다. 최종 딱정벌레 PNG·CSV는 재촬영분이다.

## 미검증·해석 범위

- 정상 조작으로 연속 플레이한 난도·물약 소비량·처치 시간·1시간 완주 페이스는 미검증. 위치 이동·사전 조건 단축·사망 API·체력 보호를 사용한 기능 검사다.
- Q105/Q305/Q405 접근용 선행 의뢰와 Lv9는 검사 전용으로 설정했다. 해당 선행 의뢰들의 자연 진행을 이번에 검증한 것이 아니다.
- 두꺼비의 낮은 점프는 기존 BT 점프 태스크를 직접 호출해 비교했다. 자연 AI가 모든 거리·지형에서 적절히 점프를 선택하는지는 미검증. 포자 피해량·지속시간의 정밀 재측정도 범위 밖이다.
- 자원 실제 평타·드롭·자연 리젠은 샛길 Tree/Stone 각1표본. 다른 맵 전체 자원 배치와 모든 지터 위치의 시각 검사는 미검증.
- 포털의 렌더 로그는 이동 순간 암전과 완전 복귀를 확인한다. 최소화·프로브 지연 환경이므로 정상 포커스 환경의 초 단위 페이드 감각이나 모든 프레임의 미세한 패럴랙스 품질까지 보증하지 않는다.
