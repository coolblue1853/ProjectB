# 샛길 경제 시뮬 (11-03, Q-F1E, 에디트 모드 모델 — 게임 내 미검증)

도구: `Tools/probes/_f1e_sideroad.cs`(`HuntingAudit.KillSeconds`·`HuntingRules.Simulate` 600초 모델, 코드/데이터 무변경). 가정: 소 물약 25G(회복 120, Lv<3)·중 45G(220, Lv3), 몸박 일반 ×0.5(`ContactRules.ScaledDamage`, 정예·보스 1), 판매 드롭·의뢰 골드 제외(직접 골드만), 일반 몹 골드 확률 0.4. 모델 물약 소비는 과대(Q-448).

| 레벨 | 시간 | 처치/분 | 직접 골드/시간 | 받는 피해/분 | 물약/시간 | 물약비 (몸박 ×1 → ×0.5) |
|---|---|---|---|---|---|---|
| Lv1~2 | 낮 | 8.3 | 2,389 | 93 → 48 | 46.6 → 24.2 | 48.7% → **25.3%** |
| Lv1~2 | 밤 | 8.4 | 3,338 | 100 → 51 | 50.0 → 25.4 | 37.5% → **19.0%** |
| Lv3 | 낮 | 14.7 | 4,252 | 49 → 28 | 13.7 → 7.6 | 14.5% → 8.1% |
| Lv3 | 밤 | 14.4 | 5,746 | 55 → 31 | 15.2 → 8.6 | 11.9% → 6.7% |

- 몸박 ×0.5 로 낮 35→25%(기존 문서 모델 52→25), 밤 19%. 낮·밤 평균 약 22% — 목표 20~30% 안.
- 밤이 19% 로 약간 낮을 뿐이라 **조정 불필요**. 낮 골드 +17% 나 Potion 가격 인하를 하면 밤이 15~16%/낮 21% 로 오히려 내려간다.
- 평타 후딜 중 몸박 무시(`AttackingGrace`)는 미반영 → 실제는 더 낮을 수 있다. 낮이 30% 를 넘는 일이 생기면 그때 Potion 가격 인하(25→21G, 약 -15%)가 골드 +17% 보다 낫다(물약만 줄어 인플레 적음).
- Lv3 이후는 무기 교체로 8% 대. 샛길 의뢰·판매 골드(약 340~390G/분) 포함 시 실부담은 훨씬 작다.
