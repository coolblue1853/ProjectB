# 첫 1시간 플레이 안내 (11-01 19:00 테스트용)

자세한 확인 항목은 `FirstHourChecklist.md`에 있다. 이 문서는 **처음 켜서 1시간 동안 무엇을 하면 되는지**만 짧게 정리한다.

## 시작 전 (에디터, 2분)

1. Unity에서 `SampleScene`을 열고 Play.
2. 타이틀에서 ←→로 **EMPTY 슬롯**을 고르고 Enter. 다른 슬롯을 고르면 플레이가 멈추니 다시 Play하고 같은 슬롯에서 Enter.
3. 메뉴 `Tools/ProjectB/Playtest/Enable Day-Night Cycle (Play Mode)`를 한 번 실행한다. 이걸 안 켜면 계속 낮이라 밤 몹 퀘스트(Q104 허수아비)를 할 수 없다.

## 치트 (SR Debugger, 11-01)

화면 위 가운데에 치트 버튼 줄이 늘 떠 있다: Level +1 · EXP +500 · Gold +1000 · Heal · Day · Night · Day-Night Cycle · Fill Quests(진행 중 의뢰 목표 채우기, 수집은 아이템 지급) · Save · God Mode(무적).
구역 이동(Town·Side Road·Near/Normal/Deep Forest·Swamp·Bandit Fortress·Tower Outskirts)과 아이템 지급(Item Key 입력 → Give Item, LeafAdae+FangDagger 한 번에)은 **Ctrl+Shift+F1**(또는 화면 오른쪽 위 구석 세 번 클릭) → Options 탭.
**조작이 안 먹으면 Game 창을 한 번 클릭**한다(에디터가 포커스 없이 플레이를 시작한다).
**벽·모서리에서 몸이 굳으면 치트 줄의 Unstuck**을 누른다. 그때 상태가 `Logs/stuck_state.txt`에 남아 원인을 찾을 수 있다.

## 1시간 흐름

| 시간 | 할 일 | 얻는 것 |
|---|---|---|
| 0~10분 | 마을 장로(오른쪽) Q101 → 사냥꾼 루엔 Q102 수락. 상인(왼쪽)에서 소형 물약 3개 사서 1번 슬롯 등록 | Lv2, 물약 |
| 10~25분 | 오른쪽 포털 → 숲 샛길 → 서쪽 고지대(로프)에서 꽃두더지 8마리 → 루엔 보고 | 첫 새 무기 **잎사귀 단검**(LeafAdae) |
| 25~40분 | 약초꾼 세나 Q103(약초 3개 채집), 루엔 Q104(밤 허수아비 6), 장로 Q201 | 레벨 3~4, 물약 |
| 40~55분 | 일반 숲 늑대 사냥(Q201 수피 + Q202 늑대 8), 탐험가 이브 Q204 관측지, 샛길 화로에서 첫 요리(Q203) | 무기 **FangDagger**, 늑대 방어구 → **2세트 효과** |
| 55~60분 | 귀환 주문서(2초 가만히) → 마을 **기록지기**에게 ↑로 저장 → 정지 → 다시 시작해 이어지는지 확인 | |

**1시간이 끝나도 계속 해도 된다.** 다음은 깊은 숲(곰·엔트, Q301~304, 보상 BearClaw·RootStaff) → 늪(Q401~404, CrocJawAxe·거대 슬라임 보스) → 산적 성채(Q501~504, 선택) → 탑 근교(Q601~604, 문지기 처치 시 지상 대시 개방·2층계 길) 순서다. 1층계 끝까지 대략 Lv15, 사냥 실측 약 4시간.

새 몹 의뢰도 있다. 루엔의 **Q105(샛길 낮 딱정벌레 5)·Q305(깊은 숲 여우 6)**, 세나의 **Q405(늪 두꺼비 6)**다. 깊은 숲·늪에는 기존 몹도 섞여 나온다. 두꺼비를 때린 자리에 포자 구름이 생기면 물러난다. 여우는 잠깐 웅크렸다가 2칸쯤 돌진하니 웅크림을 보면 피한다. 딱정벌레는 느리지만 잘 밀리지 않는다.

문지기를 잡은 뒤에는 **마을 장로에게 Q604를 보고해야 지상 대시가 열린다.** 2층계에 들어가면 2단 점프·활공도 열린다. 가방이 차면 Q405·Q604 보고도 보류되므로 남는 물건을 팔고 다시 말을 건다.

나무·광석(채집 재료)은 마을 출구 앞이 아니라 샛길 오른쪽 굴·서쪽 구역, 깊은 숲 곳곳에 흩어져 있다. 포털을 타면 화면이 잠깐 검게 바뀌었다 밝아진다.

Q602 기록 5편은 탑 근교 유적 1곳을 반복 발굴해도 된다. 유물이 나오면 일반 5분·희귀 10분 뒤 다시 판다. Q602를 끝내기 전에도 문지기 의뢰 Q604는 진행할 수 있다.

## 보면 좋은 것 (느낌 위주)

- **사냥 속도:** 새 무기를 끼면 사냥이 확실히 빨라지는가. 너무 세거나 너무 약하지 않은가.
- **세트 효과:** 늑대 2세트가 켜졌을 때 체감되는가(I 창에서 세트 표시 확인).
- **몸박·물약:** 몹에 부딪혀 맞는 아픔이 적당한가. 물약을 1시간에 얼마나 쓰는가.
- **동선:** 퀘스트가 다음 장소로 자연스럽게 이끄는가. 길을 잃은 곳이 있었는가.
- **NPC 말투:** 어색한 대사가 있었는가.
- **임시 그림:** 새 몹 3종과 스킬 이펙트 일부는 **임시 그림**이다. 그림 품질보다 "이런 몹·이펙트가 이 자리에 있으면 좋은가"를 봐 준다.

## 막히면

- **가방이 꽉 차서 보고가 안 될 때:** I에서 장비를 끼거나 마을 상인에게 팔면 된다. 진행·보상은 사라지지 않는다. 요리용 토끼고기 2·약초 1·나무 1은 남긴다.
- **허수아비가 안 보일 때:** 밤 몹이다. 낮이면 다른 퀘스트를 하고 밤에 다시 간다.
- **꽃두더지가 안 보일 때:** 샛길 오른쪽 끝 연결 포털 → 서쪽 구역 → 로프 위다. 낮 몹이다.
- **수피가 안 떨어질 때:** Q201을 먼저 받아야 떨어진다.
