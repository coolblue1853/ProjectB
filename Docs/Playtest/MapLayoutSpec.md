# 1층계 맵 고유 지형 설계안 (REWORK-10 보강, 11-14)

목적: `MapReview.md` §1·§4 의 "지형 3벌 복제"를 풀 맵별 설계안. 문서만 — 씬·코드·CSV 는 바뀌지 않았다.

## 0. 데이터 출처와 한계 (먼저 읽기)

- **11-14 maplestory.io(GMS v83) 실측**: 메랜닷컴(itshim.dev)이 쓰는 공개 API. 맵 4,411개 목록 중 3,878개 상세(발판 좌표·로프·포털·스폰 지점·몹)를 받아 `Docs/Reference/MapleMaps/`에 요약했다(`README.md`, `maps_summary.csv`, `levels_1_70.md`). 아래 §1 수치는 전부 거기서 나온 값이다(`Tools/maple_maps_dump.py`).
- 이전(메랜닷컴 화면 눈대중) 판의 "사이트에 없음" 항목(가로 길이·발판·로프·스폰 지점 수)은 이제 실측으로 채웠다. 몹 종·최대 마릿수는 이전 판과 거의 일치(예: 동쪽숲 62슬롯 vs 사이트 60).
- 읽는 법: 폭·높이는 발판 좌표 범위(px, 메이플 해상도 기준). `층` = 수평 발판 y 를 40px 로 묶은 수(경사가 많으면 커진다), `발판 덩어리` = 서로 이어진 발판 묶음 수. 로프+사다리는 합산. 스폰 슬롯 = 몹 1마리 단위 스폰 지점(우리 `HuntingSpawnsFloor1.csv` 의 포인트×count 와 같은 단위). 밀도 = 발판 1000px 당 슬롯. 리젠 배율은 `mobRate`(1=기본, 클수록 빠름). 포털 일반/히든 구분은 API 로 정확히 못 하며, `비가시`는 type 1 포털 수(추정).
- 한계: v83 수치라 해상도·점프 높이가 우리와 다르다. **구조·비율만 참고하고 지형 모양·그림은 복제하지 않는다.** 대응은 Lv·역할 기준 선택(1:1 아님).

## 2. 공통 설계 규칙 (우리 기준)

값 출처: `ClassicMapleDesign §3.5`, `MapReview §2`(현재 개체 수·포털), §1 실측(11-14 조정 반영).

- **단위**: 폭은 이제 **메이플 대응 맵 px(§1)의 1.3~1.5배**로 적는다(대응 맵 px × 1.4 기준). 이전의 "SideRoad 대비 배율"은 유닛↔px 환산이 미확인이라 폐기. 우리 씬 유닛 환산은 프로브(`MapReview §4-2`)로 확정 후 적용.
- **맵 폭 결정(사용자 11-14)**: 솔로 게임이라 맵 가로는 메이플 대응 맵보다 넓게(대략 1.3~1.5배 기준, 맵 성격별 조정). 대신 한 화면 몹 수·발판 길이당 몹 밀도는 메이플 수준 유지 — 넓힌 만큼 스폰 지점·최대 몹 수를 비례 증가하거나 짧게 도는 사냥 루프 동선으로 이동만 늘어 지루해지지 않게 한다. §3 폭 배율은 현 SideRoad 대비 값이며, 메이플 실측(§1) 확정 시 "메이플 대응 맵의 1.3~1.5배"로 재산정하고 스폰·동시 몹을 폭에 비례해 맞춘다.
- **발판 층**: 입문 2, 중반 3, 후반 3~4. 층 간 고저차 250~450px. **실측 대조(11-14)**: 메이플 필드는 큰 층 3~4 위에 작은 발판이 19~56덩어리 깔린다. 우리도 층 수는 위 범위를 유지하되 **작은 발판(2~4칸)을 층마다 2~4개 추가**해 몹 군집 자리를 만든다.
- **로프/사다리**: 실측 로프+사다리는 폭 2,250~3,970px 맵에서 5~22개(Lv1~70 중앙값 7). 인접 층마다 2~3개로는 부족하니 **맵당 5~8(세로형 탑 근교는 10 안팎)**로 늘린다. 인접 층마다 **층 사이 이동은 항상 두 경로 이상**(한쪽 끝 + 중앙). 막다른 발판은 히든 포털(`HiddenPortals.csv`)로 복귀.
- **한 화면 몹**: 6~12. 맵 총 개체는 포인트별 `count` 합이 아니라 **동시 활성 상한**으로 관리. 한 포인트 최대 4(Swamp 8 은 분산 대상). **총 슬롯(포인트×count) 기준은 실측 23~64슬롯**(밀도 약 4/1000px, 폭 ×1.4 하면 슬롯도 비례): 우리 설계의 6~9 포인트는 `count` 합이 30~60 이 되게 맞추고, 성채 266·늪 24 처럼 크게 벗어난 값은 이 범위로 정리.
- **리젠**: 현재 10초 고정(기획 결정 대기). 설계안엔 "약한 몹 빠르게(8초) / 단단한 몹 느리게(15초)" 차등 후보만 표기, 적용은 별도 결정. 실측 리젠 배율도 입문 맵 1.0~1.7, 단단한 몹 맵 0.6~1.2 로 같은 방향(§1).
- **분위기**: 어둡고 소박. 초반(샛길·일반 숲)은 단순 구조, 후반으로 갈수록 층·위험 증가.
- **보존 원칙(총괄 결정 11-14)**: 38ba36c6f 의 '맵 2장 보존'은 DeepForestCore·MistSwamp 소실 방지였고 수정 금지가 아니다. 지형 묶음마다 원본 1장 유지 — A=NearForest_SideRoad, B=DeepForest, C=Swamp. 나머지(BanditFortress·DeepForestCore·TowerOutskirts·MistSwamp·NormalForest)를 고유 지형으로 바꾼다.

## 3. 맵별 고유 지형 설계안

표기: 발판 층(최하 G=지면) · 로프 · 포털 · 스폰 · 최대 동시 몹 · 리젠 · 동선. 폭은 현 SideRoad 활성 맵(약 616유닛) 대비 배율.

### 3.1 NearForest_SideRoad (샛길) — 보존, 지형 A
- 현황 유지. 폭 1.0, 층 9~10(2유닛 단위 소단차), 사다리 16. 포털: 마을(-236)·내부·일반 숲(-262)·히든 `sr_ledge`·(Lv2 직결은 FT-* 담당).
- 변경 없음. **다른 맵과 겹치지 않도록 이 지형은 일반 숲에서 빼야 한다**(아래 3.2).

### 3.2 NormalForest (일반 숲) — 재설계 "나무 사이 오르막"
- 근거 역할: 첫 마을 옆 사냥터. 샛길과 확실히 달라야 함.
- **실측 대조(동쪽숲 3742×2251, 층 22·발판 56덩어리, 로프+사다리 22, 슬롯 62, 출구 4)**: 아래 "3층·로프 2·스폰 6"은 너무 단출하다 → **큰 층 4, 작은 발판 6~8, 로프+사다리 6~8, 슬롯 40~60(포인트 12~16×count 3~4), 폭 약 5,200px(3742×1.4)**. 동시 활성 10 은 유지.
- 구조: 3층. 좌측 지면 → 중앙으로 **계단식 경사 발판 3단**(고저 250px씩) → 우측 높은 능선. 로프 2(좌 하→중, 우 중→능선). 낭떠러지 없음(입문 안전).
- 포털: 좌끝 마을(-425), 우끝 능선에서 깊은 숲, 중앙 아래 샛길(-262). 히든 `nf_ledge` 는 능선 끝 막다른 발판(좌측 복귀).
- 스폰 6 포인트: 지면 2(달팽이·위습), 중단 발판 2(숲포자·늑대), 능선 2(멧돼지·사냥자 소수). 동시 10, 리젠 10초(달팽이는 8초 후보).
- 동선: 마을 → 지면 달팽이 → 계단 올라 늑대 → 능선 → 깊은 숲 출구. 한 바퀴 약 60초.
- 폭 약 5,200px(동쪽숲 ×1.4). 타일: 기존 숲 타일 + 경사 연결(§4 신규 후보 T1).

### 3.3 DeepForest (깊은 숲) — 보존, 지형 B 원본 1장(작은 숲)
- 현황 유지. 단 포털 5개 몰림은 **좌 2(마을·일반 숲), 우 3(늪·성채·심부)** 로 간격만 재배치 후보(씬에서 포털 좌표만 이동, 지형 불변).
- 변경 최소. 하이라이트: 여우 12·곰 33 유지. 실측 대응(남쪽숲 3343×2284, 슬롯 58, 출구 9)과 비교해 규모는 이미 충분.

### 3.4 DeepForestCore (심부) — 재설계 "뿌리 동굴"
- 근거 역할: 막다른 단일/소수 종 사냥터(확인: 개체 36·포털 1 사례). 현재 늪 지형(C) 복제라 숲 심부 컨셉과 어긋남 → 고유 지형 대상(DeepForestCore, 소실 방지 보존이었을 뿐 수정 금지 아님).
- 구조: 2층. 거대한 뿌리가 만든 **U자형 낮은 바닥 + 양쪽 높은 뿌리 발판**. 로프 2(양쪽 끝). 천장 낮음, 어두움. 막다른 곳이 의도.
- 포털: 입구(-417) 하나 + **히든 포털 1**(우측 뿌리 위 → 깊은 숲 우측 복귀. REWORK-14 `HiddenPortals.csv` 행 추가 후보).
- 스폰 5: 바닥 3(유령·엔트), 뿌리 발판 2(요정). 숲 고블린 12는 바닥 중앙 4포인트 분산. 동시 9, 리젠 12초 후보.
- 폭 대응 맵이 세로형이라(1056×1935) 우리 설계는 가로 약 1,500~2,000px 로 정한다(×1.4 대신 U자 바닥 길이 우선). **실측 대조: 층 6·로프 6(평균 627px 긴 로프 2개)·슬롯 16 단일종** → 층 2→3, 로프 2→4(긴 로프 포함), 슬롯 16~24 로 상향.

### 3.5 Swamp (늪) — 재설계 "수로 징검다리"
- 현황 지형 C 가 컨셉에 맞으므로 **지형 C 원본 1장(기준 늪)**으로 유지하되 스폰 분산(포인트당 최대 4)으로 겹침 해결.
- 구조: 3층. 물 수로(저지대, 이동 감속 없음 — 기능 추가 없이 시각) + 중간 통나무 발판 + 상단 둑길. 로프 3. 낭떠러지 대신 "빠짐=저지대 복귀"(위험 없음).
- 포털: 좌 깊은 숲(-417), 우 탑 근교(-186), 중앙 상단 안개늪(-308).
- 스폰 8 포인트 × 평균 3 = 슬롯 24 → **실측 대조(1호선 1구역 3970×970, 사다리 18, 슬롯 64 단일종, 밀도 4.4)**: 슬롯 48~64(포인트 14~16×count 4), **사다리 8~12(낮고 긴 맵이라 짧은 사다리 다수)**, 동시 활성은 화면 단위 트리거로 8 이하. 리젠 10초.
- 폭 약 5,200~5,500px(3970×1.4). 층 3 은 유지하되 작은 발판 추가. 기존 늪 타일만으로 가능(재배치).

### 3.6 MistSwamp (안개늪) — 재설계 "안개 속 단일 순환로"
- 근거 역할: 막다른 맵. Swamp(지형 C 원본)와 구분되는 고유 지형 대상(MistSwamp, 소실 방지 보존이었을 뿐 수정 금지 아님): **발판이 원형 순환**(한 방향으로 돌면 한 바퀴 55초).
- 구조: 2층, 중앙 큰 섬 + 외곽 고리 발판 4개를 로프·점프로 연결. 중앙 섬은 보상 소수 정예 몹 자리. 안개 이펙트(알파 낮춘 오버레이 스프라이트, 코드 없음).
- 포털: 입구(-417) + 히든 1(중앙 섬 → 늪 상단 복귀).
- 스폰 6(안개 몹 모기·악어 위주 + 중앙 정예 1). 동시 10, 리젠 12초 후보. **실측 대조(Jr.네키 늪 3240×546 낮고 긴 습지, 로프 5, 슬롯 30, 출구 1)**: 폭 약 4,500px(×1.4), 로프 3→5, 슬롯 30~40. 낮고 긴 형태라 순환 고리는 높이 약 550px 안에 압축.

### 3.7 BanditFortress (산적 성채) — 재설계 "성벽 3단"
- 근거 역할: 마을 외곽 요새·적 거점(분기). 현재 숲 지형 복제라 가장 어긋남.
- 구조: 4층. **성벽 안뜰(지면) → 목책 발판(2층) → 망루 연결 발판(3층) → 성루 옥상(4층)**. 로프 대신 **사다리 위주**(각 층 2개), 한 곳은 부서진 사다리(막다른 지름길, 히든 포털 `bf_ledge` 후보로 옥상→안뜰 복귀).
- 포털: 좌 마을(-425), 우 깊은 숲(-236). 보스 산적두목 방은 옥상 끝(트리거 분리).
- 스폰 9(266 개체는 과다): 안뜰 3(방패병·횃불병), 목책 2(궁수), 망루 2(자객), 옥상 2(보초·정예). **동시 활성 12 이하**. **실측 대조(서쪽바위산 2746×1599, 로프+사다리 5, 슬롯 23, 리젠 배율 0.6)**: 총 슬롯 266 → **30~40**(실측 23 ×1.4)으로 크게 낮추고 리젠은 15초 이상. 사다리 8 → 6.
- 폭 약 3,800px(×1.4). 새 타일 필요(석재 성벽·목책, §4 T2).

### 3.8 TowerOutskirts (탑 근교) — 재설계 "무너진 계단 폐허"
- 근거 역할: 유적·폐허, 탑 입구 직전. 깊은 숲 복제(B)에서 벗어난다.
- 구조: 3층. 대각선 **무너진 계단**(경사 발판 연속) + 부유 석재 발판. 낭떠러지 1곳(떨어지면 지면 복귀, 피해 없음). 로프 2 + 경사 계단.
- 포털: 좌 마을(-425), 우 늪(-236), 최상단 Lv2_MagicCliffs(-433). 최상단 도달은 계단 끝 → **2층계 진입 의식**.
- 스폰 7(골렘 3종·정령·파수꾼). 동시 10, 단단한 몹(대골렘)은 리젠 15초 후보. **실측 대조(동쪽령 2250×2235 세로형, 층 16·덩어리 45, 로프+사다리 18, 슬롯 47)**: 층 3→큰 층 4(세로 지그재그), 로프 2→8~10, 슬롯 7 포인트→40~50. 폭 약 3,150px(×1.4), 높이는 점프 한계 때문에 배율 1.0(약 2,200px). 새 타일 필요(§4 T3).
