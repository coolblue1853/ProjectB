## 0. 조사 결과와 한계 (먼저 읽기)

- **메랜 DB(`mapledb.kr`) 접속 실패(11-14)**: WebFetch 2회 `read ECONNRESET`, `curl` 응답 본문 비어 있음. **11-14 Chrome 연결 후 재시도**: `https://mapledb.kr/`·`http://www.mapledb.kr/` 이동 시 탭이 곧바로 새 탭(chrome://newtab)으로 돌아가고 도구가 "페이지가 다른 도메인으로 이동" 보안 검사로 읽기·스크린샷을 거부해 **본문을 한 번도 읽지 못했다**(사이트 차단·리다이렉트 추정, 원인 미확인). 따라서 §1 의 메이플 맵별 실측 값은 **전부 "미확인"** 이다. 추측으로 채우지 않는다.
- 이미 확인된 값(`LevelDesignRef.md` §2, 11-11 WebFetch 요약): 입문 필드 맵당 몹 5~7종·최대 개체 합 39~54(약한 몹 3~27, 단단한 몹 2~5)·포털 2~3(히든 1 포함). 고레벨 단일 종 사냥터 개체 36·포털 1. 이 값만 근거로 쓴다.
- 사이트에 원래 없는 값(`LevelDesignRef` §0): 맵 가로·세로, 발판·로프 좌표, 리젠 주기, 스폰 지점 수. 접속이 돼도 못 얻을 가능성이 높다.
- 그래서 §2 설계안의 구조 값(발판 층·로프 수 등)은 **`ClassicMapleDesign.md` §3.5(폭 2,500~5,500px, 2~4층, 고저차 250~450px, 포털 일반 2+비밀 0~1)와 우리 구역 컨셉(`FloorCoreContent.md`)에서 정한 설계 목표**이지 메이플 실측이 아니다. 메이플 맵과 1:1 대응은 **후속 조사 후 §1 을 채워 확정**한다.
- 후속(11-14 Chrome 시도도 실패, 0/9 채움): 사용자가 Chrome 에서 직접 mapledb.kr 이 열리는지 확인하거나, 도구 허용 도메인 설정을 풀어 준 뒤 §1 표를 채우거나, 사용자가 직접 맵 구조를 알려줄 것. `Docs/OpenQuestions.md` Q-MAPLAYOUT 로 기록.

## 2. 공통 설계 규칙 (우리 기준)

값 출처: `ClassicMapleDesign §3.5`, `MapReview §2`(현재 개체 수·포털). 실측이 §1 에 채워지면 이 절을 조정.

- **단위**: 유닛(1유닛=약 32px 가정, 샛길 실측 폭 약 616유닛≈19,700px 은 §3.5 목표 5,500px 의 3.5배이므로 `미확인: 유닛 환산 재확인 필요`). 아래 폭은 "현재 활성 맵 대비 배율"로 쓴다.
- **발판 층**: 입문 2, 중반 3, 후반 3~4. 층 간 고저차 250~450px.
- **로프/사다리**: 인접 층마다 2~3개, **층 사이 이동은 항상 두 경로 이상**(한쪽 끝 + 중앙). 막다른 발판은 히든 포털(`HiddenPortals.csv`)로 복귀.
- **한 화면 몹**: 6~12. 맵 총 개체는 포인트별 `count` 합이 아니라 **동시 활성 상한**으로 관리. 한 포인트 최대 4(Swamp 8 은 분산 대상).
- **리젠**: 현재 10초 고정(기획 결정 대기). 설계안엔 "약한 몹 빠르게(8초) / 단단한 몹 느리게(15초)" 차등 후보만 표기, 적용은 별도 결정.
- **분위기**: 어둡고 소박. 초반(샛길·일반 숲)은 단순 구조, 후반으로 갈수록 층·위험 증가.
- **보존 원칙(총괄 결정 11-14)**: 38ba36c6f 의 '맵 2장 보존'은 DeepForestCore·MistSwamp 소실 방지였고 수정 금지가 아니다. 지형 묶음마다 원본 1장 유지 — A=NearForest_SideRoad, B=DeepForest, C=Swamp. 나머지(BanditFortress·DeepForestCore·TowerOutskirts·MistSwamp·NormalForest)를 고유 지형으로 바꾼다.

## 3. 맵별 고유 지형 설계안

표기: 발판 층(최하 G=지면) · 로프 · 포털 · 스폰 · 최대 동시 몹 · 리젠 · 동선. 폭은 현 SideRoad 활성 맵(약 616유닛) 대비 배율.

### 3.1 NearForest_SideRoad (샛길) — 보존, 지형 A
- 현황 유지. 폭 1.0, 층 9~10(2유닛 단위 소단차), 사다리 16. 포털: 마을(-236)·내부·일반 숲(-262)·히든 `sr_ledge`·(Lv2 직결은 FT-* 담당).
- 변경 없음. **다른 맵과 겹치지 않도록 이 지형은 일반 숲에서 빼야 한다**(아래 3.2).

### 3.2 NormalForest (일반 숲) — 재설계 "나무 사이 오르막"
- 근거 역할: 첫 마을 옆 사냥터. 샛길과 확실히 달라야 함.
- 구조: 3층. 좌측 지면 → 중앙으로 **계단식 경사 발판 3단**(고저 250px씩) → 우측 높은 능선. 로프 2(좌 하→중, 우 중→능선). 낭떠러지 없음(입문 안전).
- 포털: 좌끝 마을(-425), 우끝 능선에서 깊은 숲, 중앙 아래 샛길(-262). 히든 `nf_ledge` 는 능선 끝 막다른 발판(좌측 복귀).
- 스폰 6 포인트: 지면 2(달팽이·위습), 중단 발판 2(숲포자·늑대), 능선 2(멧돼지·사냥자 소수). 동시 10, 리젠 10초(달팽이는 8초 후보).
- 동선: 마을 → 지면 달팽이 → 계단 올라 늑대 → 능선 → 깊은 숲 출구. 한 바퀴 약 60초.
- 폭 1.2. 타일: 기존 숲 타일 + 경사 연결(§4 신규 후보 T1).

### 3.3 DeepForest (깊은 숲) — 보존, 지형 B 원본 1장(작은 숲)
- 현황 유지. 단 포털 5개 몰림은 **좌 2(마을·일반 숲), 우 3(늪·성채·심부)** 로 간격만 재배치 후보(씬에서 포털 좌표만 이동, 지형 불변).
- 변경 최소. 하이라이트: 여우 12·곰 33 유지.

### 3.4 DeepForestCore (심부) — 재설계 "뿌리 동굴"
- 근거 역할: 막다른 단일/소수 종 사냥터(확인: 개체 36·포털 1 사례). 현재 늪 지형(C) 복제라 숲 심부 컨셉과 어긋남 → 고유 지형 대상(DeepForestCore, 소실 방지 보존이었을 뿐 수정 금지 아님).
- 구조: 2층. 거대한 뿌리가 만든 **U자형 낮은 바닥 + 양쪽 높은 뿌리 발판**. 로프 2(양쪽 끝). 천장 낮음, 어두움. 막다른 곳이 의도.
- 포털: 입구(-417) 하나 + **히든 포털 1**(우측 뿌리 위 → 깊은 숲 우측 복귀. REWORK-14 `HiddenPortals.csv` 행 추가 후보).
- 스폰 5: 바닥 3(유령·엔트), 뿌리 발판 2(요정). 숲 고블린 12는 바닥 중앙 4포인트 분산. 동시 9, 리젠 12초 후보.
- 폭 0.9.

### 3.5 Swamp (늪) — 재설계 "수로 징검다리"
- 현황 지형 C 가 컨셉에 맞으므로 **지형 C 원본 1장(기준 늪)**으로 유지하되 스폰 분산(포인트당 최대 4)으로 겹침 해결.
- 구조: 3층. 물 수로(저지대, 이동 감속 없음 — 기능 추가 없이 시각) + 중간 통나무 발판 + 상단 둑길. 로프 3. 낭떠러지 대신 "빠짐=저지대 복귀"(위험 없음).
- 포털: 좌 깊은 숲(-417), 우 탑 근교(-186), 중앙 상단 안개늪(-308).
- 스폰 8 포인트 × 평균 3 = 동시 24 → 화면 단위 활성 트리거로 8 이하. 리젠 10초.
- 폭 1.3. 기존 늪 타일만으로 가능(재배치).

### 3.6 MistSwamp (안개늪) — 재설계 "안개 속 단일 순환로"
- 근거 역할: 막다른 맵. Swamp(지형 C 원본)와 구분되는 고유 지형 대상(MistSwamp, 소실 방지 보존이었을 뿐 수정 금지 아님): **발판이 원형 순환**(한 방향으로 돌면 한 바퀴 55초).
- 구조: 2층, 중앙 큰 섬 + 외곽 고리 발판 4개를 로프·점프로 연결. 중앙 섬은 보상 소수 정예 몹 자리. 안개 이펙트(알파 낮춘 오버레이 스프라이트, 코드 없음).
- 포털: 입구(-417) + 히든 1(중앙 섬 → 늪 상단 복귀).
- 스폰 6(안개 몹 모기·악어 위주 + 중앙 정예 1). 동시 10, 리젠 12초 후보. 폭 1.0.

### 3.7 BanditFortress (산적 성채) — 재설계 "성벽 3단"
- 근거 역할: 마을 외곽 요새·적 거점(분기). 현재 숲 지형 복제라 가장 어긋남.
- 구조: 4층. **성벽 안뜰(지면) → 목책 발판(2층) → 망루 연결 발판(3층) → 성루 옥상(4층)**. 로프 대신 **사다리 위주**(각 층 2개), 한 곳은 부서진 사다리(막다른 지름길, 히든 포털 `bf_ledge` 후보로 옥상→안뜰 복귀).
- 포털: 좌 마을(-425), 우 깊은 숲(-236). 보스 산적두목 방은 옥상 끝(트리거 분리).
- 스폰 9(266 개체는 과다): 안뜰 3(방패병·횃불병), 목책 2(궁수), 망루 2(자객), 옥상 2(보초·정예). **동시 활성 12 이하**, 맵 총 슬롯 100~130 으로 낮춤 후보. 리젠 10초.
- 폭 1.3. 새 타일 필요(석재 성벽·목책, §4 T2).

### 3.8 TowerOutskirts (탑 근교) — 재설계 "무너진 계단 폐허"
- 근거 역할: 유적·폐허, 탑 입구 직전. 깊은 숲 복제(B)에서 벗어난다.
- 구조: 3층. 대각선 **무너진 계단**(경사 발판 연속) + 부유 석재 발판. 낭떠러지 1곳(떨어지면 지면 복귀, 피해 없음). 로프 2 + 경사 계단.
- 포털: 좌 마을(-425), 우 늪(-236), 최상단 Lv2_MagicCliffs(-433). 최상단 도달은 계단 끝 → **2층계 진입 의식**.
- 스폰 7(골렘 3종·정령·파수꾼). 동시 10, 단단한 몹(대골렘)은 리젠 15초 후보. 폭 1.2. 새 타일 필요(§4 T3).

### 3.9 NearForest (구버전) — 비활성 정리
