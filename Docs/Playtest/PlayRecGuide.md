# 플레이 기록 부탁 가이드 (PlayRecorder R2)

봇 학습 자료를 모으는 녹화입니다. 따로 켤 것은 없습니다.

1. 에디터에서 평소처럼 ▶ 플레이하면 **자동으로 기록·녹화**됩니다(로그 + 640x360 영상).
2. 이상하거나 재미있거나 막힌 순간에 **F8**(패드는 **SELECT + R3 동시**)을 누르면 북마크가 저장되고 화면에 "북마크 저장 #n" 이 잠깐 뜹니다.
   - 가방이 열린 상태에서 패드 SELECT+R3 를 누르면 SELECT(프리셋 넘김)·R3(정렬)도 같이 먹을 수 있습니다. 북마크는 필드에서 누르는 걸 권합니다.
3. **10~15분짜리 2~3판**이면 충분합니다. 사냥만 하지 말고 마을 일(상점 사고팔기, 장비 갈아입기, 스킬 찍기, 퀵슬롯 정리, 퀘스트 받기)도 섞어 주세요.
4. 끝나면 **그냥 플레이 모드를 멈추면** 됩니다. 저장·영상 마무리는 자동입니다.

파일 위치(`Logs/playrec/`, git 에 안 올라감):
- `<시각>.jsonl` 기록, `<시각>.mp4` 영상(30분 약 15~19MB, 로그도 비슷), `<시각>/mark_NN.png` 북마크 원본 스크린샷.
- 요약: `python Tools/playrec_summary.py Logs/playrec/<시각>.jsonl --frames` → `<시각>_summary.md`, `<시각>_frames/`(북마크·막힘·사망 장면).
- 최근 30판만 남기고 오래된 것은 자동 삭제됩니다.

녹화가 신경 쓰이면 알려 주세요(영상만 끄는 스위치 `PlayRecorder.VideoEnabled` 가 있습니다).
