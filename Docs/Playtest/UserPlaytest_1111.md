# 11-11 사용자 플레이 확인 목록 (미검증 항목 모음)

builder·총괄이 probe 로만 확인하고 실제 입력은 못 본 것. 이상하면 항목 번호로 알려 주면 된다.

## 슬롯·장비
- [ ] 장비창: 의상·무기·반지·목걸이·귀걸이 5칸, 잠긴 칸 표시, 툴팁 줄이 프리셋 박스와 겹치지 않는지
- [ ] 구 세이브 로드: 투구·장갑·하의·신발·부적이 새 칸/가방으로 옮겨지고 아이템이 사라지지 않는지
- [ ] 펫 줄: 키보드·패드 조작, 자동 물약(HP/SP 기준)이 실제로 먹는지
- [ ] 장비 효과 툴팁 "특수 효과" 구획·세트 단계 줄, 변형 스킬 실제 시전

## 입력·상호작용
- [ ] 포털·NPC·상점·창고·저장지점이 겹친 곳에서 `↑` 가 가장 가까운 하나만 반응하는지
- [ ] 낙사: 맵 아래로 떨어지면 마지막 발판으로 돌아오는지(피해 없음)
- [ ] 마우스 클릭·휠·드래그(칸끼리 교환·합치기·인벤 밖 버리기), 우클릭 사용/장착/판매, 호버 툴팁
- [ ] 패드: 수량 창, 버리기(RT), 인벤 버튼 기능, 스킬창(LT+Y), 퀘스트 창(LB/RB 탭)
- [ ] 상점: 클릭=상세, 재클릭·우클릭=구매 수량 창, 휠 페이지, X 닫기

## 퀘스트·스킬
- [ ] Q 창 3탭·요구 사항·보상·포기 확인, 추적 HUD(최대 5개·접기 H), 게시판·푯말 입구
- [ ] K 스킬창 4탭, 타입 Lv 토스트, 극의·공용 트리 효과 체감

## 전투·밸런스
- [ ] 미스(MISS) 표시와 레벨 차 체감, 보스 예외
- [ ] 몹 행동(후공 버섯·허수아비 제자리·토끼 점프), 소형 몹 판정 크기
- [ ] 1층 후반·2층 몹 HP 상향 체감(처치 3.5~11초), DeathBringer 700

## 요리·제작
- [ ] 마을 요리대(x=-406) 상호작용, 일괄 요리 수량 창, 가방 부족 시 들어가는 만큼만 지급
- [ ] 대장장이 일괄 제작 수량 창(상한 99)

## 알려진 미구현(고장 아님)
5·7층계 해금 스토리 지점, 수레(마차) 구현, 인벤 이름 검색·확인 창 통일(U40), 요리 레시피 CSV화, 신규 장신구·팔찌 효과, 퀘스트 대사 CSV 이행.

## 11-11 밤 추가 (1층계 주말용)
- [ ] 상점 "잡템 일괄 판매" 버튼 위치·겹침·실마우스 클릭, 확인 창 수락/취소
- [ ] 낮 샛길 쥐 도둑 스폰(Q106), 밤 안내 "밤까지 약 N분"(Q104·Q205) HUD·Q창 표시, 튜토리얼 문구·마차 해금 안내
- [ ] 구역 보고 안내판(깊은 숲·늪·산적 요새·탑 근교) 위치와 ↑ 보고 동작
- [ ] 도감 구역 전종 처치 보상(B08~B13, "전종"은 일반 몹만), 사냥 의뢰 D18~D23, Q610 마도서 보상
- [ ] 문지기 a=1 처치 시 강화석 +2와 입장 알림, 늪 Q410 정령잉어 10%
- [ ] 아이콘 없는 아이템이 임시 그림으로 뜨는지(콘솔 Warning만)
