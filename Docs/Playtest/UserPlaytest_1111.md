# 11-11 사용자 플레이 확인 목록 (미검증 항목 모음)

builder·총괄이 probe 로만 확인하고 실제 입력은 못 본 것. 이상하면 항목 번호로 알려 주면 된다.

## 슬롯·장비
- [ ] 장비창: 의상·무기·반지·목걸이·귀걸이 5칸, 잠긴 칸 표시, 툴팁 줄이 프리셋 박스와 겹치지 않는지
- [ ] 구 세이브 로드: 투구·장갑·하의·신발·부적이 새 칸/가방으로 옮겨지고 아이템이 사라지지 않는지
- [ ] 펫 줄: 키보드·패드 조작, 자동 물약(HP/SP 기준)이 실제로 먹는지
- [ ] 장비 효과 툴팁 "특수 효과" 구획·세트 단계 줄, 변형 스킬 실제 시전

## 입력·상호작용
- [ ] 포털·NPC·상점·창고·저장지점이 겹친 곳에서 `↑` 가 가장 가까운 하나만 반응하는지
- [ ] 낙사: 맵 아래로 떨어지면 마지막 발판으로 돌아오는지(피해 없음)
- [ ] 마우스 클릭·휠·드래그(칸끼리 교환·합치기·인벤 밖 버리기), 우클릭 사용/장착/판매, 호버 툴팁
- [ ] 패드: 수량 창, 버리기(RT), 인벤 버튼 기능, 스킬창(LT+Y), 퀘스트 창(LB/RB 탭)
- [ ] 상점: 클릭=상세, 재클릭·우클릭=구매 수량 창, 휠 페이지, X 닫기

## 퀘스트·스킬
- [ ] Q 창 3탭·요구 사항·보상·포기 확인, 추적 HUD(최대 5개·접기 H), 게시판·푯말 입구
- [ ] K 스킬창 4탭, 타입 Lv 토스트, 극의·공용 트리 효과 체감

## 전투·밸런스
- [ ] 미스(MISS) 표시와 레벨 차 체감, 보스 예외
- [ ] 몹 행동(후공 버섯·허수아비 제자리·토끼 점프), 소형 몹 판정 크기
- [ ] 1층 후반·2층 몹 HP 상향 체감(처치 3.5~11초), DeathBringer 700

## 요리·제작
- [ ] 마을 요리대(x=-406) 상호작용, 일괄 요리 수량 창, 가방 부족 시 들어가는 만큼만 지급
- [ ] 대장장이 일괄 제작 수량 창(상한 99)

## 알려진 미구현(고장 아님)
5·7층계 해금 스토리 지점, 신규 장신구·팔찌 효과, 퀘스트 대사 CSV 이행.

## 11-11 밤 추가 (1층계 주말용)
- [ ] 상점 "잡템 일괄 판매" 버튼 위치·겹침·실마우스 클릭, 확인 창 수락/취소
- [ ] 낮 샛길 쥐 도둑 스폰(Q106), 밤 안내 "밤까지 약 N분"(Q104·Q205) HUD·Q창 표시, 튜토리얼 문구·마차 해금 안내
- [ ] 구역 보고 안내판(깊은 숲·늪·산적 요새·탑 근교) 위치와 ↑ 보고 동작
- [ ] 도감 구역 전종 처치 보상(B08~B13, "전종"은 일반 몹만), 사냥 의뢰 D18~D23, Q610 마도서 보상
- [ ] 문지기 a=1 처치 시 강화석 +2와 입장 알림, 늪 Q410 정령잉어 10%
- [ ] 아이콘 없는 아이템이 임시 그림으로 뜨는지(콘솔 Warning만)
- [ ] 대화창에서 Space 로 대사 넘길 때 점프가 같이 나가지 않는지(26e4f58c6, UiLock("Dialogue") 확인)

## 11-14 입력 경로 확인(가상 입력으로 통과 못 본 것)

- [ ] 실패드(F1 해소 11-14, 가상 패드 통과): 필드 Start=일시정지만, 일시정지 메뉴 "가방"으로 인벤 열기, 인벤·창 열린 중 Start=닫기만 — 실패드 손맛 확인
- [ ] 실마우스: 인벤 칸 좌클릭·우클릭 메뉴·상점 슬롯 클릭·수량창 휠 ±1·가방 확장 확인창 버튼 클릭이 막히지 않는지
- [ ] 패드 손맛: 수량창 길게 누르기 가속, 가방 확장 확인창 ←→ 반응, 상점 구매→판매 전환 때 커서 위치가 직관적인지
- [ ] 창고 넣기·빼기 나누기(Y/C) 슬라이더를 패드로 쓸 때 막히는 곳
- [ ] 패드 인벤 단축(11-14): 필드 SELECT 짧게=인벤 열림, SELECT 길게(0.8초)=퀘스트(인벤 안 열림), R3 짧게=아티팩트 사용, R3 길게(0.5초)=다음 아티팩트, LT+R3=미니맵만, 인벤 중 SELECT=프리셋(닫히지 않음), Start=일시정지·인벤 열린 중 닫기
- [ ] (11-14 REWORK-0 2차) 실마우스: 장비칸 착용품(목걸이·반지·의상) 우클릭·더블클릭으로 바로 해제되는지, 창고·상점 열린 중엔 해제 안 되고 기존 동작인지
- [ ] (11-14 REWORK-0 2차) 맵 양 끝·포털 근처에서 카메라가 배경 밖(빈 화면)을 보이지 않는지, 점프 때 카메라 급상승이 거슬리지 않는지
- [ ] (11-14 REWORK-0 2차) 낙사 복귀(피해 없음) 손맛·벽 끼임 사례가 있는지, 포털 "↑ 목적지" 안내가 패드에서도 알아보기 쉬운지

## 11-14 고유 지형 5장 실입력 확인(통합 확인에서 못 본 것)

- [ ] 산적 성채: 해자(깊은 숲 포털 도착)에서 걸어 안뜰로 나오기, 목책·망루·옥상 사다리 11 오르기, 계단식 해자가 구덩이처럼 답답하지 않은지
- [ ] 깊은 숲 심부: 막다른 맵에서 지형 이동(점프·사다리)이 막히는 곳 없는지, 포털 하나뿐이라 돌아오는 길이 분명한지

- [ ] 안개늪: 물웅덩이(바닥 -182)에서 걸어 나오기·통나무 징검 점프·로프 10 오르기, 윗길 순환로 이동, 늪 감속 체감
- [ ] 일반 숲: 1칸 계단 3줄 걷기·윗발판 점프·사다리 8 오르기, 능선 끝 깊은 숲 포털까지, 히든 포털(능선 끝 <-> 길) 사용
