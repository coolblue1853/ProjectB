# 레이어 분리 연구 보고 (최신 11-10)

## 결과 먼저
1. 외형 슬롯 4칸(머리 · 갑옷 한 벌 · 장갑 · 신발)에서 권장안이 기준선보다 합성 1개당 구멍 0.86 → **0.19**, 속옷 노출 30.2 → **2.7**, 떠 있는 조각 2.5 → **0.5**, 잘림 7.2 → **5.5**. 침범은 3.2 → 3.3으로 **개선 없음**(`metrics.json`).
2. 분류 정확도 mIoU 0.712 → **0.856**(4칸), 장갑 IoU 0.23 → 0.72, 신발 0.54 → 0.73.
3. 머리: 세트별 모자 확장 + 모자 지울 마스크로, 전부 잎사귀를 입혔을 때 머리가 잎사귀 원본과 다른 픽셀 2,106 → **622**.
4. 비용: 고유 프레임 98장. 세트를 키 프레임만 생성(21장 중 7장)하고 나머지를 옮기면 실루엣 IoU 0.917. 세트 1벌 약 75 → **35 gen**(전이 10 gen/15프레임은 PixelLab 문서로 확인).
5. 속옷 몸은 키 프레임만 만들면 구멍이 6배로 늘어서 → 동작당 전부 생성.
6. **못 푼 것:** 프레임 간 경계 깜빡임 2배(98 → 213, 신발·장갑 경계), 침범 개선 없음, 잎사귀 원본의 배낭 자리, 뒷모습 배낭 끔. 전체 목록은 `failures.md`.
7. 런타임 반영: `regions/` 교체 + `export_runtime.py map ... --armor --cap-under under_fixed`. C# 변경은 배낭 `back` 슬롯 1개뿐(배낭 켜고 끄기를 쓸 때).

## 방법(요약 — 자세한 근거는 각 문서)
| 단계 | 내용 | 문서 |
|---|---|---|
| 지도 | M1h = 기준선 규칙 + 속옷 몸(부츠선·살색 손) + 세트 불변(배낭) + 머리 구역 옷 픽셀(들어 올린 팔·손) | `code/m1_underdiff.py --hybrid` |
| 슬롯 | 상의·바지·자락·배낭 → 갑옷 한 벌. 상의↔바지 경계 결함이 사라지고 가려진 바지 문제가 없어짐 | `SLOT_DECISION.md` |
| 머리 | 세트가 머리 구역에서 원본과 다르게 그린 픽셀 중 모자와 이어진 것 = 모자, 그 모자가 가리는 원본 머리카락 = 지울 마스크 | `common.cap_extend` |
| 속옷 몸 | 목·턱에서 원본 머리 덮어쓰기가 빠진 114px(머리 색만)을 원본으로 | `under_fixed/` |
| 배낭 | 기본 코트 전용 별도 레이어, 끄면 몸 안쪽은 생성 0 보완 | `export_runtime.py --split-back` |
| 비용 | 키 프레임 자동 선택 + 옮기기 | `PIPELINE.md`, `code/keyframe_select.py` |

## 평가 정의
- 조합: 세트 2벌(원본 코트 `base_coat`, 잎사귀 `leaf_set`), 21프레임. 4칸은 16조합, 5칸은 32조합.
- 구멍: 두 옷 그림이 모두 불투명한 자리인데 합성 결과가 투명. 배낭 자리(다른 세트가 배낭을 버린 자리)와 모자 지울 마스크 자리는 의도된 투명이라 뺌.
- 속옷 노출: 같은 자리인데 합성 결과가 '원본과 색이 다른 속옷 몸'.
- 떠 있는 조각: 합성 결과에서 가장 큰 덩어리 밖 불투명 픽셀(원본 3세트는 모두 0).
- 침범·잘림: 시험 7장에서 정답 지도로 **같은 규칙**(같은 모자 확장·같은 속옷 몸)으로 합성한 결과와 출처가 다르고 색이 다른 픽셀.
- 정답 라벨 `labels/` 8장은 기준선 지도 위에 손으로 고친 것(`labels/gt_ops.json`) → 기준선 쪽으로 기울어 있음.
