# 레이어 분리 연구 결과 (11-09)

## 결과 먼저
1. **권장 = M1h 지도 + 자락 소속 통일(상의) + 보완 층.** 기준선 대비(21프레임 × 32조합, 시험 7프레임): mIoU **0.686 → 0.792**, 구멍(배낭 제거 자리 제외) **5,856 → 128**, 속옷 몸 노출 **69,872 → 6,272**, 떠 있는 조각 **1,888 → 344**, 침범 2,624 → 2,696(같음), 잘림 4,500 → 3,652.
2. 장갑 IoU **0.23 → 0.68**, 신발 0.54 → 0.73: 속옷 몸에서 얻은 살색 범위·부츠선이 색 규칙보다 정확.
3. 질문 1(라벨 0): 속옷 몸만 쓰는 M1 단독은 0.624로 **기준선보다 나쁨**. 기준선을 출발점으로 두고 확실한 곳만 고치는 M1h가 최선.
4. 질문 2(전파): 키 프레임 1장 전파는 대기(작은 동작)에서만 기준선보다 나음(idle_4 0.83 vs 0.75), 큰 동작은 0.43~0.57로 **붕괴** → 규칙 재계산이 더 안정.
5. 질문 3(자락·소품): 자락 소속을 세트마다 다르게 두는 현 정책이 구멍 5,280개의 원인. **한 소속으로 통일하면 0**. 가려진 바지·상의를 보완 층으로 채우면 노출 −89%.
6. 새 단서: **옷을 바꿔 전이해도 안 변하는 픽셀 = 배낭·랜턴**(세트 불변). 옷 색과 무관하게 소품을 찾는다.
7. 미착용 부위 포함 243조합에서도 추가 구멍 0(속옷 몸 위 덧그리기 구조 덕분).
8. 못 푼 것: 뒷모습 손, 전이가 다시 그린 배낭 잔색, 보완 층이 만든 가짜 무늬, 정답 라벨의 기준선 편향 → `failures.md`.
9. 근본 해결(사용자 지적 "코트 벗기면 바지가 빔")은 생성 단계에서 **바지 → 상의 순서로 한 겹씩 입혀 차이로 뽑기**(아래 5절, PixelLab, 미검증).

## 3. 방법
**M1 / M1h (질문 1)** `code/m1_underdiff.py`
- 옷 픽셀 = 원본 ≠ 속옷 몸. 속옷 몸(옷과 무관한 같은 몸)에서 허리선(반바지 윗선), 부츠선(다리 살 아래 끝), 살색 HSV 범위를 프레임마다 얻는다.
- 손 = 속옷 살색 범위 안 2~20px 덩어리(가죽색 배낭과 닿는 것 제외). 신발 = 부츠선 아래.
- 소품 = **원본과 잎사귀 전이 그림이 ±1px 안에서 같은데 속옷 몸엔 없는 픽셀**(배낭·랜턴은 전이에서 보존됨), 6px 이상·허리 위 비중 ≥ 50% 덩어리 + 그 팔레트로 연결 성장.
- 머리 구역이라도 옷 픽셀이고 세트 불변이 아니면 머리 아님(up_4 들어 올린 소매가 모자로 가던 것 수정).
- M1h = 기준선 지도에서 시작해 위 신호로 장갑·신발·배낭·머리 구역만 고치고, 상의/자락/바지 경계는 기준선 유지. 마지막에 대각선 외딴 픽셀 채움(기준선은 10px을 라벨 0으로 남겨 구멍 발생 — 버그).
- 추가 입력: `frames_underwear_base`(같은 자세 속옷 몸), `frames_leaf_set_transfer`(같은 자세 다른 옷 1벌; 소품 판정). 다른 옷이 없으면 `--no-leaf`(소품은 실루엣 밖 위치로만, 정확도 낮음).

**M2 (질문 2)** `code/m2_propagate.py` — 5×5 패치 블록 매칭(±12px, 거리 벌점)으로 키 라벨을 가져오고 3×3 최빈값. 클립 안 연쇄 / 키에서 직접 두 가지. 추가 입력: 손 라벨 1장.

**M3 (질문 3, '코트 벗기면 바지가 빔')** `code/m3_amodal.py` — 지도는 그대로, 세트·부위마다 **보완 층**을 하나 더 둔다. 그 부위 레이어 바로 밑에 깔리고, 속옷 몸의 다리(허리선~부츠선)/몸통·팔 중 자기 레이어가 없는 곳(자락·배낭에 가려진 곳)만 채운다. 채우기 = 같은 레이어에서 빈 곳을 가장 많이 덮는 한 오프셋으로 통째 복사(줄무늬 번짐 대신 무늬 유지). 생성 0. 결과 PNG: `layers_fill/<세트>/<부위>_fill/<프레임>.png`.
- 자락(8)의 소속은 **세트 정책 하나로 통일**한다. 상의(코트 = 한 벌, 바지는 따로)를 권장: 상의 통일은 침범 2,696 / 잘림 3,652, 바지 통일은 3,208 / 4,652. 상의 통일이면 "코트 따로, 바지 따로"가 되고 코트 밑 레깅스는 보완 층이 채운다.

## 5. PixelLab으로 '바지 따로·코트 따로'를 만드는 제안 (미검증, 생성 비용 추정)
보완 층(M3)은 그럴듯하게 꾸며 넣는 것일 뿐, 가려진 진짜 그림이 아니다(up_4 뒷모습 몸통 전체가 지어낸 무늬). 근본 해결은 **생성 단계에서 한 겹씩 입히기**:
1. 속옷 몸(있음) → `transfer_outfit`으로 **바지·신발만** 입힌 21프레임(A) → A 위에 **상의만** 입힌 21프레임(B) → B 위에 모자·장갑(C).
2. 레이어 = 연속 단계의 픽셀 차이(A−속옷 = 바지·신발, B−A = 상의, C−B = 모자·장갑). 각 레이어는 앞 단계에서 이미 끝까지 그려져 있어 **가려진 부분이 비지 않는다**. 지도는 "어느 단계에서 생겼나"로 자동 결정(색 규칙 불필요, 치마·원피스·갑옷 무관).
3. 배낭·랜턴은 전 단계에서 빼고(프롬프트 "no backpack") 별도 소품 층으로 한 번만 만든다 → 잎사귀처럼 배낭을 버리는 세트의 배낭 밑 구멍(현재 구멍의 대부분)이 원천적으로 사라진다.
4. 비용: 단계당 15+6프레임 = 전이 2회 ≈ 20 gen, 3단계 ≈ 60 gen/세트(지금 한 번에 입히기 ≈ 25). 2배 이상. 대신 지도·보정 파일이 필요 없어진다.
5. 위험: 단계마다 전이가 아래 단계를 다시 그려 1px씩 밀림(이번에 잎사귀가 배낭을 1px 밀어 그린 것과 같은 현상) → 차이 추출 때 ±1px 허용 비교(`m1_underdiff.near_diff`) 필요. 검증은 이 패키지의 `evaluate.py` 지표(구멍·노출·조각)로 바로 가능.

### 지표 정의 추가
- 부자연 끊김: 다른 세트(또는 속옷 몸)에서 온 이웃 두 픽셀의 밝기 차 > 60, 둘 다 외곽선이 아니고, **원본 코트·잎사귀·속옷 몸 어느 그림에서도 그 자리가 이미 강한 경계가 아니었던 것**(손↔소매 같은 원래 경계는 뺌).
- 외곽선 통일: 그런 끊김에서 위에 그려진 부위 쪽 1px을 주변 같은 출처 픽셀 중 가장 어두운 색 × 0.8로.
- 깜빡임: 연속 프레임을 전역 이동(±6px)으로 맞춘 뒤, 같은 색(차 ≤ 20)인데 라벨이 다른 픽셀.
