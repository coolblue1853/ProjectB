# 모션 판정 기록 (Claude 판정 vs 사용자 판정)

기준·절차는 `.claude-rules/Game/MotionTheory.md` §5. 사용자에게는 점수 없이 GIF 만 먼저 보내고, 사용자가 합격/불합격을 답하면 아래 표를 채운다.
점수 항목: ①한 몸 ②호·체중(둘 필수) ③크기 일정 ④하체 연속 ⑤얼굴·소품 ⑥방향 순서 ⑦레퍼런스 일치 ⑧실루엣. 합격 = 7점 이상 + ①② 통과.
