# 그래픽 의뢰 목록 (11-13, 그래픽 방에 맡길 것)

개발 쪽은 그래픽을 만들지 않고 임시 그림으로 두었다. 아래는 사용자 검토 후 교체할 목록이다. 우선순위는 1층계 주말 플레이에서 눈에 띄는 순서.

## 높음 (주말 플레이에 바로 보임)
- 쥐 도둑·쥐 두목 전용 스프라이트: 낮 샛길에서 토끼 그림에 정예 표식으로 나와 Q106 목표를 알아보기 어렵다(Q-EH4).
- 구역 인장 3종 아이콘(`Item/ZoneSeal_Swamp·Fortress·Tower`): 파일 없음, 임시 그림 폴백 + 콘솔 Warning.
- `ChiefsLastStandRing` 아이콘: Q504 보상, 파일 없음.
- 신규 몹 6종 전용 스프라이트: 지금은 기존 프리팹 틴트 재사용(§8).
- 미니보스 5종 연출: 금색 외곽선·확대 임시. 보스급 인상 판단 필요.

## 중간
- 신규 맵 2장(`Lv1_DeepForestCore`·`Lv1_MistSwamp`) 타일·안개: 기존 타일 색조 + 흰 안개 스프라이트 임시.
- 신규 무기 3종 아이콘(석궁·투창·마도서, 행 313~315)과 신규 제작 방어구 30점 아이콘.
- 밤 몹 추가: 일반 숲·깊은 숲·늪 밤 종류가 각 2종뿐. 새 스프라이트 필요(데이터는 개발 쪽이 붙임).
- 몹 화살 `Assets/Resources/FX/MobArrow.prefab`: 산적 화살 복제 임시.

## 확인 요청
- 커밋 `38ba36c6f`(SampleScene)에 섞인 주인공 리그 변경(Adventurer·CelFist·LeftWeapon·Shoulder/Leg/Hand 등)이 그래픽 방 작업인지, 3타 외형에 영향이 없는지 확인. 이 커밋은 되돌리지 말 것(맵 2장 소실).
- 의상 하나로 합쳐진 장비의 외형 그래픽(구 5부위 레이어 → 의상 1개)은 그래픽 방 계획대로.

## 규칙
- 그래픽은 사용자 검토 후 적용(`graphics-user-review`). 개발 쪽은 파일 경로·이름 규칙만 맞추면 코드 수정 없이 교체되게 해 두었다(`ItemIconLoader` 폴백 등).
