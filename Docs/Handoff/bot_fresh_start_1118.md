# 봇 무인 플레이테스트 재정비 (11-18 시작용)

11-17 밤 사용자 지적: Lv1 봇이 후반 무기를 들고 토끼를 잡고 있었다. 확인해 보니 맞는 지적이었고, 이 문서는 내일 바로 이어서 할 수 있게 정리한 것이다.

## 1. 무엇이 잘못됐나
- `bot_run.sh` 의 `PREP_LEVEL="1 300"` 은 **레벨·골드만** 바꾸고, 사용자 세이브의 장비·가방·숙련도·스킬 투자는 그대로 둔다.
- 근거: `Logs/playrec_bot/20261117_201536.jsonl` meta(t=21) 에서 `lv:1, gold:300` 인데 `eq` 에 `PhantomScythe·FaeArmor·FaeLegArmor·WispHandArmor` 가 들어 있었다.
- 사람 11-15 기록은 새 게임(기본 무기만) 기준이다. 봇은 사람과 같은 조건이 아니었다.

## 2. 무효가 된 결과
아래 실행들은 장비를 초기화하지 않고 돌렸으므로 **레벨·EXP·처치/분·사망·곡선 비교 수치는 무효**다(막힘 위치·예외 0·UI 복구 같은 동작 확인은 참고만 한다).
- 90분 `20261117_183334`(Lv1→9, 처치 948), 90분 `20261117_201536`(Lv1→10, 처치 1260, 곡선 0.88배), 30분 `20261117_173003` 등 11-16~17 의 `PREP_LEVEL` 실행 전부.
- `Docs/Balance/BotBalance_1116.md` 의 봇 기준 몹 수치, 그리고 그것으로 정한 튜닝 8번(MonsterSheet.csv, fe7f63429)의 근거도 다시 봐야 한다. 낮은 레벨에 좋은 장비라 받은 피해가 실제보다 작게 나왔을 수 있다(수치는 되돌리지 않고 재측정 후 판단).
- 스킬 쿨타임 15분 검증(b2857edd5 "처치 10.4/분·사망 0")도 같은 조건이라 수치는 참고만 한다.

## 3. 내일 할 일 (순서대로, builder 1개씩)
1. **진짜 새 게임 시작:** 세이브 파일을 백업한 뒤 세이브 폴더를 비우고 플레이에 들어가 게임 자신의 새 게임 경로(`SaveManager.DataLoad` hadSaveFile=false → `InventoryManager.EnsureDefaultWeapon`)로 시작한다. 값을 손으로 맞추는 방식(`PREP_LEVEL`)은 쓰지 않는다. `bot_run.sh` 에 `PREP_FRESH=1` 로 넣고, 끝나면 원래 세이브를 되돌리고 md5 를 확인한다.
2. **시작 조건 자동 검사:** 보고서 '메타' 줄에 시작 장비·가방·레벨·골드를 쓰고, `PREP_FRESH` 인데 장비가 기본 무기 1개가 아니면 보고서 맨 위에 **경고**를 띄운다. 사람 기록의 시작 조건도 같은 줄에 나란히 적는다.
3. **기준선 다시 측정:** `PREP_FRESH=1 bash Tools/bot_run.sh 60` 으로 곡선을 사람과 다시 비교한다(합격 0.5~2배). 사람 기록이 새 게임 시작이었는지 meta 로 먼저 확인한다.
4. 그다음 원래 B5 순서(DeepForest 사망·파괴물 오인 → 이상 탐지 보고 → UI 기능 순회)로 돌아간다.
