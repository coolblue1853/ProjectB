아래 실행들은 장비를 초기화하지 않고 돌렸으므로 **레벨·EXP·처치/분·사망·곡선 비교 수치는 무효**다(막힘 위치·예외 0·UI 복구 같은 동작 확인은 참고만 한다).

## 3. 내일 할 일 (순서대로, builder 1개씩)
1. **진짜 새 게임 시작:** 세이브 파일을 백업한 뒤 세이브 폴더를 비우고 플레이에 들어가 게임 자신의 새 게임 경로(`SaveManager.DataLoad` hadSaveFile=false → `InventoryManager.EnsureDefaultWeapon`)로 시작한다. 값을 손으로 맞추는 방식(`PREP_LEVEL`)은 쓰지 않는다. `bot_run.sh` 에 `PREP_FRESH=1` 로 넣고, 끝나면 원래 세이브를 되돌리고 md5 를 확인한다.
2. **시작 조건 자동 검사:** 보고서 '메타' 줄에 시작 장비·가방·레벨·골드를 쓰고, `PREP_FRESH` 인데 장비가 기본 무기 1개가 아니면 보고서 맨 위에 **경고**를 띄운다. 사람 기록의 시작 조건도 같은 줄에 나란히 적는다.
3. **기준선 다시 측정:** `PREP_FRESH=1 bash Tools/bot_run.sh 60` 으로 곡선을 사람과 다시 비교한다(합격 0.5~2배). 사람 기록이 새 게임 시작이었는지 meta 로 먼저 확인한다.
   - 정적 리뷰(`Docs/Playtest/ReviewCode_1117.md`)가 찾은 시작 조건 누락도 1~2단계에서 같이 막는다: 스킬 투자 잔존(R2, 포인트=레벨 함수라 Available 음수), 완료 퀘스트 잔존(R6), 시간대 미지정(R5), 맵 준비 20회 실패해도 경고 없이 진행(R3, `bot_run.sh:36-41`).
   - R1(시트에 없는 몹을 봇이 Prop 으로 오인할 가능성, `PlayObsEnemies.cs:150`)은 봇 기록 덤프로 먼저 확인한다.
4. 그다음 원래 B5 순서(DeepForest 사망·파괴물 오인 → 이상 탐지 보고 → UI 기능 순회)로 돌아간다.
