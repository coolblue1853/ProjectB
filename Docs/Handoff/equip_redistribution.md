# 장비 슬롯 재분배 표 (11-10 밤 · 총괄 초안, 사용자 검토 대기)

근거: `Docs/Handoff/outfit_one_piece_decision.md`, 사용자 확정 해금표(`Game/EquipSlotExpansion.md` 머리말). 모션 소유 원칙(의상=기본 동작, 무기=공격 동작)과 충돌 없음 — 이 문서는 외형·스탯·효과 배치만 다룬다.

## 1. 새 슬롯과 해금 (최종)

| 해금 | 종류 | 내용 |
|---|---|---|
| 시작 | 장비 5칸 | 의상(몸 전체·기본 동작) · 무기(공격 동작) · 반지 · 목걸이 · 귀걸이 |
| 1층계 | 장비 슬롯 | 보조장비(옛 부적: 물약 쿨다운·사망 EXP 손실 완화 등) |
| 2층계 | 별도 콘텐츠 | 펫(장비 아님, 편의 기능) |
| 3층계 | 장비 슬롯 | 팔찌 |
| 4층계 | 별도 콘텐츠 | 룬(특정 스킬 강화, 내용 미정) |
| 5층계 | 장비 슬롯 | 허리띠 |
| 6층계 | 별도 콘텐츠 | 성물(오래 지속되는 지속형 버프 스킬, 내용 미정) |
| 7층계 | 장비 슬롯 | 마법석 |

- 홀수 층계는 장비 슬롯, 짝수 층계는 별도 콘텐츠. 해금 조건은 스토리 진행.
- 세트 효과에 들어가는 것은 장비 슬롯(시작 5칸 + 홀수 층계 보조장비·팔찌·허리띠·마법석)뿐. 짝수 층계(펫·룬·성물)는 장비가 아닌 별도 콘텐츠라 세트에 안 들어간다. 지금은 시작 5칸 기준 최대 5셋으로 만들고, 해금 슬롯의 세트 포함·6셋 이상 확장은 나중에 설계(기획 필요).
- 룬·성물은 이 작업 범위 밖(자리만 확보, 내용은 사용자가 정하면 설계). 펫은 큐 REWORK-9 와 연결.
- 옛 신발 효과는 3층계 팔찌·5층계 허리띠 아이템으로 나눌 수 있으나 1층계엔 없으므로, 1층계 몫은 반지·목걸이·귀걸이·보조장비로 나눈다.

## 2. 기존 부위 → 새 슬롯 (제안)

현재 방어구 세트는 투구·상의·장갑·하의·신발 5부위(+무기 1 = 6셋 단계). 14세트 × 5부위 = 약 70개 아이템과 `SetItem.csv`의 2/4/6셋 효과.

| 옛 부위 | 새 슬롯 | 이행 방법 |
|---|---|---|
| 상의 (Chest) | **의상** | 외형=옷 한 벌. 스탯·효과 그대로 |
| 무기 | 무기 | 변경 없음 |
| 장갑 (Hand) | **반지** | 같은 세트의 세트 반지로 전환. 스탯 그대로 |
| 하의 (Leg) | **목걸이** | 같은 세트의 세트 목걸이로 전환. 스탯 그대로 |
| 투구 (Head) | **귀걸이** | 같은 세트의 세트 귀걸이로 전환. 스탯 그대로 |
| 신발 (Shoes) | **분배** | 의상과 팔찌 풀 쪽으로 나눈다(아래 질문 1). 세트 칸은 아님 |

- 효과를 의상 한 곳에 합치지 않는다. 세트 효과(`SetItem.csv`)만 단계표를 바꾼다.
- 기존 일반 반지 8·목걸이 9·귀걸이 2·팔찌 2·부적 1·마법석 1은 세트 없는 단독 아이템으로 유지(Charm→보조장비 이름 전환).

## 3. 세트 효과 단계 (제안)

옛 6칸 → 새 5칸. 숫자를 가능한 한 보존한다.

| 옛 | 새 |
|---|---|
| `_2` | 2셋 (효과·수치 그대로) |
| `_4` | 4셋 (그대로) |
| `_6` | 5셋 (그대로 — 최종 단계) |

- 2셋·4셋·5셋은 기본값이고 세트마다 3·5 등으로 바꿀 수 있다(사용자 허용).
- RabbitArmor/LeafArmor/RatArmor/ScareArmor 의 `_2`·`_5` 2단계 세트는 2셋·5셋 그대로.
- 이펙트 단계: 2셋 약한 형태 → 5셋 강한 형태(등 뒤 선조 예시). 절차 생성이라 훅(`SetBonusEvaluator` 단계 이벤트)만 둔다.

## 4. 구현 순서

1. 슬롯 구조·해금 코드(`EquipSlot`·`SlotRules`·해금표) — 해금표만 확정되면 바로.
2. `ItemSheet.equipArea` 전환(장갑→Ring, 하의→Necklace, 투구→Earring, 신발은 질문 1 결정) + `SetItem.csv` 단계 정리 + `CelEquipMap`.
3. `CelEquipSync` 정리: 모자·장갑·신발 합성 끄기, `*_glove/*_shoes` 기본 규칙과 `CelComposer.AlignBoots` 삭제.
4. 장비창 UI(5칸+잠금 칸 표시·해금 연출, 마우스·키보드·패드).
5. 세이브 이행(ES3 추가만): 장착 중인 옛 투구·장갑·하의·신발은 새 칸 전환 또는 인벤토리 반환.

## 5. 사용자 결정 반영 (11-10 밤)

- 부적은 **보조장비** 슬롯(1층계 스토리 해금)으로 이름만 바꿔 유지. 반지는 한 칸. 발찌·문장 추천은 철회(사용자 최종표로 대체).
- 해금 조건은 스토리 진행. 무기도 세트 칸 가능. 세트 배분은 총괄이 기존 효과 기준으로 정한다.
- 1층계는 5칸뿐. 신발은 적당히 나눠서 다른 슬롯 아이템(반지·목걸이·귀걸이 스탯·효과)에 얹는다(위 표 (나) 변형: 아이템 삭제, 효과는 보존).
- 1층계 세트 단계는 2·4셋과 3·5셋. 옛 2·4·6셋은 없애거나 합치고 수치 조정.
- 아이콘은 나중.
- 기획 결정 목록은 `Docs/OpenQuestions.md`의 EQUIP-SLOT-REFORM v2 절.
