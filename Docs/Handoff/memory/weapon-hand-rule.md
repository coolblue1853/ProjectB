사용자(2026-10-27): "양손 무기가 아니라면 내가 봤을 때 오른손이 주 무기 손, 왼손이 부 무기 손. 손이 옮겨 다니면 안 된다."

**Why:** 기본 칼 내려베기 준비 키에서 생성기가 칼을 뒤쪽 팔로 들어 올려, 게임에서 칼이 왼팔·오른팔을 오갔다.
**How to apply:** 공격 키 생성 프롬프트에 "칼은 앞쪽(화면 오른쪽) 손에 그대로" 를 넣고, 셀 빌드 뒤 손 좌표·합성 시트로 손 전환이 없는지 확인한다. 규칙 원문은 MotionSet §7.3. [[motion-batch-review]]
