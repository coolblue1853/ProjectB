사용자 정의(2026-10-25) Project B의 형태:
- **장르·화면:** 2D 횡스크롤.
- **전투 감각:** 메이플스토리 또는 던전앤파이터 느낌.
- **파밍·무기 스킬:** 디아블로식.
- **장비 생성·기반 시스템:** 몬스터헌터 + 디아블로. 몬스터를 잡아 그 몬스터가 쓰는 계열의 무기를 직접 제작하거나 드롭으로 얻는다([[monster-lineage-gear]]).

**Why:** 기획·아트 판단(캐릭터 컨셉, 세트 디자인, 스킬)을 이 축에 맞추라는 사용자 요청("이것도 기억해 두렴").
**How to apply:** 캐릭터·장비 컨셉은 RPG 세트 효과형 직업 콘셉트(버서커, 역병 의사, 권총 사수, 저격수 등 멋있는 디자인)로 잡고, 무기는 몬스터 계보와 연결한다. 전투 연출은 메이플/던파 타격감 기준.
