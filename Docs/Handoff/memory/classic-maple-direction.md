진행·구조 = 클래식 메이플(메이플랜드 초반 1.0~2.0): 레벨·EXP, 퀘스트, 사냥 위주, 너무 윗지역은 죽음, 몸박 피해, 물약 많이 들고 다님. 다른 요소(파밍·세트·제작·미니게임)는 디아·던파·몬헌 그대로. 스킬은 캐릭터 성장 아님 — 장비에 붙음, 스킬 트리 없음(후일 특정 무기 숙련 정도). 조작은 1층계 클래식 감 → 최종 층계 현대 메이플 유연함.

**Why:** 사용자가 원하는 레벨링 감성이 클래식 메이플. 이전 임시 가정 "레벨 미도입"(Q-103)을 뒤집음.

**How to apply:** 설계·수치는 `.claude-rules/Game/ClassicMapleDesign.md`. 전투력 70~80%는 장비, 레벨 성장은 소량. 조사·수치표는 GPT(Chrome)로 — 사용자 재강조(10-31). 관련 [[game-pillars]], [[budget-priority]].
