프로젝트에 필요한 에셋·폰트·도구 다운로드(예: GitHub 릴리스의 OFL 폰트, 보유 Asset Store 패키지)는 묻지 않고 진행한다.

**Why:** 2026-10-19 Galmuri 폰트 다운로드 허락을 물었더니 사용자가 "그런건 안 물어봐도 된단다"라고 함. Asset Store 다운로드도 2026-10-18에 이미 허락(AssetIntegrationPlan 마지막 절).

**How to apply:** 출처가 공식 저장소·릴리스인지, 라이선스(OFL·MIT 등)가 상업 사용 가능한지 확인하고, 받은 파일은 새 빈 폴더에 두고 라이선스 파일을 함께 커밋한다. 실행 파일 실행이나 출처 불명 파일은 여전히 조심한다. 관련: [[no-stopping]]
