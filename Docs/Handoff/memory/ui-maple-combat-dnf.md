전투 감각은 던파에서 많이 가져온다(무기에 스킬이 달린 구조는 그대로). 인벤토리·상점·창고 같은 시스템은 메이플에서 따온다. 기능을 최대한 많이 넣고, UI 그림은 임시여도 된다. 기존 UI 도 기능적으로 고칠 게 있으면 고친다.

**Why:** 11-01 플레이테스트 뒤 "바꿔야 할 게 많다", 편의 기능 부족 체감.
**How to apply:** 지시 없이 Codex 큐로 기능 추가 계속(Claude 주간 10% 상한, [[usage-budget]]). 그래픽 확정은 여전히 사용자 검토([[graphics-user-review]]).

11-02 추가: **1층계 플레이를 최대한 고도화**(미니맵·포털 이동 등 다듬을 수 있는 건 전부). 보스 애니·플레이어 무기 동작은 나중. 더미 이미지 허용, 콘텐츠는 임의로 넣어 두면 사용자가 넣을 것/뺄 것을 고른다(새 콘텐츠는 목록 문서로 남길 것).

11-02 중요: 우리는 **완전 횡스크롤(메이플 뷰, 깊이축 없음)**. 던파 요소는 골라서만 — 전투는 '메이플 + 던파 적당히'. 깊이축(Z 이동·라인 회피)·과한 띄우기 콤보·잡기 같은 벨트스크롤 전제는 넣지 않는다. 캔슬·경직 감쇠·쿨다운 HUD 처럼 횡스크롤에서도 통하는 것만.
