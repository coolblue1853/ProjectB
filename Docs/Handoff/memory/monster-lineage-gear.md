Weapons and set effects mostly mirror the monster you killed (e.g. scarecrow → staff that summons scarecrows). Set bonuses even more so. Unique/legendary tiers add distinctive non-lineage weapons. Every new monster should come with a lineage weapon + set (checklist in `.claude-rules/Game/TowerWorld.md` §12).
