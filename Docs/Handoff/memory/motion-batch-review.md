사용자(2026-10-27): "그냥 한 번에 하자. 대신 성공 기준을 아주 높게 잡아. 모션이랑 이펙트는 분리해야 같은 모션에 다른 이펙트를 돌려 쓴다."

**Why:** 한 장씩 판단을 떠넘기는 진행에 크게 화냄("하나하나 내가 판단하게 해줘야 한다는 게 레전드"). 점검 안 된 초안을 보여 준 게 원인.
**How to apply:** 모션마다 스컬 설계표 → 우리 키 자세 → 사이 프레임 → 자체 점검(MotionSet §7 기준) → 게임 적용까지 혼자 끝내고, 전체를 마지막에 한 번 보여준다. 모션 셀에 이펙트(스미어)를 그려 넣지 않는다 — 이펙트는 별도 레이어로 나중에. [[one-motion-review]] 를 대체한다. [[skul-asset-library]]
