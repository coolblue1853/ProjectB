**Why:** 10-28 "앞으로는 내가 말하지 않아도 가져올 수 있는 건 스컬 + 림버스 기반으로 가져와 외형적인 부분들은". 림버스 문법으로 만든 스미어 v7이 "100배 나아짐" 평을 받았다.
