사용량을 아껴야 하는 순서: **PixelLab > Claude > GPT**. GPT(ChatGPT, 사용자 크롬에 로그인)는 100% 다 써도 된다. 잡일·자료 정리(이미지 분류, 표 만들기, 대량 요약 등)는 GPT가 나으면 GPT에 맡긴다.

**Why:** 10-29 "잡일 필요한 거고 너보다 나을 거 같으면 gpt 써서 자료 정리하거나 해도 상관없어 gpt 쪽 사용량은 100퍼 다 써도 상관없거든".
**How to apply:** 대량 이미지 분류·문서 초안 같은 반복 작업은 Claude in Chrome 으로 chatgpt.com 에 파일 올려 맡기고 결과 텍스트만 읽는다. PixelLab 생성은 최후 수단. [[usage-budget]] [[use-chrome-for-web]]
- 10-30 사용자: "Claude 사용량 아낄 수 있으면 GPT Plus 많이 써라(품질 차이 없으면)" — 기획서·수치·리서치·채점·초안 코드는 GPT(크롬 탭)로 만들고, Claude 는 Unity 통합·검증·커밋만.
