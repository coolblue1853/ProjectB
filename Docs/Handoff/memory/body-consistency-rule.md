사용자(2026-10-27): "손 모양은 바뀔 수 있어도 비슷한 자세일 때 크기가 바뀌면 안 된다. 다른 신체 부위도 같다 — 같은 형태가 움직이는 것이다. 머리가 막 흔들리는 것도 아직 있다."
1. 신체 부위가 이상하게 잘리거나 커지거나 작아지면 안 된다.
2. 칼을 든 손의 위치가 이상하게 바뀌면 안 된다.
3. 투구는 제거하고 기본 복장으로 작업한다.
4. 머리카락이 너무 이상해지면 안 된다.
5. (10-27 추가) 다리를 벌리는 건 맞지만 원래 다리 길이보다 늘어나면 안 된다 — "신체 부위가 원래보다 길어지거나 커지면 안 된다. 같은 개체의 인간이니까."

**Why:** 생성 초안마다 주먹·머리카락 크기가 달라 게임에서 손이 커졌다 작아지고 머리가 출렁였다.
**How to apply:** 공격 셀마다 머리 폭·머리카락 덩어리·주먹 픽셀 수를 대기와 비교하는 자동 검사를 돌리고(±5%), 손은 칼 직선이 아니라 주먹 중심을 수동 키로 정한다. PixelLab 은 코드·GPT 로 안 될 때만. [[weapon-hand-rule]] [[pixellab-budget]] [[motion-batch-review]]
