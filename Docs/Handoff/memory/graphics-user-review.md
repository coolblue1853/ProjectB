그래픽류(스프라이트·아이콘·도트·이펙트 외형)는 사용자 검토를 받아야 한다. 혼자 만들어 적용·커밋하지 말고, 시안은 미리보기로 보여주고 판정을 기다린다.

**Why:** 사용자 10-31 "이런 그래픽류는 나한테 검토 맡아야해서" — Codex 한도 대기 중 Claude 가 골드 더미 그림을 직접 다듬자 중단시킴.

**How to apply:** 대기 시간 채우기용으로 그래픽 작업을 고르지 않는다. 시안은 `Logs/` 패치·미리보기 PNG 로만 두고 보고. 관련 [[art-ref-criteria]], [[codex-delegation]].
