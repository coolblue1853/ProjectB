브라우저에서 유튜브 영상을 함부로 재생하지 않는다. 광고까지 소리가 나서 사용자가 불편했다(이전에도 말했음). 꼭 영상 프레임이 필요하면 먼저 사용자에게 묻고, 열 때는 페이지 로드 직후 탭/모든 media 요소 음소거(`muted=true`, 볼륨 0)를 하고 광고가 재생되지 않게 한다.

**Why:** 10-27 엘든링 레퍼런스 찾다가 유튜브를 열어 광고 소리가 났다 — "멋대로 유튜브 틀지 말라고, 틀 거면 소리 꺼".
**How to apply:** 영상 레퍼런스는 정지 이미지·GIF·연속 사진(위키미디어 등)을 먼저 쓰고, 영상이 필요하면 사용자 확인 + 음소거 후에만. [[skul-reference]]
