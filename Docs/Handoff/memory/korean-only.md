Write every user-facing message in Korean — progress notes, status lines and summaries included, not just final answers.

**Why:** On 2026-10-18 the user complained that mid-task updates came out in English ("중간중간 영어로 말하는데 한글로 말해").

**How to apply:** Even when the thinking or code is in English, user-visible text must be Korean. Related: [[no-focus-steal]].
