# 작업: 1층계 장비 HP·방어 기준 정리(Q-F1H) + 보스·정예 피해 재확인

Docs/OpenQuestions.md Q-F1H, Docs/Playtest/Floor1Balance.md §7-1·7-2 를 읽는다. 문제: 늑대 세트만 껴도 HP 124→434(장비 +260·세트 +50)라 성장 HP 를 압도하고, 보스 피해는 맨몸 기준이라 장비를 끼면 너무 약해진다. 사용량 절약: grep 위주.
1. 1층계 방어구(구역별 계보 세트 Wolf·Bear/Ent·Bog·Outlaw/IronRaider·Stoneborn 등)의 HP·방어 수치를 표로 뽑는다(프리팹 hp 값·ItemSheet·SetItem.csv).
2. 메이플식 기준: 해당 구역 권장 장비 풀세트의 HP 합 = 그 레벨 성장 HP 의 40~70% 정도, 세트 보너스 HP 는 그 절반 이하. 상위 구역 장비가 하위보다 높게 계단식. 강화 +로 오르는 몫도 고려.
3. 수치 조정(데이터만, 프리팹 hp 값·SetItem.csv). 기존 세이브 장비는 프리팹 값을 읽으므로 자동 반영되는지 확인.
4. 권장 레벨 + 권장 장비 HP 기준으로 보스 1회 피해 10~25%, 정예 8~15%, 일반 몸박 5~10%(상승 부하 ×1.4 포함)가 되는지 계산표, 벗어나면 보스·정예 피해 재조정. 엔트 1회 실측.
5. 결과 Floor1Balance.md §8, ItemSpec 표 갱신, Q-F1H 에 결정 기록.
EditMode 전체 통과(기대값 바뀌는 테스트는 갱신).
