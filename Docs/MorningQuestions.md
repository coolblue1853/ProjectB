## 가. 어제 가정 확인 (아니면 알려 달라)
1. **"수호자류 메시지" 해석** — 마을에서 나갈 때 뜨던 메시지를 "구역 진입 시 수호자(정예/미니보스/보스) 이름 + 목표 한 줄"로 바꿨다고 가정했다.
   - A 맞다(추천) / B 아니다: 정확히 어떤 문구가 어느 때 뜨는지 알려 달라.
2. **문지기 강화 공식** — 졸업 시험 달성도(인장 40% + 세트 30% + 도감 30%)가 낮을수록 문지기 HP가 최대 ×1.5, 피해가 ×1.2까지 늘어난다. 실측 전이라 임시값이다.
   - A 이대로 실측 후 조정(추천) / B 더 세게(×2.0) / C 더 약하게(×1.25)
3. **세트 제작 골드** — 5부위 합 1,300(Wolf·Wisp)~2,500(Outlaw·Raider)골드. 그 구역 시간당 소득의 약 15%다.
   - A 유지(추천) / B 더 비싸게 / C 더 싸게
4. **신규 맵 2장의 위치** — 깊은 숲 심부와 안개 늪을 기존 깊은 숲·늪에 포털로 붙였고, 보스는 기존 맵에 그대로 있다. 폭과 층수는 초안이다. 직접 가 보시고 크기·모양이 괜찮은지 봐 주세요.
5. **SampleScene.unity 커밋 시점** — 신규 맵 2장은 디스크의 이 씬에 이미 들어 있지만, 이 파일이 사용자 미커밋 변경과 섞여 있어 커밋만 안 됐다. 백업 프리팹은 `Assets/Backup/Floor1Maps/`에 있다.
   - A 지금 커밋(그 변경들 포함, 원하시면 변경 목록을 먼저 요약해 드림) / B 사용자가 변경 정리한 뒤 커밋(추천) / C 씬 분리 시도(포털 참조가 깨질 수 있어 비권장)

## 나. 어제 발견된 문제 — 방향 선택이 필요
6. **깊은 숲 포털 도착 지점이 위험하다** — 일반 숲에서 깊은 숲으로 넘어가면 도착 위치(-236, -0.7)가 엔트와 곰 무리 2~6칸 이내다. 2초 안에 HP 16~50을 잃는다. (어제 "마을에서 나오자마자 엔트에게 죽음"은 봇 순간이동 탓이었지만, 이 도착 지점은 실제 문제다.)
   - A 도착 지점을 몹에서 떨어진 곳으로 옮기고 입구 근처 몹을 줄임(추천)
   - B 진입 직후 3~5초 무적을 줌(몹은 그대로)
   - C 둘 다(가장 안전)
7. **통주 2시간 판정이 불확정** — 봇이 고대 엔트(Q301)에서 막혀 완주하지 못했다. 75분 동안 처치 953, 사망 19. 무적(`god=1`) 실행은 수치 오염이라 판정에서 뺐다. 봇 보강이 필요하다.
   - A 내일 봇의 보스 대응을 보강해 재측정(추천) / B 봇 말고 사용자께서 직접 한 번 통주해서 시간 알려 주기(주말 가능하면)

## 다. 기획 추가 제안 (필요하면 고르세요, 여러 개 가능)
