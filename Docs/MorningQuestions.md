## 가. 어제 임시 가정 확인 (틀렸으면 고치겠다)

**1. "수호자류 메시지"를 어떻게 이해했는지**
- 상황: 사용자께서 "마을에서 나갈 때마다 수호자 어쩌고 하는 메시지가 뜬다, 암전도 없이 순간이동해서 어색하다"고 하셨다. 퀘스트 이름 "첫 번째 문의 수호자"(Q604)가 있어서 그 문구일 수도 있고, 구역 입장 배너일 수도 있다. 지금은 **구역 진입 시 "수호자(정예/미니보스/보스) 이름 + 목표 한 줄" 배너로 해석**했다.
- A 맞다(추천): 그 배너로 가고 마을 출입 때는 띄우지 않는다.
- B 아니다: 정확히 어느 화면에서 어떤 문구가 뜨는지 알려 달라(스크린샷이면 가장 좋다).
- 참고: 포털 이동 때 **암전 페이드 + 카메라 스냅** 문제는 별도 큐 항목("포털 전환 점검")으로 진행 예정이다.

**2. 졸업 시험 미달 시 문지기 강화 정도**
- 상황: 졸업 시험(정예 인장 3 + 세트 3종 제작 + 도감 15종)을 안 해도 문지기에 도전할 수 있다. 대신 달성도 a(인장 40%·세트 30%·도감 30%)가 낮으면 문지기가 강해진다. 공식: HP ×(1+0.5×(1−a)), 피해 ×(1+0.2×(1−a)). 달성도 0이면 HP ×1.5, 피해 ×1.2. 실측 전이라 임시값.
- A 이대로 두고 실측 후 조정(추천).
- B 더 세게(HP ×2.0, 피해 ×1.4): 시험을 하게 만드는 압박이 커진다. 대신 맨몸으로 도전하는 사람은 벽처럼 느낄 수 있다.
- C 더 약하게(HP ×1.25, 피해 ×1.1): 자유도는 높고 시험의 의미는 줄어든다.

**3. 세트 제작에 드는 골드**
- 상황: 세트 5부위 제작 골드 합계가 1,300(Wolf·Wisp)~2,500(Outlaw·Raider)이다. 그 구역에서 시간당 직접 소득의 약 15%이다. 재료 모으기가 주 비용이고 골드는 보조.
- A 유지(추천) / B 더 비싸게(소득의 25~30%, 골드 sink 강화) / C 더 싸게(소득의 8~10%)

**4. 산적 성채 상향 보상 구성**
- 상황: 선택 콘텐츠라 갈 이유를 줬다. 재료 드롭 45%, 미니보스 M4 확정 Outlaw 부츠 1점(부위는 임시로 가장 싼 것), 산적 대장 강화석 4~9개(첫 처치 9개)·전쟁 깃발 16%, Outlaw·Raider 세트 HP +8%·방어 +2, 성채 전용 보급 상점(물약·강화석).
- A 이대로(추천) / B 더 후하게 / C 보급 상점 가격 할인·대량 묶음 추가(현재는 일반 상점 가격과 같다. 구현하려면 Price 열 추가 필요)

**5. 신규 맵 2장(깊은 숲 심부·안개 늪)의 위치와 크기**
- 상황: 기존 깊은 숲·늪에 포털로 붙였고 보스(엔트·슬라임)는 기존 맵에 그대로 있다. 폭과 층수는 초안이고 몹·수집품도 임시다.
- 직접 가 보시고 "크기 괜찮다 / 더 크게 / 더 작게 / 구조 바꿔라" 정도로 알려 주세요.

**6. SampleScene.unity 커밋 시점**
- 상황: 신규 맵 2장은 이 씬 파일에 이미 들어 있다. 그런데 이 파일이 사용자 미커밋 변경(작업 전부터 대량 변경)과 섞여 있다. 맵 백업 프리팹은 `Assets/Backup/Floor1Maps/`(포털 참조 끊김)에 있다.
- A 지금 커밋(그 변경들 포함해서. 원하시면 변경 목록을 먼저 요약해 드린다).
- B 사용자가 변경을 정리한 뒤 커밋(추천): 씬이 길게 미커밋이면 맵이 사고로 사라질 위험이 있어 가능한 한 빨리.
- C 맵을 별도 씬으로 분리: 게임이 `GameObject.Find('Map')` 자식으로 맵을 찾고 포털이 씬 오브젝트를 참조해서 깨질 수 있어 비권장.

## 나. 어제 발견된 문제 — 방향 선택이 필요

**7. 깊은 숲 포털 도착 지점이 위험하다**

- A 도착 지점을 몹에서 떨어진 곳으로 옮기고 입구 근처 몹 배치를 줄임(추천): 근본 해결, 맵 데이터 수정.
- B 진입 직후 3~5초 무적을 줌: 구현이 쉽고 어디서든 통용되지만 몹이 입구에 몰린 어색함은 남는다.
- C 둘 다: 가장 안전.

**8. 통주 2시간 판정이 불확정**
- 상황: 통주 봇이 고대 엔트(Q301)에서 막혀 완주 못 했다. 무적 없이 75분 동안 처치 953·사망 19(깊은 숲 11). 무적 실행은 수치 오염이라 판정에서 뺐다. "2시간 이상" 목표를 아직 수치로 확인하지 못했다.
- A 봇의 보스 대응을 보강해 내일 재측정(추천): 평일에 해서 주말 비용을 아낀다.
- B 사용자가 직접 한 번 통주하고 시간을 알려 주기(주말).
- C 둘 다.

**9. 선택 퀘스트가 수락이 안 된다(NPC_BLOCK)**
- 상황: 어제 봇이 일부 선택 퀘스트에서 수락이 막히는 것을 발견했다. 원인 조사가 큐에 있다.
- 사용자께서 직접 플레이하다가 "이 NPC 대화가 안 된다" 같은 경험이 있으면 알려 달라(없으면 건너뛰기).

## 다. 기획 추가 제안 (데모 완성도 관점. 넣을 것을 고르세요, 여러 개 가능)

**10. 1층계 데모에 넣고 싶은 것**
- A **첫 행동 힌트·튜토리얼**: 마을 첫 진입 때 이동/공격/점프/물약/퀘스트창을 짧게 안내. 데모 첫인상과 이탈 방지에 효과가 가장 크다. 비용: 작음.
- B **미니맵·웨이포인트**: 구역이 6곳에서 신규 맵 포함 8곳으로 늘어 길 찾기 부담이 크다. 퀘스트 목적지 표시. 비용: 중간(기본 기능 목록에 있음).
- C **전투 효과음·구역 BGM**: 무음이면 데모가 매우 비어 보인다. 보유 에셋(사운드 카탈로그)을 매핑하는 작업이라 비용은 중간이고 체감 효과는 크다.
- D **데모 엔딩 연출**: 문지기 격파 후 "다음 층계 예고" 화면 + 플레이 시간·킬 수·사망 수 요약. 데모로 낼 때 마무리감. 비용: 작음.
- E **설정 메뉴·키 설정**: 조작감이 바뀌었으니 키를 바꾸고 싶어질 수 있다. 사운드 볼륨도 같이. 비용: 중간.
- F **사망 페널티 재점검**: 지금 사망 EXP −5%. 몸박이 약해졌고 점프·캔슬이 쉬워졌으니 체감이 달라졌다.
- 추천: A + D(싸고 효과 큼), 다음으로 C. 나머지는 상황 봐서.

**11. 도감·업적 요소를 더 키울까?**
- 상황: 도감 15종이 졸업 시험에 들어가 있다. 도감 보상은 현재 단순하다.
- A 지금대로 / B 도감 완성 보상(칭호·소품 아이템)을 추가 / C 구역별 "탐험가 칭호"를 1층계에서 먼저 체험하게 확장

**12. 정예 둥지(웨이브 → 정예 → 상자) 반복성**
- 상황: 둥지는 쿨타임 3분이고 실패하면 쿨타임이 돈다. 상자 보상 수치는 임시.
- A 구역당 하루 1~2번만(소모성 콘텐츠로 희소하게) / B 무제한 반복 가능(파밍 루프로 활용, 추천) / C 처음 한 번은 확정 보상, 그 후 낮은 보상

## 라. 세밀하게 잡아 줬으면 하는 것 (직접 플레이 후 짧게 말씀해 주세요)

**13. 조작감 체감** — "더 빠르게 / 더 느리게 / 지금 좋음"
- 공격 중 앞키 전진(1·2타 0.5, 3타 0.25).
- 캔슬 창(후딜 40% 지점부터 이동·점프로 끊기).
- 점프(버퍼 0.1초, 코요테 0.08초, 가변 점프 높이), 가감속.
- 공중 평타 관성.
- 특히 걸리는 느낌이 남아 있는 상황(예: 계단 오를 때, 벽 붙을 때, 3타 후 이동)이 있으면 알려 주세요.

**14. 몸박 ×0.5** — 일반 몹 몸박이 약해졌다. "여전히 아프다 / 적당 / 너무 약하다". 요즘 게임에 몸박이 안 어울리면 비활성화도 검토하라고 하셨으니, "몸박 자체를 아예 없애고 싶다 / 약하게 유지 / 원래대로" 중에서.

**15. 물약과 골드 체감** — 샛길(Lv2)에서 물약비가 소득의 20~30%가 되게 맞추기로 했다. 지금 초반이 빡빡한가, 여유로운가.

**16. 주인공 그림(ds03 vs 예전 셀)** — 나란히 비교 시트를 아직 안 만들었다.
- A 비교 시트를 만들어서 고르기(생성 비용 0)(추천) / B 지금은 ds03 확정 / C 예전 셀로 복귀
- 판단 기준: 호감도·유입이 높은 쪽, 비슷하면 싼 쪽. 제 의견은 ds03(걷기 합격, 인디 액션 장르 느낌), 단 무기·방어구 외형이 그림에 박혀 있다는 단점.

**17. 신규 맵·미니보스·정예 둥지·무기 시연대의 느낌** — 구조 위주로. 임시 그림이므로 색·모양은 신경 쓰지 말고 "크기, 몹 수, 보상, 동선" 정도만.
