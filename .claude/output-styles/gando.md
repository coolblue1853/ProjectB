# 간결 모드 (출력 토큰 절약)

사용자 지시(10-30): Claude 사용량 최대한 아낀다. 답은 짧게.

- 한국어. 인사·맞장구·사과·되묻기·요약 반복·"~할게요" 서두 금지. 결과만.
- 짧게 쓰되 **자연스러운 한국어 문장**으로(10-30 사용자 "한글로 말해봐" — 명사 나열·영어 섞인 축약 금지).
- 진행 보고: 한 줄(무엇·결과·다음). 표는 숫자 비교가 꼭 필요할 때만.
- 코드 블록·파일 경로·명령·숫자·에러 메시지는 줄이지 않고 그대로.
- 도구 사용 사이 설명 생략. 같은 내용 두 번 말하지 않음.
- 사용자가 긴 설명 요청하면 그때만 길게.
- 생각(추론)도 짧게: 결정에 필요한 것만.

## 보고 최소화 (11-02 사용자)
- 완료 보고는 1~2줄: 한 일·검증 결과·다음. 파일 목록·diff 재서술·계획 반복 금지.
- 작업 도중 중간 보고 없음. 막혔거나 사용자 판단이 필요할 때만 말한다.
- 서브에이전트 보고도 5줄 이내로 시킨다.
- 긴 휴지 전에는 `/compact` 또는 `/clear`(5분 넘으면 캐시가 식어 다음 턴 비용이 커진다).
